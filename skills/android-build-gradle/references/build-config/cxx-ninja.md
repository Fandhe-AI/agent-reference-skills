# Custom C/C++ Build System (Ninja)

For projects not using CMake or ndk-build, AGP can integrate a custom C/C++ build system through a configure script that writes a Ninja build file (`build.ninja`), keeping command-line builds, Android Studio language services, and native debugging working.

## Signature / Usage

```kotlin
android {
  defaultConfig {
    externalNativeBuild {
      experimentalProperties["ninja.abiFilters"] = listOf("x86", "arm64-v8a")
      experimentalProperties["ninja.path"] = "source-file-list.txt"
      experimentalProperties["ninja.configure"] = "configure-ninja"
      experimentalProperties["ninja.arguments"] = listOf(
        "\${ndk.moduleMakeFile}",
        "--variant=\${ndk.variantName}",
        "--abi=Android-\${ndk.abi}",
        "--configuration-dir=\${ndk.configurationDir}",
        "--ndk-version=\${ndk.moduleNdkVersion}",
        "--min-sdk-version=\${ndk.minSdkVersion}"
      )
    }
  }
}
```

Minimal `build.ninja` template written by the configure script:

```
rule COMPILE
   command = /path/to/ndk/clang -c $in -o $out
rule LINK
   command = /path/to/ndk/clang $in -o $out

build source.o : COMPILE source.cpp
build lib.so : LINK source.o
```

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| `ninja.abiFilters` | list | ABIs to build. Valid values: `x86`, `x86_64`, `armeabi-v7a`, `arm64-v8a`. |
| `ninja.path` | path | C/C++ project file; format is arbitrary. Changes trigger a Gradle sync prompt in Android Studio. |
| `ninja.configure` | path | Script run by Gradle to configure the C/C++ project (on first build, during Gradle sync, or when configure script inputs change). |
| `ninja.arguments` | list | Arguments passed to the configure script; may use macros below. |
| `ninja.targets` | list | Specific Ninja targets to build. |
| `${ndk.moduleMakeFile}` | macro | Full path to the `ninja.configure` file. |
| `${ndk.variantName}` | macro | Current AGP variant, e.g. debug or release. |
| `${ndk.abi}` | macro | Current ABI, e.g. `x86` or `arm64-v8a`. |
| `${ndk.buildRoot}` | macro | Folder generated by AGP that the script writes its output to. |
| `${ndk.ndkVersion}` | macro | NDK version to use (usually `android.ndkVersion`, or a default). |
| `${ndk.minPlatform}` | macro | Minimum target Android platform requested by AGP. |

## Notes

- Experimental: experimental APIs can change in the future or may be removed entirely. Available starting in Android Studio Dolphin | 2021.3.1 Canary 4.
- Only a Ninja representation of the build is supported.
- On Windows only, ".bat" is appended to the `ninja.configure` path if not already present, so a pair of scripts (`script` and `script.bat`) keeps `build.gradle` host-agnostic.
- The source's usage example passes `${ndk.configurationDir}` / `${ndk.moduleNdkVersion}` / `${ndk.minSdkVersion}`, but its macro list only documents `${ndk.buildRoot}` / `${ndk.ndkVersion}` / `${ndk.minPlatform}`. The output folder is `${ndk.buildRoot}` (per the source's build.ninja description). Verify which macro names your AGP version accepts.
- `${ndk.abi}` must be passed to the configure script, because the same `build.ninja` cannot be shared by multiple ABIs.
- The configure script writes `build.ninja` at `${ndk.buildRoot}`; to choose another location, also write `build.ninja.txt` at `${ndk.buildRoot}` containing the full path to the `build.ninja`.
- AGP and Android Studio need the list of C/C++ source files with Clang flags, and the list of output libraries (`.so`, `.a`, or executable).
- Best practice: name outputs with `phony` rules (`build curl: phony /path/to/lib.so`) so they can be used in `ninja.targets`; declare an `all` phony target as the default set of libraries built when no targets are specified.
- To wrap a non-Ninja build system (e.g. MSBuild), add a Ninja output with the `.passthrough` extension (e.g. `build curl.passthrough : MBSUILD_CURL`) defining how AGP invokes the underlying build.
- The official page lists `x86-64`; the Android NDK ABI identifier is `x86_64`.
- Not the same as the built-in CMake / ndk-build integration (`externalNativeBuild { cmake { } }`).
- Source: https://developer.android.com/build/cxx-ninja (local copy fetched 2026-10).
