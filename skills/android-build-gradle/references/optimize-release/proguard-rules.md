# ProGuard/R8 Keep Rules

`proguard-rules.pro` (or `.keep` files under `keepRules/` on AGP 9.3+) declares which classes and members R8 must not remove, rename, or optimize away.

## Signature / Usage

```kotlin
android {
    defaultConfig {
        // Rules a library consumer's build must also apply
        consumerProguardFiles("consumer-rules.pro")
    }

    buildTypes {
        release {
            isMinifyEnabled = true
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
        }
    }
}
```

```proguard
# proguard-rules.pro
-keep class com.example.MyClass { *; }

-keepclassmembers class * {
    *** someMethod(...);
}

-dontwarn com.external.**

-keepattributes SourceFile,LineNumberTable,*Annotation*,Signature,Exceptions
```

## Options / Props

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `-keep` | directive | — | Preserves a class and (optionally) its specified members from removal, renaming, and optimization. |
| `-keepclassmembers` | directive | — | Preserves specified members only if the containing class survives shrinking; enables more optimization than `-keep`. |
| `-keepclasseswithmembers` | directive | — | Preserves a class and members only if all specified members exist. |
| `-keepnames` / `-keepclassmembernames` | directive | — | Prevents renaming but still allows removal if unused. |
| `-dontwarn` | directive | — | Suppresses warnings about missing classes/members (e.g. optional external library classes). |
| `-keepattributes` | directive | — | Preserves class-file attributes (e.g. `SourceFile,LineNumberTable` for stack traces, `*Annotation*` for reflection, `Signature` for generics). |
| `-dontobfuscate` | directive | — | Disables obfuscation entirely; troubleshooting only. |
| `consumerProguardFiles` | `vararg String` | — | Rule files bundled into an AAR so consuming apps automatically apply the library's required keep rules. |
| Keep option modifiers | `allowoptimization`, `allowobfuscation`, `allowshrinking`, `includedescriptorclasses`, `allowaccessmodification`, `allowrepackage` | — | Attached to a keep option (e.g. `-keep,allowoptimization class ...`) to relax specific protections while keeping others. |

## Notes

- Wildcards: `**` matches any type name across package separators, `*` matches within one segment, `***` (members only) matches any type including primitives/arrays, `...` matches any parameter list, `%` matches any primitive type.
- `-keepclassmembers` is recommended over `-keep` where possible, since it lets R8 remove the class itself if otherwise unreferenced.
- Conditional rules use `-if <class_specification_if> <keep_rule>`, referencing captured wildcards with `<1>` (e.g. keeping `NavArgs.fromBundle` or Gson `@SerializedName` fields).
- Kotlin specifics: suspend functions gain a `Continuation` parameter in generated bytecode; top-level functions in `MyClass.kt` compile to a `MyClassKt` class; `internal` members should be referenced as `public` in keep rules.
- AGP 9.2+ supports negating member patterns, e.g. `public *** !*ForTesting(...)` to keep all public methods except those ending in `ForTesting`.
- Use APK Analyzer or Android Studio's "Show Kotlin Bytecode > Decompile" to verify the exact generated class/method names before writing rules.
- AGP 9.3+: default file is `proguard-android-optimize.txt`; `proguard-android.txt` (with `-dontoptimize`) is dropped starting AGP 9.0.
