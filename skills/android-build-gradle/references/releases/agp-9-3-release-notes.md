# AGP 9.3 Release Notes

Android Gradle plugin 9.3 is a minor release that includes a variety of new features and improvements.

## Signature / Usage

```bash
# Run the R8 Configuration Analyzer in isolation (no APK/Bundle compilation)
./gradlew :app:analyzeReleaseR8Config
```

## Options / Props

| Item | Minimum version | Default version |
|------|-----------------|-----------------|
| Gradle | 9.5.0 | 9.5.0 |
| SDK Build Tools | 36.0.0 | 36.0.0 |
| NDK | N/A | 28.2.13676358 |
| JDK | 17 | 17 |

## Notes

- Compatibility table above: maximum supported API level is 37.
- Standalone R8 Configuration Analyzer task: `:app:analyzeReleaseR8Config` generates the report without completing the APK or Bundle pipeline, giving a shorter feedback loop when refining keep rules. The report is also generated by R8 release builds such as `assembleRelease` or `bundleRelease`.
- Updated optimization DSL: a new `optimization` block configures R8 keep rules, supported by app modules and library module tests. For apps, configure it inside a build type (such as `release` or `debug`). Turning on optimization enables both code optimization and optimized resource shrinking, and the default Android keep rules file no longer needs to be specified. The legacy DSL continues to be supported.
- Keep rule source sets: place keep rules in `src/<variant>/keepRules/` with the file suffix `.keep`. Supported by both the updated and legacy DSL, in app modules, library modules, and as consumer rules in Kotlin Multiplatform (KMP) modules.
- Fixed in 9.3.3: AGP 9.3.0's new `optimization { enable = true }` DSL did not set `isMinifyEnabled` in the ApplicationVariant object (#556343682); a number of D8/R8 issues (e.g. D8 9.2.14 slower in `mergeProjectDexDebug` #558810278, R8 non-determinism #554586985, `.kotlin_module` file name with `:` invalid on Windows #543685256).
- Fixed in 9.3.2: lint crash on JDK 17 (`NoSuchMethodError: java.util.List.removeLast()`, #522845800). 9.3.0 / 9.3.1 / rc releases list no public fixed issues.
- Source: https://developer.android.com/build/releases/agp-9-3-0-release-notes (fetched 2026-10).
