# Testing

Pino provides a dedicated utility for testing log output.

## pino-test

Use [`pino-test`](https://github.com/pinojs/pino-test) for verifying logs generated by the Pino logger in your test suites.

```js
const { test } = require('node:test')
const assert = require('node:assert')
const pino = require('pino')
const { sink, once } = require('pino-test')

test('logs the expected message', async () => {
  const stream = sink()
  const logger = pino(stream)

  logger.info('hello world')

  const result = await once(stream, 'info')
  assert.strictEqual(result.msg, 'hello world')
})
```

`sink()` creates a writable stream that buffers and parses each log line as JSON, so assertions can inspect the resulting objects directly instead of parsing raw output. `once(stream, level)` resolves with the next log record whose `level` matches, and rejects if a record with a different level arrives first; use `consecutive(stream, count)` to collect an array of the next `count` records in order for multi-log assertions.

## Notes

- `pino-test` is the officially recommended utility for testing Pino log output
- It is part of the core Pino ecosystem and maintained by the Pino team
- Use it to assert on log levels, messages, and structured data in tests
