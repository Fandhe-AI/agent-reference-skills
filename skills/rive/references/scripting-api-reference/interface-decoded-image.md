# DecodedImage

Pixel data decoded via `context:decodeImage(data)` (see [interface-context.md](./interface-context.md)).

## Options / Props

| Member | Description |
| --- | --- |
| `data` | Premultiplied RGBA8 pixel data (`width * height * 4` bytes) |
| `width` | Image width in pixels |
| `height` | Image height in pixels |
