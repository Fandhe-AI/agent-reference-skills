# Getting Started (Scripting)

Rive Scripting lets you write code, animation, and interaction together in the Rive Editor. Scripts run on Luau (a typed Lua dialect) with editor-generated type definitions for the engine APIs.

## Signature / Usage

Fundamentals to read in order:

- Why Scripting runs on Luau
- [Creating Scripts](./creating-scripts.md) — how to create a new script asset
- [Protocols](./protocol-overview.md) — the type of scripts you can create (Node, Layout, Converter, Path Effect, Listener Action, Transition Condition, Test, Util)
- [Script Inputs](./script-inputs.md) — connecting scripts to inputs and data
- [Debugging](./debugging.md) — inspecting output and errors
- AI Agent — using AI to create and modify scripts inside the editor
