# Rendering to a Bitmap

Rendering to a bitmap is not supported directly in the React runtime.

## Notes

- For snapshot testing or video generation, use external tools that integrate with Rive: Revideo and Remotion both provide Rive support for these use cases.
- To export static images or video directly from a `.riv` file, use the Rive Editor's export functionality instead of the React runtime.
