# Layout Styles

Visual styles — fills, strokes, feathers, blend modes, and corner radius — that can be applied directly to a Layout container, in addition to it acting as a container for other Rive objects.

## Options / Props

| Style Placement | Description |
| --- | --- |
| Background style | Fill/stroke/feather renders behind the Layout's child objects |
| Foreground style | Fill/stroke/feather renders in front of the Layout's child objects |
| Corner Radius | Rounds the rectangular shape generated by fills/strokes/feathers; also shapes the Layout's clipping bounds when Clip is enabled |
| Blend Mode | Background blend affects objects behind the Layout; foreground blend affects the Layout's children, background, and objects behind it |

## Notes

- Useful for cases like a fill + feathered drop shadow that should render behind children, while a stroke renders in front.
