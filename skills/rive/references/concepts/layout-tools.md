# Layout Tools

Editor tools and workflows for creating and arranging Layout containers.

## Options / Props

| Tool | Description |
| --- | --- |
| Layout tool | Creates a single Layout container by dragging on the artboard (Absolute) or on top of an existing Layout (Relative child) |
| Row / Column tool | Creates a Layout with an initial set of children positioned in a row or column; use number/arrow keys while dragging to set child count |
| Wrap in Layout | Wraps selected objects into a Layout via right-click → `Wrap in` → `Layout`, the `Shift + L` shortcut, or the Layout selection button in the inspector |
| Add Child Layout | Adds a new child Layout (width/height set to Fill) via the button shown in the inspector when a Layout is selected |
| Drag and drop | Absolute and Relative Layouts can be dragged/dropped into other Layouts via the hierarchy panel or directly on the stage |

## Notes

- Absolute Layouts can be dragged around or resized like other Rive objects.
- Layouts are deleted by selecting them and pressing the delete key.
