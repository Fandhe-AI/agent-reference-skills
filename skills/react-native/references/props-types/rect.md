# Rect Object Type

`Rect` accepts numeric pixel values to describe how far to extend a rectangular area. These values are added to the original area's size to expand it.

## Signature / Usage

```js
{
    bottom: 20,
    left: null,
    right: undefined,
    top: 50
}
```

## Options / Props

| Name | Type | Required |
| --- | --- | --- |
| `bottom` | number, `null`, `undefined` | No |
| `left` | number, `null`, `undefined` | No |
| `right` | number, `null`, `undefined` | No |
| `top` | number, `null`, `undefined` | No |

## Notes

- Used by `Image`, `Pressable`, `Text`, `TouchableWithoutFeedback`.
