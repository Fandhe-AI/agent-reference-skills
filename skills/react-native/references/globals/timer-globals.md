# Timer globals

Global timer and scheduling functions, as defined in Web specifications: `setTimeout`, `clearTimeout`, `setInterval`, `clearInterval`, `requestAnimationFrame`, `cancelAnimationFrame`, `requestIdleCallback`, `cancelIdleCallback`, and `queueMicrotask`.

## Signature / Usage

```text
The global `setTimeout` function, as defined in Web specifications.
```
