# Network globals

Global networking and binary-data APIs, as defined in Web specifications: `fetch`, `Headers`, `Request`, `Response`, `FormData`, `Blob`, `File`, `FileReader`, `URL`, `URLSearchParams`, `AbortController`, `AbortSignal`, `WebSocket`, and `XMLHttpRequest`.

## Signature / Usage

```text
The global `fetch` function, as defined in Web specifications.
```
