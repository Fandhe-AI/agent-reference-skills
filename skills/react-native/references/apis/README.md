# apis

| Name | Description | Path |
|------|-------------|------|
| AccessibilityInfo | Query whether a screen reader is active and subscribe to changes in its state. | [accessibilityinfo.md](./accessibilityinfo.md) |
| ActionSheetIOS | Displays the native iOS Action Sheet component. | [actionsheetios.md](./actionsheetios.md) |
| Alert | Launches an alert dialog with the specified title and message. | [alert.md](./alert.md) |
| Appearance | Exposes the user's appearance preferences, such as the preferred light or dark color scheme. | [appearance.md](./appearance.md) |
| AppRegistry | The JS entry point to running all React Native apps. | [appregistry.md](./appregistry.md) |
| AppState | Tells you whether the app is in the foreground or background, and notifies you when the state changes. | [appstate.md](./appstate.md) |
| BackHandler | Detects hardware back button presses on Android and lets you register back action listeners. | [backhandler.md](./backhandler.md) |
| Dimensions | Get the application window's (and screen's) width and height. | [dimensions.md](./dimensions.md) |
| DynamicColorIOS | iOS-specific platform color type, similar to UIColor colorWithDynamicProvider:. | [dynamiccolorios.md](./dynamiccolorios.md) |
| I18nManager | Utilities for managing Right-to-Left (RTL) layout support for languages like Arabic and Hebrew. | [i18nmanager.md](./i18nmanager.md) |
| Keyboard | Listen for native keyboard events and make changes to the keyboard, such as dismissing it. | [keyboard.md](./keyboard.md) |
| Linking | Linking gives you a general interface to interact with both incoming and outgoing app links. | [linking.md](./linking.md) |
| PermissionsAndroid | Access to Android M's permissions model. Dangerous permissions require a dialog prompt. | [permissionsandroid.md](./permissionsandroid.md) |
| PixelRatio | PixelRatio gives you access to the device's pixel density and font scale. | [pixelratio.md](./pixelratio.md) |
| Platform | Exposes the current OS, Version, and constants, plus select() for platform-specific values. | [platform.md](./platform.md) |
| PlatformColor | Access native colors on the target platform by supplying the native color's corresponding string value. | [platformcolor.md](./platformcolor.md) |
| ReactNativeVersion | Exposes the version of the resolved react-native package on the JS side. | [reactnativeversion.md](./reactnativeversion.md) |
| RootTag | An opaque identifier assigned to the native root view of your React Native surface. | [roottag.md](./roottag.md) |
| Settings | A wrapper for NSUserDefaults, a persistent key-value store available only on iOS. | [settings.md](./settings.md) |
| Share | Open a dialog to share text content. | [share.md](./share.md) |
| StyleSheet | A StyleSheet is an abstraction similar to CSS StyleSheets. | [stylesheet.md](./stylesheet.md) |
| ToastAndroid | Exposes the Android platform's ToastAndroid module as a JS module. | [toastandroid.md](./toastandroid.md) |
| useColorScheme | Provides and subscribes to color scheme updates from the Appearance module. | [usecolorscheme.md](./usecolorscheme.md) |
| useWindowDimensions | Automatically updates all of its values when screen size or font scale changes. | [usewindowdimensions.md](./usewindowdimensions.md) |
| Vibration | Vibrates the device. | [vibration.md](./vibration.md) |
