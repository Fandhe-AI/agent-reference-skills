# Debugging Release Builds

Symbolicating minified stack traces from release builds with source maps and `metro-symbolicate`.

## Signature / Usage

```shell
# Print usage instructions
npx metro-symbolicate

# From a file containing the stack trace
npx metro-symbolicate android/app/build/generated/sourcemaps/react/release/index.android.bundle.map < stacktrace.txt

# From adb logcat (Android)
adb logcat -d | npx metro-symbolicate android/app/build/generated/sourcemaps/react/release/index.android.bundle.map
```

## Enabling source maps

**Android** (enabled by default): ensure the following `hermesFlags` are present in `android/app/build.gradle`.

```groovy
react {
    hermesFlags = ["-O", "-output-source-map"]
}
```

Metro build output should show the sourcemap location:

```text
Writing bundle output to:, android/app/build/generated/assets/react/release/index.android.bundle
Writing sourcemap output to:, android/app/build/intermediates/sourcemaps/react/release/index.android.bundle.packager.map
```

**iOS** (disabled by default): in Xcode, edit the build phase "Bundle React Native code and images" and, above the other exports, add a `SOURCEMAP_FILE` entry with the desired output path.

```diff
+ export SOURCEMAP_FILE="$(pwd)/../main.jsbundle.map"
  WITH_ENVIRONMENT="../node_modules/react-native/scripts/xcode/with-environment.sh"
```

```text
Writing bundle output to:, Build/Intermediates.noindex/ArchiveIntermediates/application/BuildProductsPath/Release-iphoneos/main.jsbundle
Writing sourcemap output to:, Build/Intermediates.noindex/ArchiveIntermediates/application/BuildProductsPath/Release-iphoneos/main.jsbundle.map
```

## Notes

- Entries like `p@1:132161` are minified function names and bytecode offsets; symbolication translates them into file, line and function name (e.g. `AwesomeProject/App.js:54:initializeMap`).
- Source maps are required to symbolicate stack traces.
- Multiple source maps may be generated by the build process; use the one in the location shown in the examples.
- The source map must correspond to the exact commit of the crashing app; small source changes can cause large offset differences.
- If `metro-symbolicate` exits immediately with success, make sure the input comes from a pipe or redirection and not from a terminal.
