# gcloud storage insights operations

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha storage insights operations cancel

```text
NAME
    gcloud alpha storage insights operations cancel - cancel an insights
        operation

SYNOPSIS
    gcloud alpha storage insights operations cancel OPERATION_NAME
        [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha storage insights operations describe

```text
NAME
    gcloud alpha storage insights operations describe - describe an insights
        operation

SYNOPSIS
    gcloud alpha storage insights operations describe OPERATION_NAME
        [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha storage insights operations list

```text
NAME
    gcloud alpha storage insights operations list - list insights operations

SYNOPSIS
    gcloud alpha storage insights operations list PARENT_RESOURCE_NAME
        [--filter=EXPRESSION] [--limit=LIMIT] [--page-size=PAGE_SIZE]
        [--sort-by=[FIELD,...]] [--uri] [GCLOUD_WIDE_FLAG ...]
```
