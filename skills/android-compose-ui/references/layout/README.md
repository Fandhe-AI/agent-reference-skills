# layout

> This is the Jetpack Compose (Kotlin, `androidx.compose.foundation.layout`) API — distinct from the same-named SwiftUI / Ark UI / Chakra UI / fandhe-frontend components.

| Name | Description | Path |
|------|-------------|------|
| Column | Places children in a vertical sequence. | [column.md](./column.md) |
| Row | Places children in a horizontal sequence. | [row.md](./row.md) |
| Box | Stacks children on top of one another (Z-axis). | [box.md](./box.md) |
| Spacer | Empty space element sized via size modifiers. | [spacer.md](./spacer.md) |
| BoxWithConstraints | Box variant that exposes incoming constraints to its content. | [boxwithconstraints.md](./boxwithconstraints.md) |
| Arrangement / Alignment | Main-axis spacing (`Arrangement`) and cross-axis/2D positioning (`Alignment`) for Row/Column/Box. | [arrangement-alignment.md](./arrangement-alignment.md) |
| IntrinsicSize | Sizes content to its min/max intrinsic width or height. | [intrinsicsize.md](./intrinsicsize.md) |
| Modifier (layout) | Sizing/padding/offset/aspectRatio modifiers (size, fillMaxSize, padding, offset, aspectRatio, ...). | [modifier-layout.md](./modifier-layout.md) |
| LazyColumn | Vertically scrolling list that composes only visible items. | [lazycolumn.md](./lazycolumn.md) |
| LazyRow | Horizontally scrolling list that composes only visible items. | [lazyrow.md](./lazyrow.md) |
| LazyListScope (item / items / itemsIndexed / stickyHeader) | DSL for declaring items inside LazyColumn/LazyRow. | [lazy-list-scope.md](./lazy-list-scope.md) |
| rememberLazyListState | Creates/remembers a LazyListState for reading and controlling list scroll. | [rememberlazyliststate.md](./rememberlazyliststate.md) |
| LazyVerticalGrid | Lazy vertical grid with Fixed/Adaptive column counts. | [lazyverticalgrid.md](./lazyverticalgrid.md) |
| LazyHorizontalGrid | Lazy horizontal grid with Fixed/Adaptive row counts. | [lazyhorizontalgrid.md](./lazyhorizontalgrid.md) |
| LazyVerticalStaggeredGrid | Lazy vertical staggered grid supporting variable item heights. | [lazyverticalstaggeredgrid.md](./lazyverticalstaggeredgrid.md) |
| HorizontalPager / VerticalPager / rememberPagerState | Lazily paged content with snap-fling scrolling. | [pager.md](./pager.md) |
| FlowRow / FlowColumn | Wrapping row/column layouts that flow to a new line when space runs out. | [flow-layout.md](./flow-layout.md) |
| ConstraintLayout | Places composables relative to each other via constraints (separate artifact). | [constraintlayout.md](./constraintlayout.md) |
| Layout (custom layout) | Primitive composable for manual measure/place of children. | [layout.md](./layout.md) |
| SubcomposeLayout | Layout primitive that subcomposes content during measurement. | [subcomposelayout.md](./subcomposelayout.md) |
| verticalScroll / horizontalScroll / rememberScrollState / nestedScroll | Scroll modifiers for non-lazy scrollable content. | [scroll.md](./scroll.md) |
