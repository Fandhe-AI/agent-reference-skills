# Navigation Controls

| Name | Description | Path |
|------|-------------|------|
| NavigationView | Adaptive top-level navigation control (top/left pane, hierarchical items) | [navigationview.md](./navigationview.md) |
| NavigationViewItem | Single navigation entry hosted in a NavigationView pane | [navigationviewitem.md](./navigationviewitem.md) |
| TabView | Document/static tab strip with content, reordering, tear-out | [tabview.md](./tabview.md) |
| TabViewItem | Single tab (header + content) hosted in a TabView | [tabviewitem.md](./tabviewitem.md) |

| SplitView | Expandable/collapsible pane plus always-visible content area | [splitview.md](./splitview.md) |
| MenuBar | Horizontal row of top-level menus (File/Edit/View style) | [menubar.md](./menubar.md) |
| MenuBarItem | Single top-level menu entry hosted in a MenuBar | [menubaritem.md](./menubaritem.md) |
