# Collections

| Name | Description | Path |
|------|-------------|------|
| AnnotatedScrollBar | A vertical scrollbar replacement that shows category labels and a tooltip along the rail to help users navigate a large scrollable collection. | [annotated-scroll-bar.md](./annotated-scroll-bar.md) |
| ComboBox | A drop-down list: starts collapsed showing the current selection (or empty), and expands to show selectable items. | [combo-box.md](./combo-box.md) |
| FlipView | Displays one item at a time from a collection, letting the user "flip" through items via swipe, navigation buttons, or arrow keys. | [flip-view.md](./flip-view.md) |
| GridView | Presents a collection of items in rows and columns that scroll vertically, stacking items horizontally until a row fills and then wrapping to the next row. | [grid-view.md](./grid-view.md) |
| ItemContainer | Represents the container for an individual item in an `ItemsView` collection control. | [item-container.md](./item-container.md) |
| ItemsControl | Base class that presents a collection of items. Most practical collection controls (`ListView`, `GridView`, `ListBox`, `ComboBox`, `FlipView`, via `Selector`) derive from it. | [items-control.md](./items-control.md) |
| ItemsRepeater | A low-level, virtualizing, data-driven panel used as a building block for custom collection controls. | [items-repeater.md](./items-repeater.md) |
| ItemsView | Displays a collection of items using a pluggable, swappable layout system, while preserving selection when the layout changes at run time. | [items-view.md](./items-view.md) |
| ListBox | Lets a user choose one or multiple items from a collection that is always fully expanded (no compact/collapsed state, unlike `ComboBox`). | [list-box.md](./list-box.md) |
| ListView | Displays data stacked vertically in a single column. Best for text-focused, top-to-bottom-ordered collections such as message lists or search results. | [list-view.md](./list-view.md) |
| ScrollView | Provides scroll, pan, and zoom support for a single content element. The modern counterpart to `ScrollViewer`, built on `InteractionTracker` with animation-driven view changes, designed for full compatibility with `ItemsRepeater`. | [scroll-view.md](./scroll-view.md) |
| SemanticZoom | A control that lets users pinch-zoom between two synchronized views of the same data — a detailed `ZoomedInView` and a higher-level `ZoomedOutView` (e.g. group headers). | [semantic-zoom.md](./semantic-zoom.md) |
| SelectorBar | A lightweight bar that lets a user switch between a small, fixed number of sets/views of data (icon + text items), with exactly one item selected at a time. | [selector-bar.md](./selector-bar.md) |
| TreeView | Displays a hierarchical list with expanding/collapsing nodes, using indentation and chevron icons to show parent/child relationships. | [tree-view.md](./tree-view.md) |
