# AnimatedVisualPlayer

A general-purpose element that hosts and controls playback of an animated `Visual` tree (e.g. a Lottie animation), controlled imperatively via methods like `PlayAsync`, `Pause`, and `Stop`.

## Signature / Usage

```xaml
<AnimatedVisualPlayer x:Name="player" AutoPlay="True">
    <local:MyLottieAnimation/>
</AnimatedVisualPlayer>
```

```csharp
await player.PlayAsync(fromProgress: 0, toProgress: 1, looped: false);
player.Pause();
player.Stop();
player.SetProgress(0.5);
```

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| Source | IAnimatedVisualSource | The animated visual content (e.g. LottieGen-generated class). Content property of the element. |
| AutoPlay | bool | Whether the animated visual plays immediately when loaded. |
| PlaybackRate | double | Rate at which the animation plays. |
| IsPlaying | bool | Whether an animated visual is loaded and currently playing (read-only). |
| Duration | TimeSpan | Duration of the loaded animated visual, or `TimeSpan.Zero` if none loaded (read-only). |
| FallbackContent | object | Content displayed if the animated visual fails to load. |
| PlayAsync(from, to, looped) | method | Starts playing the loaded animated visual between progress values. |
| Pause() / Stop() | method | Pauses/stops the currently playing animation. |
| SetProgress(double) | method | Moves playback to a specific progress value without playing. |

## Notes

- Package: `Microsoft.UI.Xaml.Controls.AnimatedVisualPlayer` (WinUI 3). Distinct from Rive's `AnimatedVisualPlayer`-like players and Lottie players in other frameworks.
- Use AnimatedVisualPlayer (not AnimatedIcon) for animations that loop, play once, can be paused, or are not tied to a control's visual-state transitions, and anywhere general UI is needed (not just an icon slot).
- Requires content generated by the `LottieGen` tool from the Lottie-Windows library.
