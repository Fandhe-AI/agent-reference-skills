# Media & Misc Controls

| Name | Description | Path |
|------|-------------|------|
| AnimatedIcon | An `IconElement` that plays a Lottie-based animated icon in response to user interaction and visual state changes (e.g. hover, press, selection). | [animated-icon.md](./animated-icon.md) |
| AnimatedVisualPlayer | A general-purpose element that hosts and controls playback of an animated `Visual` tree (e.g. a Lottie animation), controlled imperatively via methods like `PlayAsync`, `Pause`, and `Stop`. | [animated-visual-player.md](./animated-visual-player.md) |
| CalendarDatePicker | A drop-down control optimized for picking a single date from a contextual calendar view (e.g. day-of-week or calendar fullness matters). | [calendar-date-picker.md](./calendar-date-picker.md) |
| CalendarView | A control that presents an always-visible calendar for a user to view and interact with, navigable by month, year, or decade. | [calendar-view.md](./calendar-view.md) |
| ColorPicker | A control for browsing and selecting colors via a spectrum, sliders, or RGB/HSV/hex text input. | [color-picker.md](./color-picker.md) |
| DatePicker | A standardized control for picking a localized date value via a drop-down picker surface (day/month/year columns). | [date-picker.md](./date-picker.md) |
| Expander | A container with a header that is always visible and a content area that can be expanded/collapsed to show or hide secondary content. | [expander.md](./expander.md) |
| Icon Elements | Base `IconElement` / `IconSource` class family — `FontIcon`, `SymbolIcon`, `PathIcon`, `BitmapIcon`, `ImageIcon` (plus their `*Source` forms) and `IconSourceElement` — used to assign icons via `Icon`/`IconSource` properties across controls. | [icon-elements.md](./icon-elements.md) |
| Image | A control that displays image content (`Image` element) or paints another object with an image (`ImageBrush`). | [image.md](./image.md) |
| InkCanvas / InkToolbar | UWP controls for pen/stylus ink input (`InkCanvas`) and an associated toolbar of ink tools (`InkToolbar`). | [inkcanvas-inktoolbar.md](./inkcanvas-inktoolbar.md) |
| MediaPlayerElement | A control to display video and image content, with built-in transport controls for play/pause, seek, volume, and captions. | [media-player-element.md](./media-player-element.md) |
| ParallaxView | A container that associates the scroll position of a foreground element (e.g. a list) with a background element (e.g. an image), creating a 3D depth effect via differing scroll rates. | [parallax-view.md](./parallax-view.md) |
| PersonPicture | Displays the avatar image for a person if one is available; otherwise displays the person's initials or a generic glyph. | [person-picture.md](./person-picture.md) |
| RefreshContainer | A `ContentControl` that wraps scrollable content (e.g. `ListView`, `ScrollViewer`) and implements pull-to-refresh via touch, backed by a `RefreshVisualizer`. | [refresh-container.md](./refresh-container.md) |
| Shapes | Drawing primitives in `Microsoft.UI.Xaml.Shapes` — `Rectangle`, `Ellipse`, `Line`, `Polygon`, `Polyline`, and `Path` — each a `UIElement` whose boundary is defined by a `Geometry` and rendered with `Fill`/`Stroke` brushes. | [shapes.md](./shapes.md) |
| SwipeControl | A touch-gesture accelerator for context menus, wrapping content and exposing directional swipe commands (Reveal or Execute mode). | [swipe-control.md](./swipe-control.md) |
| TimePicker | A standardized control for picking a time value via a drop-down picker surface (hour/minute/AM-PM columns). | [time-picker.md](./time-picker.md) |
| TitleBar | Provides a simplified way to create a custom app title bar that identifies the app, hosts system caption buttons, and lets the user drag the window. | [title-bar.md](./title-bar.md) |
| WebView2 | An embedded Chromium-based web browser control for displaying web content inside a WinUI 3 app. | [webview2.md](./webview2.md) |
