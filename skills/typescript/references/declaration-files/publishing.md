# Publishing

How to get declaration files to users: bundle them with the npm package, or publish to the `@types` organization on npm via DefinitelyTyped.

## Signature / Usage

Point `types` at the bundled declaration file in `package.json`:

```json
{
  "name": "awesome",
  "author": "Vandelay Industries",
  "version": "1.0.0",
  "main": "./lib/main.js",
  "types": "./lib/main.d.ts"
}
```

Version selection with `typesVersions` (folder redirect):

```json
{
  "name": "package-name",
  "version": "1.0.0",
  "types": "./index.d.ts",
  "typesVersions": {
    ">=3.1": { "*": ["ts3.1/*"] }
  }
}
```

File redirect:

```json
{
  "name": "package-name",
  "version": "1.0.0",
  "types": "./index.d.ts",
  "typesVersions": {
    "<4.0": { "index.d.ts": ["index.v3.d.ts"] }
  }
}
```

## Notes

- Two ways to publish: bundling with your npm package, or publishing to the `@types` organization. If types are generated by your source code, publish them with the source (both TypeScript and JavaScript projects can generate types via `declaration`); otherwise submit them to DefinitelyTyped, which publishes to `@types`.
- The `"typings"` field is synonymous with `types`.
- Dependencies: all managed by npm. If your declarations expose types from another package, list it (and its `@types/*` package if it does not bundle declarations) under `"dependencies"`, not `"devDependencies"`, so consumers get them. A command line application not used as a library might use `devDependencies`.
- Red flags: do not use `/// <reference path="..." />` in declaration files; use `/// <reference types="..." />`. If your definitions depend on another package, do not combine it with yours, do not copy its declarations, and do depend on the npm type declaration package if it does not package its declaration files.
- `typesVersions`: TypeScript reads it first when opening `package.json`. `{ "*": ["ts3.1/*"] }` works like path mapping. If none of the fields match, TypeScript falls back to `types`. For file redirects, imports within a project are not affected: redirections only affect the external API of a package.
- Matching uses Node semver ranges. With multiple fields, order matters: the first matching range applies, so `">=3.2"` must come before `">=3.1"` (the reverse order "doesn't work").
- `@types` packages are published automatically from DefinitelyTyped using the types-publisher tool; submit a pull request to DefinitelyTyped.
