# Modules - Introduction

How TypeScript models JavaScript modules. The Modules reference is divided into four sections: theory, guides, reference, and appendices.

## Signature / Usage

```text
Theory      /docs/handbook/modules/theory.html
Guides      /docs/handbook/modules/guides/choosing-compiler-options.html
Reference   /docs/handbook/modules/reference.html
Appendices  /docs/handbook/modules/appendices/esm-cjs-interop.html
```

## Notes

- Theory: develops the theory behind how TypeScript approaches modules. Start here to write the correct module-related compiler options for any situation, reason about how to integrate TypeScript with other tools, or understand how TypeScript processes dependency packages.
- Guides: show how to accomplish specific real-world tasks, starting with picking the right compilation settings for a new project.
- Reference: a more detailed look at the syntaxes and configurations presented in previous sections.
- Appendices: complicated topics that deserve more detail than the theory or reference sections allow.
