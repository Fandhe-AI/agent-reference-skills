# Generate

設定ファイルの生成。

## Signature / Usage

### editorconfig-checker 初期設定ファイルの生成

```sh
editorconfig-checker -init
```

プロジェクトルートに `.editorconfig-checker.json` を生成する。

## Notes

- 取得日: 2026-11-14。editorconfig-checker v4.0.2 の README に基づく。`-init` は設定を作成し、`-config` でパスを指定した場合はそこに作成される。
