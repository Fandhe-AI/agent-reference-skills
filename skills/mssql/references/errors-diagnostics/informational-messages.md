# Informational messages

To receive informational messages generated by `PRINT` or `RAISERROR` commands, listen for the `info` event on a `Request`.

## Signature / Usage

```javascript
const request = new sql.Request()
request.on('info', info => {
    console.dir(info)
})
request.query('print \'Hello world.\';', (err, result) => {
    // ...
})
```

## Options / Props

| Name | Description |
|------|-------------|
| `info.message` | Message. |
| `info.number` | The message number. |
| `info.state` | The message state, used as a modifier to the number. |
| `info.class` | The class (severity) of the message. Equal or lower than 10. |
| `info.lineNumber` | The line number in the SQL batch or stored procedure that generated the message. Line numbers begin at 1; if not applicable, the value is 0. |
| `info.serverName` | The server name. |
| `info.procName` | The stored procedure name. |
