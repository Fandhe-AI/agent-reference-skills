# Installation

Supported TDS drivers: Tedious (pure JavaScript - Windows/macOS/Linux, default) and MSNodeSQLv8 (Microsoft / Contributors Node V8 Driver for Node.js for SQL Server, v2-v5 native - Windows or Linux/macOS 64 bits only).

## Signature / Usage

### Tedious driver (default)

```
npm install mssql
```

### MSNodeSQLv8 driver (optional)

```
npm install mssql msnodesqlv8
```
