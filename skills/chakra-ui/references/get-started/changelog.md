# Changelog

Chakra UI v3 changelog is maintained on GitHub.

## Location

**URL:** [https://github.com/chakra-ui/chakra-ui/blob/main/.changelog/v3.mdx](https://github.com/chakra-ui/chakra-ui/blob/main/.changelog/v3.mdx)

## Notes

- The changelog is not hosted on the Chakra UI documentation site; it lives in the GitHub repository
- Current stable version: **3.38.0**
- At the 3.38.0 tag (`@chakra-ui/react@3.38.0`, commit `f0387b6e832a41663eb7186a375db7879337724e`), `.changelog/v3.mdx` goes up to 3.37.0 (it has no 3.38.0 entry); the 3.38.0 entry is in [`packages/react/CHANGELOG.md`](https://github.com/chakra-ui/chakra-ui/blob/f0387b6e832a41663eb7186a375db7879337724e/packages/react/CHANGELOG.md) (the 3.37.0 entry, also present in `.changelog/v3.mdx`, is the source for the `hideMode`, `DateInput`, `createOverlay<Props, TReturn>` and `createToaster<Content>` notes in this reference; the 3.38.0 entry is the source for the `Command`, `KbdGroup` and Ark UI 5.39.3 / 5.40.0 notes)
- 3.38.0 highlights: new `Command` component, `Kbd` gained `KbdGroup`, Ark UI updated to 5.39.3 and 5.40.0, plus patch fixes (`useBreakpoint`, `useMediaQuery`, `createOverlay`, `NumberInput`, `cva` / `sva`, `cursor` tokens)
- `3.37.0` references in older pages are baseline notes for behavior introduced in that release and remain valid
- The version basis is the pinned URL above; the `main` link under Location only points to the latest changelog location
