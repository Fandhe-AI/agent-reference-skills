# Legacy versions

The legacy versions of the Compose file reference have moved to the V1 branch of the Compose repository and are no longer actively maintained.

## Signature / Usage

```text
https://github.com/docker/compose/tree/v1/docs
```

## Notes

- The latest and recommended version of the Compose file format is defined by the Compose Specification. It merges the 2.x and 3.x versions and is implemented by Compose 1.27.0+.
- The top-level `version` element is obsolete in the Compose Specification (see Version and name).
- Docker Compose (container orchestration), not Jetpack Compose: see android-compose-ui / android-compose-components / android-compose-graphics-animation.
