# docker buildx version

Show buildx version information.

## Signature / Usage

```console
$ docker buildx version
github.com/docker/buildx v0.11.2 9872040b6626fb7d87ef7296fd5b832e8cc2ad17
```

## Notes

- The version string in the example above is the official docs' sample output, not the version documented by this skill (Buildx v0.38.0 per the vendored docs).
