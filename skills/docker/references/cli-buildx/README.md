# cli-buildx

| Name | Description | Path |
|------|-------------|------|
| docker buildx bake | Bake is a high-level build command. | [buildx-bake.md](./buildx-bake.md) |
| docker buildx build | Start a build using BuildKit. | [buildx-build.md](./buildx-build.md) |
| docker buildx create | Create a new builder instance pointing to a Docker context or endpoint. | [buildx-create.md](./buildx-create.md) |
| docker buildx du | Shows the disk usage of the currently selected builder's build cache. | [buildx-du.md](./buildx-du.md) |
| docker buildx history export | Export one or more build records to `.dockerbuild` archive files. | [buildx-history-export.md](./buildx-history-export.md) |

| docker buildx history inspect | Inspect a build record to view metadata such as duration, status, build inputs, platforms, outputs, and attached artifacts. | [buildx-history-inspect.md](./buildx-history-inspect.md) |
| docker buildx history logs | Print the logs for a completed build in the same format as `--progress=plain`. | [buildx-history-logs.md](./buildx-history-logs.md) |
| docker buildx history ls | List completed builds recorded by the active builder. | [buildx-history-ls.md](./buildx-history-ls.md) |
| docker buildx history open | Open a build record in Docker Desktop for visual inspection. | [buildx-history-open.md](./buildx-history-open.md) |
| docker buildx history rm | Remove one or more build records from the current builder's history. | [buildx-history-rm.md](./buildx-history-rm.md) |
| docker buildx history trace | View the OpenTelemetry trace for a completed build. | [buildx-history-trace.md](./buildx-history-trace.md) |
| docker buildx imagetools create | Create a new manifest list based on source manifests. | [buildx-imagetools-create.md](./buildx-imagetools-create.md) |
| docker buildx imagetools inspect | Show details of an image in the registry. | [buildx-imagetools-inspect.md](./buildx-imagetools-inspect.md) |
| docker buildx inspect | Shows information about the current or specified builder. | [buildx-inspect.md](./buildx-inspect.md) |
| docker buildx ls | Lists all builder instances and the nodes for each instance. | [buildx-ls.md](./buildx-ls.md) |
| docker buildx prune | Clears the build cache of the selected builder. | [buildx-prune.md](./buildx-prune.md) |
| docker buildx rm | Removes the specified or current builder. | [buildx-rm.md](./buildx-rm.md) |
| docker buildx stop | Stops the specified or current builder. | [buildx-stop.md](./buildx-stop.md) |
| docker buildx use | Switches the current builder instance. | [buildx-use.md](./buildx-use.md) |
| docker buildx version | Show buildx version information. | [buildx-version.md](./buildx-version.md) |
| docker buildx | Extended build capabilities with BuildKit. | [buildx.md](./buildx.md) |
