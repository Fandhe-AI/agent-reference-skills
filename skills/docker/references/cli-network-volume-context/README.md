| docker volume ls | List all volumes known to Docker. Alias: `docker volume list`. | [volume-ls.md](./volume-ls.md) |
| docker volume prune | Remove unused local volumes. | [volume-prune.md](./volume-prune.md) |
| docker volume rm | Remove one or more volumes. Alias: `docker volume remove`. | [volume-rm.md](./volume-rm.md) |
| docker volume update | Update a volume (cluster volumes only). Orchestrator: Swarm. | [volume-update.md](./volume-update.md) |
