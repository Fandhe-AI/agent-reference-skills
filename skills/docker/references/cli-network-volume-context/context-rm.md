# docker context rm

Remove one or more contexts. Alias: `docker context remove`.

## Signature / Usage

```console
$ docker context rm CONTEXT [CONTEXT...]
```

## Options / Props

| Option | Default | Description |
| --- | --- | --- |
| `-f`, `--force` |  | Force the removal of a context in use |
