# Third-party events in Eventarc

Preview. Eventarc asynchronously delivers events from third-party SaaS providers (non-Google providers that offer an Eventarc source) to subscribers. A subscriber creates a channel for the provider and passes the channel name and activation token to the provider, which activates the channel and then publishes events through the Eventarc Publishing API.

## Signature / Usage

List all Eventarc providers and retrieve their details, including supported event types (see the source's list-providers page):

```bash
gcloud eventarc providers list --location=us-central1
```

### Event subscription flow

1. A subscriber creates a channel using either the Eventarc API or the Google Cloud console.
2. Eventarc returns an activation token for the channel, which binds the channel to a specific provider.
3. The subscriber conveys the channel name and activation token to the event provider.
4. The event provider activates the channel using the activation token (valid 24 hours; once used it cannot be used again).
5. The event provider can now publish events to the channel using the Eventarc Publishing API.

## Options / Props

### Terms

| Term | Meaning |
|------|---------|
| Provider | Service or entity that can emit events directly to Google Cloud, which are routed to a project; includes third-party non-Google entities offering an Eventarc source |
| Subscriber | Subscribes to events from a provider; events can invoke, for example, a Cloud Run service or a Workflows workflow |
| Channel | Google Cloud resource, controlled by the subscriber, through which the provider interacts with the subscriber's project |
| Activation token | String generated by Eventarc at channel creation; the provider uses it to create a `ChannelConnection` in its own project, making the channel active. Valid 24 hours after creation, after which the channel becomes INACTIVE |
| Trigger | Configures event routing with filters (event type, destination, channel) |

## Notes

- Preview: subject to the "Pre-GA Offerings Terms"; Pre-GA features are available "as is" and might have limited support. No cost during preview, but it is a chargeable feature (see the Eventarc pricing page).
- Events from a provider can be routed to any Eventarc destination. Subscribers can filter on any attribute written by the provider.
- All third-party events are regional: each event is published to a channel connection, routed through a channel and matched to a trigger in the same Google Cloud region. Eventarc makes no assertion about the provider's data regionality; the provider platform's data location might not match the channel's. Providers may further limit regions; see the provider-specific page. You cannot create a channel in any other location than those listed.
- The activation token and channel name are credentials-like values: share them only with the intended provider. Once the token is used it cannot be used again and does not need to be retained.
