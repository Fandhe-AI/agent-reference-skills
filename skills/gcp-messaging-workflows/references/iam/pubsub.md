- Provides access to publish messages to a topic. Lowest-level resources where you can grant this role: - Topic
- Permissions (1): `pubsub.topics.publish`

#### Pub/Sub Subscriber (`roles/pubsub.subscriber`)

- Provides access to consume messages from a subscription and to attach subscriptions to a topic. Lowest-level resources where you can grant this role: - Snapshot - Subscription - Topic

### Example: grant a role

Generated example (not in the official docs) granting the first role on this page on a whole project (the role's lowest-level resource is Schema; granting it there instead limits the scope, but this example does not show that command):

```bash
gcloud projects add-iam-policy-binding PROJECT_ID \
  --member="user:EMAIL_ADDRESS" \
  --role="roles/pubsub.admin"
```
