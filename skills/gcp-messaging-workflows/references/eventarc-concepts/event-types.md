# Google event types supported by Eventarc

Eventarc routes events from Google services to downstream destinations whenever cloud resources change. You filter for specific event types to trigger automated actions in services such as Cloud Run and Workflows. Event types are either sent directly from a Google source or produced through Cloud Audit Logs.

## Signature / Usage

### Filter on an event type in a trigger

```bash
gcloud eventarc triggers create trigger-pubsub \
    --destination-run-service=hello \
    --destination-run-region=us-central1 \
    --location=us-central1 \
    --event-filters="type=google.cloud.pubsub.topic.v1.messagePublished" \
    --transport-topic=projects/your-projectid/topics/your-topic
```

### Using Cloud Audit Logs

Create filters with the `serviceName` and `methodName` values in the service audit logs (event type `google.cloud.audit.log.v1.written`). For exact values see https://docs.cloud.google.com/logging/docs/audit/services and Determine event filters for Cloud Audit Logs.

## Options / Props

### Edition support

| Edition | Supported Google event types |
|---|---|
| Eventarc Advanced | Event types sent directly from a Google source, except Cloud Firestore, Cloud Pub/Sub, Cloud Storage, Firebase Alerts, Firebase Authentication, Firebase Realtime Database, Firebase Remote Config, Firebase Test Lab, Gemini Cloud Assist. Support for Google event types must first be enabled to publish events from Google sources |
| Eventarc Standard | Directly from a Google source; using Cloud Audit Logs |

## Notes

- Preview (Pre-GA Offerings Terms) while Eventarc is GA: events sent directly from Eventarc, Firebase Realtime Database, and Gemini Cloud Assist. The source also marks Firebase Authentication as (preview) in its heading.
- Google Cloud IoT Core was retired on August 16, 2023, and Cloud IoT events were deprecated at that time; contact your account team for more information.
- Cloud Source Repositories: effective June 17, 2024 it is not available to new customers; organizations that used it before June 17, 2024 are not affected. New projects not connected to an organization cannot enable the API.
- Eventarc Advanced does not support direct events from Cloud Firestore, Cloud Pub/Sub, Cloud Storage, Firebase Alerts, Firebase Authentication, Firebase Realtime Database, Firebase Remote Config, Firebase Test Lab, or Gemini Cloud Assist.
