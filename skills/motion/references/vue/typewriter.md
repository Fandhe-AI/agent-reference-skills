# Typewriter

Motion+ component (1.5kb) for realistic typewriter text animations with human-like typing variance and accessible cursors.

## Signature / Usage

```bash
npm install motion-plus-vue
```

```ts
import { Typewriter } from "motion-plus-vue"
```

## Notes

- Not included in the free `motion-v` package; installed from `motion-plus-vue`.
- Requires a Motion+ subscription.
- Typing speed varies naturally, including pauses between sentences and slower speeds during longer words; supports backspace effects.
- Reactive: animates automatically when content changes.
- Text and cursor can be styled independently; animation and typing behavior are fully customizable.
- Includes ARIA labels for screen reader accessibility.
