# AnimateNumber

Motion+ component for beautiful number animations like countdowns, built on Motion's layout animation system and based on Max Barvian's NumberFlow.

## Notes

- Requires a Motion+ subscription.
- Adds 3.6kb on top of Motion for Vue.
- Uses Motion's existing transition settings for configuration.
- Based on an earlier version of NumberFlow; currently lacks newer props like `trend` and `plugins`.
