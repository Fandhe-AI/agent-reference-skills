# Cursor

Motion+ component for building custom cursors and follow-along effects in Vue, auto-adapting to links, text, and buttons.

## Signature / Usage

```bash
npm install motion-plus-vue
```

```ts
import { Cursor } from "motion-plus-vue"
```

The `useCursorState` hook (also covered in the official guide) exposes cursor state for customisation.

## Notes

- Not included in the free `motion-v` package; installed from `motion-plus-vue`.
- Requires a Motion+ subscription (one-time fee membership).
- Supports automatic content detection (links, buttons, text, disabled states).
- Style with CSS, animate with Motion variants.
- Supports follow-cursor effects and multiple simultaneous cursors with configurable spring strengths.
