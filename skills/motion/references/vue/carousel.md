# Carousel

Motion+ component for performant, accessible, infinitely-scrolling carousels in Vue with pointer, wheel, and keyboard navigation.

## Signature / Usage

```bash
npm install motion-plus-vue
```

```ts
import { Carousel } from "motion-plus-vue"
```

## Notes

- Not included in the free `motion-v` package; installed from `motion-plus-vue`.
- Requires a Motion+ subscription.
- Adds +5.8kb; built-in ARIA labels and RTL support.
- Performant infinite scrolling clones only the minimal set of items needed.
- Customizable via functions and state for controls.
