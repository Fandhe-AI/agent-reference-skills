# UnionValue() / AppUnionValue / AppUnionValueCasesProviding

The `@UnionValue` macro generates `AppUnionValue` conformance for an enum so it can be used as a Shortcuts parameter with rich metadata; `AppUnionValueCasesProviding` is the protocol of the generated `Cases` enum.

## Signature / Usage

```swift
@attached(extension, conformances: _IntentValueRepresentable, AppUnionValue, names: arbitrary) macro UnionValue()
```

```swift
protocol AppUnionValue : TypeDisplayRepresentable
```

```swift
protocol AppUnionValueCasesProviding : AppEnum
```

```swift
@UnionValue
enum Reaction {
    case tapback(Tapback)
    case text(String)
}

extension Reaction {
    static var typeDisplayRepresentation: TypeDisplayRepresentation {
        "Reaction"
    }

    static let caseDisplayRepresentations: [Cases: DisplayRepresentation] = [
        .tapback: "Tapback",
        .text: "Text Reaction"
    ]
}
```

## Options / Props

| Name | Declaration | Description |
| --- | --- | --- |
| `AppUnionValue.Cases` | `associatedtype Cases : AppUnionValueCasesProviding` (required) | The nominal type representing the cases of this union value. |
| `AppUnionValue.caseDisplayRepresentations` | `static var caseDisplayRepresentations: [Self.Cases : DisplayRepresentation]` (required; 1 default implementation) | A dictionary that maps each case to the visual elements that represent it. |
| `AppUnionValueCasesProviding.UnionValue` | `associatedtype UnionValue : AppUnionValue` (required) | The union value type that this cases enum represents. |

## Notes

- `UnionValue()`: iOS 18.0+, iPadOS 18.0+, Mac Catalyst 18.0+, macOS 15.0+, tvOS 18.0+, visionOS 2.0+, watchOS 11.0+
- `AppUnionValue` and `AppUnionValueCasesProviding`: iOS 27.0+, iPadOS 27.0+, Mac Catalyst 27.0+, macOS 27.0+, tvOS 27.0+, visionOS 27.0+, watchOS 27.0+ (June 2026 updates)
- `AppUnionValue`: union values conforming to this protocol can be used as Shortcuts parameters with rich metadata support, enabling appropriate picker UI and parameter summaries. The `@UnionValue` macro automatically generates conformance; custom metadata is provided by implementing the protocol requirements in an extension.
- `AppUnionValueCasesProviding`: automatically conformed to by the `Cases` enum generated by the `@UnionValue` macro. It bridges the cases enum back to the union value type and inherits metadata through the `AppEnum` conformance.
- The `UnionValue()` page itself carries no abstract or overview in the source JSON.
