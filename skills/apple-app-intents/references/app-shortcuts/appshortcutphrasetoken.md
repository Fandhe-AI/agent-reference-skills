# AppShortcutPhraseToken

Dynamic values you can include in the spoken phrases that run your shortcut.

## Signature / Usage

```swift
enum AppShortcutPhraseToken
```

Case listed under “Getting the tokens”:

```swift
case applicationName
```

## Options / Props

| Name | Kind | Description |
|------|------|-------------|
| applicationName | case | The only case listed on the page; no description is given |

## Notes

- iOS 16.0+, iPadOS 16.0+, Mac Catalyst 16.0+, macOS 13.0+, tvOS 16.0+, watchOS 9.0+; visionOS is listed on the page without an introduced version.
- Conforms to `Equatable` and `Hashable`.
