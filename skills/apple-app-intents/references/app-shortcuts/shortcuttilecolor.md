# ShortcutTileColor

Describes the colors a shortcut tile in the Shortcuts app.

## Signature / Usage

```swift
enum ShortcutTileColor
```

Used by the provider:

```swift
static var shortcutTileColor: ShortcutTileColor
```

## Options / Props

| Case | Description |
|------|-------------|
| blue | A blue color. |
| grape | A grape color. |
| grayBlue | A grayish-blue color. |
| grayBrown | A grayish-brown color. |
| grayGreen | A grayish-green color. |
| lightBlue | A light blue color. |
| lime | A lime color. |
| navy | A navy blue color. |
| orange | An orange color. |
| pink | A pink color. |
| purple | A purple color. |
| red | A red color. |
| tangerine | A tangerine color. |
| teal | A teal color. |
| yellow | A yellow color. |

## Notes

- iOS 16.0+, iPadOS 16.0+, Mac Catalyst 16.0+, macOS 13.0+, tvOS 16.0+, watchOS 9.0+; visionOS is listed on the page without an introduced version.
- Conforms to `Equatable`, `Hashable`, `Sendable` and `SendableMetatype`.
