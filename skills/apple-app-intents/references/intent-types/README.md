# intent-types

| Name | Description | Path |
|------|-------------|------|
| AudioPlaybackIntent | An App Intent that plays, pauses, or otherwise modifies audio playback state when it executes. | [audioplaybackintent.md](./audioplaybackintent.md) |
| AudioRecordingIntent | An app intent that starts, stops or otherwise modifies audio recording state. | [audiorecordingintent.md](./audiorecordingintent.md) |
| CameraCaptureIntent | Designates intent that will launch an activity that uses device's camera to capture photos or videos. | [cameracaptureintent.md](./cameracaptureintent.md) |
| CustomIntentMigratedAppIntent | An interface for replacing a custom SiriKit intent that allows existing shortcuts and donations to continue working. | [customintentmigratedappintent.md](./customintentmigratedappintent.md) |
| CustomURLRepresentationParameterConvertible | An interface that allows a type to express its contents in a URL representation. | [customurlrepresentationparameterconvertible.md](./customurlrepresentationparameterconvertible.md) |
| DeleteIntent | Delete the associated entity(s). | [deleteintent.md](./deleteintent.md) |
| DeprecatedAppIntent | An app intent that marks an action as deprecated and informs people which action to use instead. | [deprecatedappintent.md](./deprecatedappintent.md) |
| IntentURLRepresentation | The type that provides the URL for an app intent. | [intenturlrepresentation.md](./intenturlrepresentation.md) |
| OpenIntent | An app intent that opens and displays a specific item in your app's interface. | [openintent.md](./openintent.md) |
| OpenURLIntent | An app intent that opens one of your universal links and displays its contents. | [openurlintent.md](./openurlintent.md) |
| PlayVideoIntent | An intent that looks for videos based on a search term, then plays the content. | [playvideointent.md](./playvideointent.md) |
| ProgressReportingIntent | An intent that reports progress to the system during its execution. | [progressreportingintent.md](./progressreportingintent.md) |
| PushToTalkTransmissionIntent | An intent that begins or ends an audio transmission with the Push to Talk framework. | [pushtotalktransmissionintent.md](./pushtotalktransmissionintent.md) |
| SetValueIntent | An intent that contains a value which can be set. | [setvalueintent.md](./setvalueintent.md) |
| ShowInAppSearchResultsIntent | An app intent that displays a set of search results in the app's interface. | [showinappsearchresultsintent.md](./showinappsearchresultsintent.md) |
| StringSearchCriteria | A type that tells your app to match its items against a provided string. | [stringsearchcriteria.md](./stringsearchcriteria.md) |
| StringSearchScope | Constants that describe the types of content your app includes in search results when the search criteria is a string. | [stringsearchscope.md](./stringsearchscope.md) |
| SystemIntent | Designates intent types provided by App Intents. | [systemintent.md](./systemintent.md) |
| URLRepresentableIntent | An interface you add to an app intent type so the system can handle it like a universal link. | [urlrepresentableintent.md](./urlrepresentableintent.md) |
| VideoCategory | Constants for the categories of video content an app supports through `PlayVideoIntent`. | [videocategory.md](./videocategory.md) |
