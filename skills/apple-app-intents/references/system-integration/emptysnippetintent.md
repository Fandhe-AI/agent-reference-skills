# EmptySnippetIntent

A snippet intent that renders an empty view.

## Signature / Usage

```swift
struct EmptySnippetIntent
```

## Notes

- iOS 26.0+, iPadOS 26.0+, Mac Catalyst 26.0+, macOS 26.0+, tvOS 26.0+, visionOS 26.0+, watchOS 26.0+
- You don't create this type directly. `AppIntent` uses the default value for functions that expect a `SnippetIntent`.
- Conforms to `AppIntent`, `PersistentlyIdentifiable`, `Sendable`, `SendableMetatype`, `SnippetIntent`.
