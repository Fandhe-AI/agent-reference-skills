# ShowsSnippetIntent

The result of performing an action that present a snippet generated by a `SnippetIntent`-conforming type.

## Signature / Usage

```swift
protocol ShowsSnippetIntent : IntentResult where Self.Snippet == _SnippetIntentContainer
```

```swift
associatedtype Snippet = Never   // IntentResult.Snippet, the default
```

## Notes

- iOS 26.0+, iPadOS 26.0+, Mac Catalyst 26.0+, macOS 26.0+, tvOS 26.0+, visionOS 26.0+, watchOS 26.0+
- The source page contains only the declaration and links; there is no overview text. `IntentResultContainer` is the listed conforming type.
- Inherits from `IntentResult`, `Sendable`, `SendableMetatype`.
- Article: "Displaying static and interactive snippets".
