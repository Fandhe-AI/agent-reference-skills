# buttons

> This is the Jetpack Compose (Kotlin, `androidx.compose.material3`) API — distinct from the same-named SwiftUI / Ark UI / Chakra UI / fandhe-frontend components.

| Name | Description | Path |
|------|-------------|------|
| Button | Filled button for high-emphasis primary actions like "submit" and "save". | [button.md](./button.md) |
| FilledTonalButton | Medium-emphasis tonal button, middle ground between Button and OutlinedButton. | [filledtonalbutton.md](./filledtonalbutton.md) |
| ElevatedButton | High-emphasis button, a FilledTonalButton with a shadow. | [elevatedbutton.md](./elevatedbutton.md) |
| OutlinedButton | Medium-emphasis bordered button for secondary actions like "Cancel". | [outlinedbutton.md](./outlinedbutton.md) |
| TextButton | Low-emphasis button for non-critical actions like "Learn More". | [textbutton.md](./textbutton.md) |
| IconButton | Button displaying a single icon for a common action (with Filled/FilledTonal/Outlined variants). | [iconbutton.md](./iconbutton.md) |
| IconToggleButton | Icon button representing a binary on/off toggle action. | [icontogglebutton.md](./icontogglebutton.md) |
| FloatingActionButton | High-emphasis button promoting a single primary action (with Small/Large variants). | [floatingactionbutton.md](./floatingactionbutton.md) |
| ExtendedFloatingActionButton | FAB combining an icon and text label for descriptive primary actions. | [extendedfloatingactionbutton.md](./extendedfloatingactionbutton.md) |
| SegmentedButton | Individual button within a SingleChoiceSegmentedButtonRow / MultiChoiceSegmentedButtonRow. | [segmentedbutton.md](./segmentedbutton.md) |
| SplitButton | Groups a leading (primary) and trailing (secondary) button, e.g. action + dropdown. | [splitbutton.md](./splitbutton.md) |
| ButtonGroup | Horizontal button layout with press-driven expand/compress animation and overflow menu. | [buttongroup.md](./buttongroup.md) |
| FloatingActionButtonMenu | Expandable menu of items shown alongside a ToggleFloatingActionButton. | [floatingactionbuttonmenu.md](./floatingactionbuttonmenu.md) |
