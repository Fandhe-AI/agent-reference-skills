# navigation-components

> This is the Jetpack Compose (Kotlin, `androidx.compose.material3`) API — distinct from the same-named SwiftUI / Ark UI / Chakra UI / fandhe-frontend components.

| Name | Description | Path |
|------|-------------|------|
| TopAppBar | Small top app bar for information/actions at the top of a screen; base for CenterAligned/Medium/Large/Flexible variants. | [topappbar.md](./topappbar.md) |
| TopAppBarScrollBehavior | Interface controlling how a top/bottom app bar responds to content scrolling. | [topappbarscrollbehavior.md](./topappbarscrollbehavior.md) |
| BottomAppBar | Bottom app bar for navigation and actions across the bottom of the screen, with optional embedded FAB. | [bottomappbar.md](./bottomappbar.md) |
| HorizontalFloatingToolbar | Floating toolbar showing navigation/actions in a Row, collapsible on scroll. | [horizontalfloatingtoolbar.md](./horizontalfloatingtoolbar.md) |
| VerticalFloatingToolbar | Floating toolbar showing navigation/actions in a Column, collapsible on scroll. | [verticalfloatingtoolbar.md](./verticalfloatingtoolbar.md) |
| AppBarRow | Horizontal action layout that overflows excess children into a dropdown menu; base for AppBarColumn. | [appbarrow.md](./appbarrow.md) |
| NavigationBar | Persistent bottom navigation container for 3-5 primary destinations. | [navigationbar.md](./navigationbar.md) |
| NavigationBarItem | Single destination item within a NavigationBar. | [navigationbaritem.md](./navigationbaritem.md) |
| ShortNavigationBar | Compact bottom navigation container variant with configurable item arrangement. | [shortnavigationbar.md](./shortnavigationbar.md) |
| ShortNavigationBarItem | Single destination item within a ShortNavigationBar. | [shortnavigationbaritem.md](./shortnavigationbaritem.md) |
| NavigationRail | Vertical navigation container for tablet/desktop layouts. | [navigationrail.md](./navigationrail.md) |
| NavigationRailItem | Single destination item within a NavigationRail. | [navigationrailitem.md](./navigationrailitem.md) |
| NavigationDrawerItem | Single destination item used inside a navigation drawer sheet. | [navigationdraweritem.md](./navigationdraweritem.md) |
| PrimaryTabRow | Fixed row of primary tabs for main content destinations; base for Secondary/Scrollable variants. | [primarytabrow.md](./primarytabrow.md) |
| Tab | Individual tab with text and/or icon slots, used inside a tab row. | [tab.md](./tab.md) |
| LeadingIconTab | Tab variant with a required icon positioned before the text label. | [leadingicontab.md](./leadingicontab.md) |
