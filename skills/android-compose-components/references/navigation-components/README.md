# navigation-components

| Name | Description | Path |
|------|-------------|------|
| AppBarColumn | Arranges children vertically, and if children overflow the available height, displays an overflow indicator that moves excess items into a dropdown menu. | [appbarcolumn.md](./appbarcolumn.md) |
| AppBarRow | Arranges children horizontally (e.g. app bar actions), and if children overflow the available width, displays an overflow indicator that moves excess items into a dropdown menu. | [appbarrow.md](./appbarrow.md) |
| BottomAppBar | Material Design bottom app bar that displays navigation and key actions across the bottom of the screen, optionally embedding a FloatingActionButton. | [bottomappbar.md](./bottomappbar.md) |
| HorizontalFloatingToolbar | A horizontal floating toolbar that displays navigation and key actions in a Row, floating above content and optionally collapsing/expanding in response to scroll. | [horizontalfloatingtoolbar.md](./horizontalfloatingtoolbar.md) |
| LeadingIconTab | A tab displaying a text label with an icon positioned before the label. Responds to selection state through color tinting of both elements. | [leadingicontab.md](./leadingicontab.md) |
| NavigationBar | Container that offers a persistent, convenient way to switch between primary destinations in an app, displayed at the bottom of the screen. | [navigationbar.md](./navigationbar.md) |
| NavigationBarItem | Represents a single destination within a NavigationBar, handling the visual selected/unselected state and click interactions. | [navigationbaritem.md](./navigationbaritem.md) |
| NavigationDrawerItem | Represents a single destination within a navigation drawer, supporting an icon, badge, and selected state. | [navigationdraweritem.md](./navigationdraweritem.md) |
| NavigationRail | Container providing access to primary destinations in apps on tablet and desktop screens, displayed as a vertical column on the side of the screen. | [navigationrail.md](./navigationrail.md) |
| NavigationRailItem | Represents a single selectable destination within a NavigationRail, displaying an icon and an optional label. | [navigationrailitem.md](./navigationrailitem.md) |
| PrimaryTabRow | Material Design primary tabs row for displaying the main content destinations of a screen, placed at the top of the content pane under a top app bar. | [primarytabrow.md](./primarytabrow.md) |
| ShortNavigationBar | Material Design short navigation bar, a more compact bottom-navigation container variant offering a persistent way to switch between primary destinations. | [shortnavigationbar.md](./shortnavigationbar.md) |
| ShortNavigationBarItem | Represents a single destination within a ShortNavigationBar. Labels are always shown, both when selected and unselected, and the icon can be positioned at the top or start of the item. | [shortnavigationbaritem.md](./shortnavigationbaritem.md) |
| Tab | A primary navigation tab with slots for text and/or icon, representing a single page of content within a tab row. | [tab.md](./tab.md) |
| TopAppBar | Material Design small top app bar for displaying information and actions at the top of a screen. | [topappbar.md](./topappbar.md) |
| TopAppBarScrollBehavior | Interface that defines how a top app bar responds to the scrolling of the content below it. | [topappbarscrollbehavior.md](./topappbarscrollbehavior.md) |
| VerticalFloatingToolbar | A vertical floating toolbar that displays navigation and key actions in a Column, floating above content and optionally collapsing/expanding in response to scroll. | [verticalfloatingtoolbar.md](./verticalfloatingtoolbar.md) |
| WideNavigationRail | Material Design navigation rail providing access to primary destinations on tablet, desktop, and large-screen layouts. | [widenavigationrail.md](./widenavigationrail.md) |
| WideNavigationRailItem | Represents a single selectable destination within a WideNavigationRail or ModalWideNavigationRail, displaying an icon and a text label. | [widenavigationrailitem.md](./widenavigationrailitem.md) |
