# Deploying

Deploying a React Router v8 app.

## Signature / Usage

### Deployment modes

1. **Fullstack Hosting** — server-rendered apps
2. **Static Hosting** — SPA, deployed like a standard React app

### Official templates

#### Node.js + Docker (default)

```bash
npx create-react-router@latest --template remix-run/react-router-templates/default
```

Features server rendering + Tailwind CSS. Targets: AWS ECS, Google Cloud Run, Azure Container Apps, Digital Ocean, Fly.io, Railway.

#### Node.js + Docker + custom server

```bash
npx create-react-router@latest --template remix-run/react-router-templates/node-custom-server
```

Adds a custom Express server for finer control. Same deployment targets as above.

#### Node.js + Docker + Postgres

```bash
npx create-react-router@latest --template remix-run/react-router-templates/node-postgres
```

Adds Postgres with Drizzle ORM and a custom Express server. Same deployment targets as above.
