# Declarative Routers

| Name | Description | Path |
| --- | --- | --- |
| BrowserRouter | A declarative `<Router>` using the browser History API for client-side routing. | [BrowserRouter.md](./BrowserRouter.md) |
| HashRouter | A declarative `<Router>` that stores the location in the `hash` portion of the URL so it is not sent to the server. | [HashRouter.md](./HashRouter.md) |
| unstable_HistoryRouter | A declarative `<Router>` that accepts a pre-instantiated `history` object. | [HistoryRouter.md](./HistoryRouter.md) |
| MemoryRouter | A declarative `<Router>` that stores all entries in memory. | [MemoryRouter.md](./MemoryRouter.md) |
| Router | Provides location context for the rest of the app. | [Router.md](./Router.md) |
| StaticRouter | A `<Router>` that may not navigate to any other `Location`. Useful on the server where there is no stateful UI. | [StaticRouter.md](./StaticRouter.md) |
