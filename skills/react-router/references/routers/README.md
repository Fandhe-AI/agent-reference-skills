# routers

| Name | Description | Path |
|------|-------------|------|
| HydratedRouter | Framework Mode client-side router that hydrates the app from a `ServerRouter`-rendered HTML. Used in `entry.client.tsx` to initialize the router after SSR. | [HydratedRouter.md](./HydratedRouter.md) |
| ServerRouter | Framework Mode server-side router used to generate the initial HTML response. Used in `entry.server.tsx` to render the app on the server. | [ServerRouter.md](./ServerRouter.md) |
