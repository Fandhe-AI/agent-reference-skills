# AnimatedVisualPlayer (Lottie)

Hosts and controls playback of an animated `Visual` tree, used to display Lottie (Bodymovin JSON) vector animations rendered via the Lottie-Windows library, integrated with XAML UI.

## Signature / Usage

```xaml
<muxc:AnimatedVisualPlayer x:Name="Player" AutoPlay="True">
    <animatedvisuals:LottieLogo1_AnimatedVisualSource/>
</muxc:AnimatedVisualPlayer>
```

```csharp
Player.PlayAsync(fromProgress: 0, toProgress: 1, looped: false);
```

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| Source | `IAnimatedVisualSource` | The animated visual content to play (e.g. a `LottieVisualSource`, or a class generated by the `LottieGen` tool). |
| AutoPlay | bool | Whether the animation begins playing automatically when loaded. |
| IsPlaying | bool | Whether the player is currently playing. |
| PlaybackRate | double | Speed multiplier for playback. |
| Play() / PlayAsync(fromProgress, toProgress, looped) / Pause() / Stop() / SetProgress(double) | methods | Playback control. |

## Notes

- Package: `Microsoft.UI.Xaml.Controls` (WinUI 3), general-purpose animation player usable anywhere in the app UI — controlled via methods (`Play`/`Pause`), unlike `AnimatedIcon` which is controlled via a `State` property and used only where an `IconElement` is expected.
- Lottie content is produced from Adobe After Effects via Bodymovin, then either loaded dynamically with a `LottieVisualSource` (CommunityToolkit.WinUI.Lottie NuGet package) or precompiled to a C++/WinRT or C# class using the `LottieGen` command-line tool (recommended for performance).
- Use `AnimatedIcon` instead when the animation must respond to visual-state transitions (pointer over, pressed, selected) as a control's icon.
