# ItemContainerStyle

Gets or sets the `Style` used to render each item container generated by an `ItemsControl` (e.g. `ListViewItem` for `ListView`, `ContentPresenter` for a plain `ItemsControl`). Set as the container's `Style` property.

## Signature / Usage

```xaml
<ListView ItemsSource="{x:Bind tempList}">
    <ListView.ItemTemplate>
        <DataTemplate x:DataType="x:String">
            <TextBlock Text="{x:Bind}" FontSize="24"/>
        </DataTemplate>
    </ListView.ItemTemplate>

    <ListView.ItemContainerStyle>
        <Style TargetType="ListViewItem">
            <Setter Property="HorizontalAlignment" Value="Right"/>
            <Setter Property="Margin" Value="15"/>
        </Style>
    </ListView.ItemContainerStyle>
</ListView>
```

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| ItemContainerStyle | `Style` | Style applied to each generated item container; default is `null`. |

## Notes

- Package: `Microsoft.UI.Xaml.Controls` (WinUI 3, `ItemsControl.ItemContainerStyle`). Distinct from `System.Windows.Controls.ItemsControl.ItemContainerStyle` (WPF).
- Available on `ItemsControl` and its derived classes (`Selector`, `ListBox`, `ComboBox`, `FlipView`, `ListViewBase` → `ListView`/`GridView`, `MenuFlyoutPresenter`); the container type differs per control (`ContentPresenter` by default, `ListViewItem` for `ListView`, `GridViewItem` for `GridView`).
- Use `ItemContainerStyle` to change how the *container* around each item is laid out (alignment, margin, border) — use `ItemTemplate`/`DataTemplate` to change the visualization of the *data itself*, and `ItemsPanel` to change the overall layout/orientation of the collection.
- A companion `ItemContainerStyleSelector` property exists for per-item container style selection logic, analogous to `DataTemplateSelector`.
