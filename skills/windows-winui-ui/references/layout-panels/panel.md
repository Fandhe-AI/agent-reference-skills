# Panel

Provides a base class for all Panel elements. Use Panel elements to position and arrange child objects in a UI page.

## Signature / Usage

```xaml
<!-- Panel is abstract; use a derived type such as Grid, StackPanel, Canvas, etc. -->
<Grid>
    <!-- children -->
</Grid>
```

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| Children | `UIElementCollection` | Collection of child elements of the panel; the XAML content property |
| Background | `Brush` | Fills the panel content area |
| BackgroundTransition | `BrushTransition` | Automatically animates changes to `Background` |
| ChildrenTransitions | `TransitionCollection` | `Transition` style elements applied to child content |
| IsItemsHost | `bool` | Whether this Panel is a container for items generated by an `ItemsControl` |

## Notes

- Package: `Microsoft.UI.Xaml.Controls` (WinUI 3). Base class `FrameworkElement`. Distinct from `System.Windows.Controls.Panel` (WPF), `@ark-ui/react` / `@chakra-ui/react` layout primitives, and Jetpack Compose layout composables.
- Direct/practical derived layout panels: `Canvas`, `Grid`, `ItemsStackPanel`, `ItemsWrapGrid`, `RelativePanel`, `StackPanel`, `VariableSizedWrapGrid`, `WrapPanel`; `VirtualizingPanel` is an intermediate base for virtualizing item hosts.
- Choose a concrete Panel subtype based on how it positions/sizes children and handles overlap — see the panel-selection guidance.
