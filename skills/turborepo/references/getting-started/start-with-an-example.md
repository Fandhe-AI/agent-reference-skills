# Start with an Example

Initialize a monorepo using a core- or community-maintained example via `create-turbo`.

## Signature / Usage

```bash
pnpm dlx create-turbo@latest --example [example-name]
pnpm dlx create-turbo@latest --example [github-url]

yarn dlx create-turbo@latest --example [example-name]
npx create-turbo@latest --example [example-name]
bunx create-turbo@latest --example [example-name]
```

`--example` accepts either an example name or a GitHub repository URL.

## Options / Props

| Category | Description |
| --- | --- |
| Core-Maintained Examples | Maintained by the Turborepo team. Dependencies are kept up to date and supported promptly |
| Community-Maintained Examples | Maintained by the community. GitHub issues are closed, so fixes should be submitted as PRs |

## Notes

- Issues on community-maintained examples are closed as a matter of policy; propose fixes via PR instead
