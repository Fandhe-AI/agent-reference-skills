# Single-Package Workspaces

## Signature / Usage

Turborepo can also be used with a single-application structure generated by `create-next-app` or `npm create vite`.

Scenario 1: Sequential task execution

```json
{
  "tasks": {
    "dev": { "dependsOn": ["db:seed"], "persistent": true },
    "db:seed": { "dependsOn": ["db:push"] },
    "db:push": {}
  }
}
```

Execution order: `db:push` → `db:seed` → `dev`

Scenario 2: Parallel task execution

```bash
turbo check-types lint format
```

Scenario 3: Optimizing cache inputs

```json
{
  "tasks": {
    "check-types": { "inputs": ["**/*.{ts,tsx}"] }
  }
}
```

## Notes

- Available: local caching, remote caching, task parallelization.
- Unavailable: cross-package task targeting (such as `app#build`).
