# CLI

| Name | Description | Path |
|------|-------------|------|
| Supabase CLI: データベースコマンド | ローカルデータベースのスキーマ変更を差分として検出し、マイグレーション SQL を生成する。 | [db-commands.md](./db-commands.md) |
| Supabase CLI: Edge Functions コマンド | Edge Functions の作成（new）・ローカル実行（serve）・デプロイ（deploy）・削除（delete）・ダウンロード（download）コマンド。 | [functions-commands.md](./functions-commands.md) |
| Supabase CLI: 型生成コマンド | データベーススキーマから TypeScript の型定義ファイルを生成する。 | [gen-commands.md](./gen-commands.md) |
| Supabase CLI: 検査コマンド | `supabase inspect db` コマンド群は、データベースのパフォーマンスや状態を診断するためのツール。 | [inspect-commands.md](./inspect-commands.md) |
| Supabase CLI: ローカル開発コマンド | プロジェクトの初期化（init）・ローカル環境の起動（start）・停止（stop）・状態確認（status）・リモートプロジェクトへのリンク（link）コマンド。 | [local-dev.md](./local-dev.md) |
| Supabase CLI: マイグレーションコマンド | マイグレーションの作成（new）・適用（up）・ロールバック（down）・一覧（list）・取得（fetch）・履歴修復（repair）・統合（squash）コマンド。 | [migration-commands.md](./migration-commands.md) |
| Supabase CLI 概要 | npm / Homebrew / Scoop による CLI のインストール方法と認証設定、グローバルフラグ。 | [overview.md](./overview.md) |
| Supabase CLI: プロジェクト・その他コマンド | プロジェクト・組織・シークレット・Storage・ブランチ・ネットワーク制限・SSO などの管理コマンド。 | [project-commands.md](./project-commands.md) |
