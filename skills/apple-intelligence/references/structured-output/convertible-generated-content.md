# ConvertibleToGeneratedContent / ConvertibleFromGeneratedContent

Protocol pair for converting a type to and from `GeneratedContent`. `Generable` inherits both.

## Signature / Usage

### ConvertibleToGeneratedContent

A type that can be converted to generated content.

```swift
protocol ConvertibleToGeneratedContent : InstructionsRepresentable, PromptRepresentable
```

Requirement:

```swift
var generatedContent: GeneratedContent { get }
```

### ConvertibleFromGeneratedContent

A type that can be initialized from generated content.

```swift
protocol ConvertibleFromGeneratedContent : SendableMetatype
```

Requirement:

```swift
init(_ content: GeneratedContent) throws
```

## Options / Props

| Name | Protocol | Description |
| --- | --- | --- |
| generatedContent | ConvertibleToGeneratedContent | This instance represented as generated content. |
| init(_:) | ConvertibleFromGeneratedContent | Creates an instance from content generated by a model. |

## Notes

- Availability (both protocols): iOS 26.0+, iPadOS 26.0+, Mac Catalyst 26.0+, macOS 26.0+, visionOS 26.0+, watchOS 27.0+.
- Because `ConvertibleToGeneratedContent` refines `InstructionsRepresentable` and `PromptRepresentable`, conforming values can be used in instructions and prompts.
- Source fetched 2026-10-16 (no version in URL).
