# Transcript.Entry

An entry in a transcript. An individual entry may represent instructions from you to the model, a prompt from a user, tool calls, or a response generated by the model.

## Signature / Usage

```swift
@nonexhaustive enum Entry
```

## Options / Props

| Case | Description |
|------|-------------|
| instructions(_:) | Instructions, typically provided by you, the developer. |
| prompt(_:) | A prompt, typically sourced from an end user. |
| response(_:) | A response from the model. |
| reasoning(_:) | Reasoning from the model. |
| toolCalls(_:) | A collection of tool calls generated by the model. |
| toolOutput(_:) | A tool output provided back to the model. |
| data(_:) | An entry representing a custom type encoded as data. (beta) |

## Notes

- Availability: iOS 26.0+, iPadOS 26.0+, macOS 26.0+, Mac Catalyst 26.0+, visionOS 26.0+, watchOS 27.0+.
- Beta: iOS 27.2+ for `data(_:)`.
- The enum is `@nonexhaustive`; handle future cases with a default branch.
