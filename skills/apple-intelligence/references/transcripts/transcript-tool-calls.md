# Transcript.ToolDefinition / ToolCalls / ToolCall / ToolOutput

Transcript types for inspecting tool calling: the tool definitions offered to the model, the calls the model generates, and the outputs provided back.

## Signature / Usage

### Transcript.ToolDefinition

A definition of a tool.

```swift
struct ToolDefinition
```

### Transcript.ToolCalls

A collection of tool calls generated by the model.

```swift
struct ToolCalls
```

### Transcript.ToolCall

A tool call generated by the model containing the name of a tool and arguments to pass to it.

```swift
struct ToolCall
```

### Transcript.ToolOutput

A tool output provided back to the model.

```swift
struct ToolOutput
```

## Options / Props

### Transcript.ToolDefinition

| Name | Description |
|------|-------------|
| init(name:description:parameters:) | Creates a tool definition with the name, description, and parameter schema you provide. |
| init(tool:) | Creates a tool definition that describes the tool you provide. |
| description | A description of how and when to use the tool. |
| name | The tool's name. |
| parameters | A schema that specifies the parameters of the tool. |

### Transcript.ToolCalls

| Name | Description |
|------|-------------|
| init(id:_:) | Creates a collection that contains the tool calls you provide. |
| RandomAccessCollection Implementations | `ToolCalls` is a random-access collection of tool calls. |

### Transcript.ToolCall

| Name | Description |
|------|-------------|
| init(id:toolName:arguments:) | Creates a tool call that invokes a tool with the arguments you provide. |
| init(id:metadata:toolName:arguments:) | Creates a tool call that invokes a tool with the metadata and arguments you provide. |
| arguments | Arguments to pass to the invoked tool. |
| toolName | The name of the tool being invoked. |
| metadata | Metadata produced by the model while generating this tool call. |

### Transcript.ToolOutput

| Name | Description |
|------|-------------|
| init(id:toolName:segments:) | Creates a tool output that provides the result of a tool call back to the model. |
| id | A unique id for this tool output. |
| segments | Segments of the tool output. |
| toolName | The name of the tool that produced this output. |

## Notes

- Availability (all four types): iOS 26.0+, iPadOS 26.0+, macOS 26.0+, Mac Catalyst 26.0+, visionOS 26.0+, watchOS 27.0+.
- If you use tool calling, a `Transcript` includes a history of tool calls and their results (`Transcript.Entry.toolCalls(_:)` and `.toolOutput(_:)`).
- `Transcript.Instructions.toolDefinitions` lists the tools made available to the model.
