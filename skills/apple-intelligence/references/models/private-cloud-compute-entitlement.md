# com.apple.developer.private-cloud-compute

A Boolean value that indicates whether the app can use Private Cloud Compute.

## Signature / Usage

```xml
<key>com.apple.developer.private-cloud-compute</key>
<true/>
```

## Notes

- Availability: iOS 27.0+, iPadOS 27.0+, macOS 27.0+, visionOS 27.0+, watchOS 27.0+.
- Type: Boolean property list key (managed entitlement).
- To develop with PCC you must meet certain eligibility requirements. To request access to the managed entitlement, see "Accessing Private Cloud Compute" (https://developer.apple.com/private-cloud-compute/).
- The XML snippet above is the standard entitlements plist form of the documented key; the official page itself contains no code listing.
