# SystemLanguageModel.Variant

The variant of an on-device model.

## Signature / Usage

```swift
struct Variant
```

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| core3 | static property | AFM 3 Core. |
| coreAdvanced3 | static property | AFM 3 Core Advanced. |
| displayName | property | The user-facing name of the variant. |

## Notes

- Availability: iOS 27.0+, iPadOS 27.0+, Mac Catalyst 27.0+, macOS 27.0+, visionOS 27.0+.
- Read the variant backing an instance through `SystemLanguageModel.variant`.
