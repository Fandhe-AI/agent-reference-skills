# SystemLanguageModel.Guardrails

A set of controls that flag sensitive content from model input and output.

## Signature / Usage

```swift
struct Guardrails
```

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| default | static property | Guardrails that default to ensuring that the system blocks unsafe content in prompts and responses. |
| permissiveContentTransformations | static property | Guardrails that allow for permissively transforming text input, including potentially unsafe content, to text responses. |
| LanguageModelError.guardrailViolation(_:) | error case | The model's safety guardrails were triggered by content in a prompt or the response generated by the model. |

## Notes

- Availability: iOS 26.0+, iPadOS 26.0+, Mac Catalyst 26.0+, macOS 26.0+, visionOS 26.0+.
- Distance: these are the on-device Foundation Models guardrails passed to `SystemLanguageModel.init(useCase:guardrails:)`. Cloud API guardrails, tool calling and structured outputs are covered by the openai-agents, openai-api-core and anthropic-api-tools-mcp skills.
