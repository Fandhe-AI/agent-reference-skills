# LanguageModelSession.Usage

Information about how many tokens were used by a response.

## Signature / Usage

```swift
struct Usage
```

```swift
var usage: LanguageModelSession.Usage
```

The second declaration is `LanguageModelSession.usage`: the total accumulated usage across all responses generated by the session.

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| init(input:output:metadata:) | initializer | Creates a usage value with the given token counts. |
| input | `LanguageModelSession.Usage.Input` | The input token counts from the transcript. |
| output | `LanguageModelSession.Usage.Output` | The output token counts from the response. |
| metadata | `[String : GeneratedContent]` | Additional usage statistics that the language model encodes for the response. |
| totalTokenCount | `Int` | The total number of tokens involved in this generation, combining input and output counts. |

`LanguageModelSession.Usage.Input` holds token counts for the transcript submitted to the model; `LanguageModelSession.Usage.Output` holds token counts for the output produced by the model.

## Notes

- Availability: iOS 27.0+, iPadOS 27.0+, Mac Catalyst 27.0+, macOS 27.0+, visionOS 27.0+, watchOS 27.0+.
