# LanguageModelSession

An object that represents a session that interacts with a language model.

## Signature / Usage

```swift
final class LanguageModelSession
```

```swift
let session = LanguageModelSession(instructions: """
    You are a motivational workout coach that provides quotes to inspire \
    and motivate athletes.
    """
)
let prompt = "Generate a motivational quote for my next workout."
let response = try await session.respond(to: prompt)
```

## Notes

- Availability: iOS 26.0+, iPadOS 26.0+, Mac Catalyst 26.0+, macOS 26.0+, visionOS 26.0+, watchOS 27.0+.
- A session is a single context that maintains state between requests. You can reuse the existing instance or create a new one each time you call the model.
- The framework records each call to the model in a `Transcript` that includes all prompts and responses. If the session exceeds the available context size, it throws `LanguageModelError.contextSizeExceeded(_:)`.
- Use Instruments to analyze token consumption and to look for optimizations such as `prewarm(promptPrefix:)`.
- Distance: this page covers Apple's Foundation Models framework itself. Third-party `LanguageModel` conformances such as `ClaudeLanguageModel` are documented in the anthropic-models-sdks skill.
