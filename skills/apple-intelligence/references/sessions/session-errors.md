# LanguageModelSession.Error / GenerationError

A failure caused by incorrect use of a language model session, and the deprecated iOS 26 error enum it replaces.

## Signature / Usage

### LanguageModelSession.Error

```swift
enum Error
```

```swift
do {
    let response = try await session.respond(to: prompt)
} catch {
    if #available(iOS 27.0, macOS 27.0, visionOS 27.0, *),
        let error = error as? LanguageModelSession.Error
    {
        // Handle the error.
    } else if case .concurrentRequests = error as? LanguageModelSession.GenerationError {
        // Handle the deprecated error.
    }
}
```

### LanguageModelSession.GenerationError (deprecated)

```swift
enum GenerationError
```

## Options / Props

### LanguageModelSession.Error

| Case | Description |
|------|-------------|
| `concurrentRequests` | The session received multiple concurrent requests. |
| `transcriptMutationWhileResponding` | A request mutated the session's transcript while it was in progress. |

### LanguageModelSession.GenerationError (all cases deprecated)

| Case | Description |
|------|-------------|
| `assetsUnavailable(_:)` | The assets required for the session are unavailable. |
| `decodingFailure(_:)` | The session failed to deserialize a valid generable type from model output. |
| `exceededContextWindowSize(_:)` | The session reached its context window size limit. |
| `guardrailViolation(_:)` | The system's safety guardrails are triggered by content in a prompt or the response generated by the model. |
| `rateLimited(_:)` | Your session has been rate limited. |
| `refusal(_:_:)` | The model refused to answer. |
| `concurrentRequests(_:)` | You attempt to make a session respond to a second prompt while it's still responding to the first one. |
| `unsupportedGuide(_:)` | A generation guide with an unsupported pattern was used. |
| `unsupportedLanguageOrLocale(_:)` | The model is prompted to respond in a language that it does not support. |

Other members: `Context` (the context in which the error occurred), `Refusal` (a refusal produced by a language model), `errorDescription`, `failureReason`, `recoverySuggestion`, and `LocalizedError` implementations.

## Notes

- Availability: `LanguageModelSession.Error` is iOS 27.0+, iPadOS 27.0+, Mac Catalyst 27.0+, macOS 27.0+, visionOS 27.0+, watchOS 27.0+. `LanguageModelSession.GenerationError` is iOS 26.0+, iPadOS 26.0+, Mac Catalyst 26.0+, macOS 26.0+, visionOS 26.0+ (no watchOS listed).
- If your app deploys to iOS 26, macOS 26, or visionOS 26, where `LanguageModelSession.Error` is unavailable, use an availability check and fall back to `LanguageModelSession.GenerationError`.
- Deprecated: when your app is built against Xcode 27 or later, the framework throws `LanguageModelError`, `SystemLanguageModel.Error`, or `LanguageModelSession.Error` instead of `GenerationError`. Apps built against Xcode 26 continue to receive `LanguageModelSession.GenerationError`.
