# Files API

Upload, inspect, list and delete media files (audio, images, video, documents and other supported types) for use in Gemini requests. The basic operations are the same for every file type.

## Signature / Usage

Upload a file and use it in `interactions.create` (Python):

```python
from google import genai

client = genai.Client()

myfile = client.files.upload(file="path/to/sample.mp3")

interaction = client.interactions.create(
    model="gemini-3.8-flash",
    input=[
        {"type": "text", "text": "Describe this audio clip"},
        {"type": "audio", "uri": myfile.uri, "mime_type": myfile.mime_type}
    ]
)

print(interaction.output_text)
```

JavaScript:

```javascript
import { GoogleGenAI } from "@google/genai";

const client = new GoogleGenAI({});

async function main() {
  const myfile = await client.files.upload({
    file: "path/to/sample.mp3",
    config: { mimeType: "audio/mpeg" },
  });

  const interaction = await client.interactions.create({
    model: "gemini-3.8-flash",
    input: [
      { type: "text", text: "Describe this audio clip" },
      { type: "audio", uri: myfile.uri, mime_type: myfile.mimeType }
    ]
  });
  console.log(interaction.output_text);
}

await main();
```

REST (resumable upload, then use the URI):

```bash
BASE_URL="https://generativelanguage.googleapis.com"
AUDIO_PATH="path/to/sample.mp3"
MIME_TYPE=$(file -b --mime-type "${AUDIO_PATH}")
NUM_BYTES=$(wc -c < "${AUDIO_PATH}")
DISPLAY_NAME=AUDIO

tmp_header_file=upload-header.tmp

# Initial resumable request defining metadata.
# The upload url is in the response headers dump them to a file.
curl "${BASE_URL}/upload/v1beta/files" \
  -H "x-goog-api-key: ${GEMINI_API_KEY}" \
  -D "${tmp_header_file}" \
  -H "X-Goog-Upload-Protocol: resumable" \
  -H "X-Goog-Upload-Command: start" \
  -H "X-Goog-Upload-Header-Content-Length: ${NUM_BYTES}" \
  -H "X-Goog-Upload-Header-Content-Type: ${MIME_TYPE}" \
  -H "Content-Type: application/json" \
  -d "{'file': {'display_name': '${DISPLAY_NAME}'}}" 2> /dev/null

upload_url=$(grep -i "x-goog-upload-url: " "${tmp_header_file}" | cut -d" " -f2 | tr -d "\r")
rm "${tmp_header_file}"

# Upload the actual bytes.
curl "${upload_url}" \
  -H "Content-Length: ${NUM_BYTES}" \
  -H "X-Goog-Upload-Offset: 0" \
  -H "X-Goog-Upload-Command: upload, finalize" \
  --data-binary "@${AUDIO_PATH}" 2> /dev/null > file_info.json

file_uri=$(jq -r ".file.uri" file_info.json)
echo "file_uri=${file_uri}"
```

Get metadata / list / delete (Python):

```python
myfile = client.files.upload(file='path/to/sample.mp3')
file_name = myfile.name
myfile = client.files.get(name=file_name)
print(myfile)

print('My files:')
for f in client.files.list():
    print(' ', f.name)

client.files.delete(name=myfile.name)
```

JavaScript list / delete:

```javascript
import { GoogleGenAI } from "@google/genai";

const client = new GoogleGenAI({});
const myfile = await client.files.upload({
  file: "path/to/sample.mp3",
  config: { mimeType: "audio/mpeg" },
});
const fileName = myfile.name;

const listResponse = await client.files.list({ config: { pageSize: 10 } });
for await (const file of listResponse) {
  console.log(file.name);
}

await client.files.delete({ name: fileName });
```

REST get / list / delete:

```bash
name=$(jq -r ".file.name" file_info.json)

# get
curl "https://generativelanguage.googleapis.com/v1beta/${name}" \
  -H "x-goog-api-key: ${GEMINI_API_KEY}" > file_info.json

# list
curl "https://generativelanguage.googleapis.com/v1beta/files" \
  -H "x-goog-api-key: ${GEMINI_API_KEY}"

# delete
curl --request "DELETE" "https://generativelanguage.googleapis.com/v1beta/${name}" \
  -H "x-goog-api-key: ${GEMINI_API_KEY}"
```

## Options / Props

| Operation | Python | JavaScript | REST |
|-----------|--------|------------|------|
| Upload | `client.files.upload(file=...)` | `client.files.upload({file, config})` | `POST {BASE_URL}/upload/v1beta/files` (resumable) |
| Get metadata | `client.files.get(name=...)` | `client.files.get({name})` | `GET /v1beta/{name}` |
| List | `client.files.list()` | `client.files.list({config:{pageSize}})` | `GET /v1beta/files` |
| Delete | `client.files.delete(name=...)` | `client.files.delete({name})` | `DELETE /v1beta/{name}` |

## Notes

- Always use the Files API when the total request size (files, text prompt, system instructions, etc.) is larger than 100 MB; for PDF files the limit is 50 MB.
- Usage information: store up to 20 GB of files per project, with a per-file maximum size of 2 GB. Files are stored for 48 hours (automatically deleted; manual delete also possible). You can get metadata during that time but cannot download user-uploaded files; files generated by models, such as videos, can be downloaded with `files.download`. The Files API is available at no cost in all regions where the Gemini API is available.
- File prompting strategies (section "File prompting strategies" on the page): be specific in your instructions; add a few examples (few-shot); break it down step-by-step; specify the output format (Markdown, JSON, HTML); put your image first for single-image prompts; troubleshoot multimodal prompts (point out which part of the image to use, ask the model to describe the image before reasoning, ask it to explain its reasoning, to find which part of the prompt failed).
- The source REST upload example references `${BASE_URL}` without defining it; this page defines `BASE_URL`, uses `jq -r`, and quotes variable expansions. The REST get/delete examples define `name` from `file_info.json` as on the source page's get section.
- The source JS upload example passes `config.mime_type`; other official examples and the JS SDK upload config use camelCase `config.mimeType`, which this page follows (the `mime_type` field inside `input[]` items stays snake_case).
- The Files API prompting guide recommends putting the image first for single-image prompts; image-understanding.md recommends the text prompt before the image (the source pages disagree).
- Page also has Java and Go examples; not reproduced here.
- API availability: Files API is part of the v1beta REST surface used by both Interactions API and generateContent calls; this page's examples use the Interactions API. Docs fetched 2026-10-16.
