# Code execution

The code execution tool lets the model generate and run Python code and learn iteratively from the results until it reaches a final output. Gemini can only execute Python; it can generate code in other languages but cannot run it with this tool.

## Signature / Usage

```python
from google import genai

client = genai.Client()

interaction = client.interactions.create(
    model="gemini-3.8-flash",
    input="What is the sum of the first 50 prime numbers? "
          "Generate and run code for the calculation, and make sure you get all 50.",
    tools=[{"type": "code_execution"}]
)

for step in interaction.steps:
    if step.type == "model_output":
        for content_block in step.content:
            if content_block.type == "text":
                print(content_block.text)
    elif step.type == "code_execution_call":
        print(step.arguments.code)
    elif step.type == "code_execution_result":
        print(step.result)
```

```javascript
import { GoogleGenAI } from "@google/genai";

const client = new GoogleGenAI({});

const interaction = await client.interactions.create({
    model: "gemini-3.8-flash",
    input: "What is the sum of the first 50 prime numbers? " +
           "Generate and run code for the calculation, and make sure you get all 50.",
    tools: [{ type: "code_execution" }]
});

for (const step of interaction.steps) {
    if (step.type === "model_output") {
        for (const contentBlock of step.content) {
            if (contentBlock.type === "text") {
                console.log(contentBlock.text);
            }
        }
    } else if (step.type === "code_execution_call") {
        console.log(step.arguments.code);
    } else if (step.type === "code_execution_result") {
        console.log(step.result);
    }
}
```

Code execution with images (enable Code Execution as a tool and Thinking):

```python
import requests
import base64

image_path = "https://goo.gle/instrument-img"
image_bytes = requests.get(image_path).content

interaction = client.interactions.create(
    model="gemini-3.8-flash",
    input=[
        {"type": "image", "data": base64.b64encode(image_bytes).decode('utf-8'), "mime_type": "image/jpeg"},
        {"type": "text", "text": "Zoom into the expression pedals and tell me how many pedals are there?"}
    ],
    tools=[{"type": "code_execution"}]
)
```

Multi-turn with `previous_interaction_id`:

```python
interaction1 = client.interactions.create(
    model="gemini-3.8-flash",
    input="I have a math question for you.",
    tools=[{"type": "code_execution"}]
)

interaction2 = client.interactions.create(
    model="gemini-3.8-flash",
    previous_interaction_id=interaction1.id,
    input="What is the sum of the first 50 prime numbers? "
          "Generate and run code for the calculation, and make sure you get all 50.",
    tools=[{"type": "code_execution"}]
)
```

## Options / Props

Response parts when using code execution:

| Name | Type | Description |
|------|------|-------------|
| `text` | content | Inline text generated by the model |
| `code_execution_call` | step | Code generated by the model that is meant to be executed (`step.arguments.code`) |
| `code_execution_result` | step | Result of the executable code (`step.result`) |

Code execution I/O details:

| Item | Detail |
|------|--------|
| Maximum runtime | 30 seconds |
| Error retries | If the environment errors, the model may regenerate the code, up to 5 times |
| Input file size | Limited by the model token window; exceeding the context window returns an error |
| File types | Works best with text and CSV files; input as inline data or via the Files API; output file always returned as inline data |
| Graphs | Only `matplotlib` is supported for graph rendering |

Supported libraries (you cannot install your own): attrs, chess, contourpy, fpdf, geopandas, imageio, jinja2, joblib, jsonschema, jsonschema-specifications, lxml, matplotlib, mpmath, numpy, opencv-python, openpyxl, packaging, pandas, pillow, protobuf, pylatex, pyparsing, PyPDF2, python-dateutil, python-docx, python-pptx, reportlab, scikit-learn, scipy, seaborn, six, striprtf, sympy, tabulate, tensorflow, toolz, xlrd.

## Notes

- Code Execution with images is officially supported in Gemini 3 Flash: the model can zoom/inspect, do visual math, and annotate images. It zooms automatically for small details; prompt it explicitly for other tasks (e.g. "Write code to count the number of gears").
- Billing: no additional charge for enabling code execution; billed at the model's input/output token rates. The original prompt, generated code, and executed result are intermediate tokens billed as input tokens; the final summary, generated code, and result returned to you are billed as output tokens. With I/O, output tokens include generated code, execution output, thinking tokens, and summary. The API response includes an intermediate token count.
- Limitations: the model can only generate and execute code, not return other artifacts like media files; enabling code execution can regress other output (e.g. writing a story); success varies across models.
- Can be combined with Grounding with Google Search; Gemini 3 models support combining built-in tools with function calling. Code Execution is server-side with its own context circulation (`code_execution_call` and `code_execution_result` steps) in tool combination.
- The tool-combination source table names the call step `code_execution`; the schema step type is `code_execution_call`.
- API surface: Interactions API; generateContent version is under `generate-content/` (grounding-tools). Docs fetched 2026-10-16.
