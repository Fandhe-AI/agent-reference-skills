# Available regions

Lists the countries and territories where the Gemini API and Google AI Studio are available, and the reasons access may be refused.

## Signature / Usage

Check which region a Colab instance is in (region restrictions apply to the Colab instance, not the user):

```text
!curl ipinfo.io
```

Alphabetical excerpt of the supported list (verbatim; the page lists 230 entries from Albania to Åland Islands):

```text
- Albania
- Algeria
- American Samoa
- Andorra
- Angola
- ...
- Japan
- ...
- United Kingdom
- United States
- ...
- Zambia
- Zimbabwe
- Åland Islands
```

## Notes

- Reasons you may reach this page: regional restrictions, age requirement (18+), or an unverified age on your Google Account.
- If you are not in a listed country or territory, the page suggests the Gemini API in Gemini Enterprise Agent Platform (Google Cloud side, out of scope for this skill).
- Full country list: see the source page; it is not reproduced here.
- Docs fetched 2026-10-16.
