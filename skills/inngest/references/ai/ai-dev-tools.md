# AI Development Tools

Hub page linking the resources for using Inngest with AI coding agents: Dev Server MCP, agent plugins/skills, CLI workflows, and LLM-ready documentation (llms.txt / llms-full.txt).

## Notes

- **Agent skills and plugins** teach a coding agent how to build with Inngest APIs and current patterns.
- **Dev Server MCP** lets an agent interact with a running local app — send events, invoke functions, inspect run status.
- **CLI for coding agents** gives a terminal-first way to start local services and debug function runs from an agent session.
- **LLM docs**: [inngest.com/llms.txt](https://www.inngest.com/llms.txt) is a table of contents for small context windows; [inngest.com/llms-full.txt](https://www.inngest.com/llms-full.txt) is the full docs corpus in markdown.
- Recommended loop: install the agent plugin/skills for the coding tool, start the Inngest Dev Server, and connect the tool to the Dev Server MCP endpoint.
