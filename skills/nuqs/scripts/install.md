# Install

nuqs パッケージのインストールコマンド集。

## npm でのインストール

```sh
npm install nuqs
```

## pnpm でのインストール

```sh
pnpm add nuqs
```

## yarn でのインストール

```sh
yarn add nuqs
```

## bun でのインストール

```sh
bun add nuqs
```

## 対応フレームワークとバージョン（nuqs@^2）

| フレームワーク | 対応バージョン |
| --- | --- |
| Next.js（app / pages routers） | `next@>=14.2.0` |
| React SPA | `react@^18.3 \|\| ^19` |
| Remix | `@remix-run/react@^2` |
| React Router v6 | `react-router-dom@^6` |
| React Router v7 | `react-router@^7` |
| React Router v8 | `react-router@^8` |
| TanStack Router | `@tanstack/react-router@^1` |

## 旧バージョン（nuqs v1）のインストール

Next.js の古いバージョンを使用する場合は v1 系を指定する。

```sh
npm install nuqs@^1
```

```sh
pnpm add nuqs@^1
```
