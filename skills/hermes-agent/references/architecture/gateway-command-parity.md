# Gateway Command Parity

What each local client (classic CLI, Ink TUI, Desktop, ACP) does with every slash command on the shared gateway: run client-side against a canonical verb, or send to the owner as `slash.exec`.

## Signature / Usage

Adapted (not in the official docs): three rows excerpted verbatim from the generated table, placed in a fence.

```text
| Command | Gateway (`slash.exec`) | Classic CLI | Ink | Desktop | ACP | Notes |
| `/yolo` | control | HermesCLI._toggle_yolo | config.set | action: yolo | slash.exec | per-session setting (gateway handler) |
| `/model` | refused | HermesCLI._handle_model_switch | canonical route | picker: model | session.mutate model |  |
| `/diff` | read | HermesCLI._handle_diff_command | slash.exec | slash.exec | slash.exec |  |
```

## Options / Props

Gateway (`slash.exec`) column, 105 registry commands (29 control, 19 read, 57 refused); `gateway/session_commands.py` runs only the reviewed reads and refuses the rest (`unsupported_command`):

| Value | Meaning |
|---|---|
| `read` | The real handler runs for a local session (`tests/gateway/test_session_read_commands.py`) |
| `control` | Admission-fenced write; `/approve` / `/deny` resolve the session's waiting approval (`tests/gateway/test_session_approval_commands.py`) |
| `refused` | Not available through `slash.exec` |

`read`: `/bundles`, `/commands`, `/context`, `/cron` (bare / `list`), `/diff`, `/help`, `/insights`, `/kanban` (list/show/stats/assignees/context/runs/log/diagnostics), `/memory` (bare / `pending`), `/platforms`, `/profile`, `/skills` (bare/`pending`/`diff`), `/status`, `/suggestions` (bare only), `/toolsets`, `/topup`, `/usage` (bare only), `/version`, `/whoami`.

`control`: `/approvals`, `/approve`, `/autoprune`, `/blueprint`, `/busy`, `/codex-runtime`, `/curator`, `/debug`, `/deny`, `/egress`, `/fast`, `/footer`, `/goal`, `/heartbeat`, `/init`, `/learn`, `/login`, `/loop`, `/moa`, `/personality`, `/plan`, `/reasoning`, `/refine`, `/review`, `/subgoal`, `/title`, `/verbose`, `/voice` (`tts` refused), `/yolo`.

Notes column values: `per-session setting (gateway handler)` (the messaging handler applies the setting to this local session, saving `config.yaml` only where the handler does), `client-local (cli_only)` (terminal/UI features of a client), `messaging-only` (`/approve`, `/commands`, `/deny`, `/pause`, `/platform`, `/restart`, `/sethome`, `/start`, `/topic`).

Canonical verbs in the ACP column (clients run these instead of `slash.exec`): `/model` (`session.mutate model`), `/new` / `/reset` and `/clear` (`session.mutate reset`), `/compress` (`session.mutate compress`), `/title` (`session.mutate rename`), `/undo` / `/retry` (`session.mutate rewind`), `/steer` (`session.steer`), `/queue` (`prompt.submit`), `/discard` (`prompt.resolve_unknown`, also Ink), `/branch` (`ACP fork_session`).

## Notes

- The classic CLI (`hermes chat`) is main's `HermesCLI` with a gateway-backed agent and session store (`hermes_cli/gateway_agent.py`, `gateway_session_store.py`); its column names the handler it runs in-process. The `--stream-json` / safe-mode transport client keeps its own narrower routes (`hermes_cli/gateway_chat_commands.py`).
- The official page is generated by `scripts/gen_gateway_command_parity.py` (DO NOT EDIT); this page condenses the per-client columns. Per-command Classic CLI / Ink / Desktop / ACP routes are in the official table.
- Adapted from the official docs: the Signature / Usage snippet is a verbatim three-row excerpt of the generated table placed in a fence (the page itself has no code block).
