# Configuration

| Name | Description | Path |
|------|-------------|------|
| Configuration | Hermes agent configuration reference. Settings are stored in `~/.hermes/` and can be managed via the `hermes config` commands. | [configuration.md](./configuration.md) |
| Configuring Models | Hermes uses a main model slot (the agent's reasoning) and auxiliary model slots (side-jobs such as compression, vision, approval). | [configuring-models.md](./configuring-models.md) |
| Managed Scope | Managed scope lets an administrator push a baseline of configuration and secrets that a standard (non-root) user cannot override, via a system-level directory (default `/etc/hermes`). | [managed-scope.md](./managed-scope.md) |
