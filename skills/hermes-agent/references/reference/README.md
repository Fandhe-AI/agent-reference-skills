|------|-------------|------|

| Environment Variables | Complete reference of environment variables read by Hermes Agent. | [environment-variables.md](./environment-variables.md) |

| Skills Hub | The Skills Hub is the catalog and management interface for Hermes Agent skills — reusable procedure files that extend the agent's capabilities for specialized tasks. | [skills-hub.md](./skills-hub.md) |
| Tools Reference | Authoritative list of Hermes built-in tools, grouped by toolset. | [tools-reference.md](./tools-reference.md) |
