# Skills Hub

The Skills Hub is the catalog and management interface for Hermes Agent skills — reusable procedure files that extend the agent's capabilities for specialized tasks.

## How Skills Work

Skills store procedures — step-by-step instructions for how to do things (as opposed to Memory, which stores facts). Users discover, search, and install skills from multiple registries to customize their agent for specific workflows without starting from scratch.

Manage skills via:

```sh
hermes skills config      # enable / disable installed skills
hermes skills install     # install a skill from a registry
```

## Registry Sources

Identifiers are source-qualified:

- **official**: optional skills shipped with Hermes (`official/<category>/<skill>`, e.g. `hermes skills install official/security/1password`); not active by default.
- **skills-sh**: Vercel's public skills.sh directory.
- **well-known**: skills served from `/.well-known/skills/index.json` on a website.
- **github**: direct repo/path installs and custom taps.
- **clawhub** (`clawhub/...`), **lobehub**, **browse-sh**: community marketplaces.
- **url**: direct HTTP(S) `SKILL.md` URL.
- Built-in: bundled skills copied into `~/.hermes/skills/` on install; restore a missing one with `hermes skills reset <name> --restore`.

## Notes

- The `claude-marketplace` source was removed (v2026.8.3 release notes, the v0.20.0-era release).
- The website's per-skill "Install in Hermes" button uses `official/` and `clawhub/` prefixed targets (see the Skills feature page).
- Telegram deployments are limited to 100 commands per bot; disable unused skills via `hermes skills config` to stay within this limit.
- Skills are stored per-profile and are fully isolated between profiles.
