# Bundled Skills Catalog

Catalog of skills bundled with Hermes Agent. They are copied into `~/.hermes/skills/` on install and synced on `hermes update` (the sync respects local deletions and user edits).

## Signature / Usage

```bash
# Restore a bundled skill that is missing from your profile
hermes skills reset <name> --restore
```

## Options / Props

Skill name (path under `~/.hermes/skills/`) and description, by category.

## Notes

- A skill missing from `~/.hermes/skills/` is still shipped with Hermes; restore it with `hermes skills reset <name> --restore`.
- The catalog is generated by `website/scripts/generate-skill-docs.py`; a skill present in the repo but absent here means the catalog has not been regenerated.
- Each skill also has a dedicated page under `user-guide/skills/bundled/<category>/` on the official site; those pages are not part of this reference.
- Hermes bundled skills are Hermes Agent's own `SKILL.md` procedure files, distinct from Claude Code Agent Skills.
- Source: https://hermes-agent.nousresearch.com/docs/reference/skills-catalog (pinned to v0.23.1)

### Migration (v0.22 -> v0.23)

Migration (v0.22 -> v0.23): these v0.22 bundled skills are no longer in the bundled catalog and appear in the optional catalog instead: `opencode`, `design-md`, `gif-search`, `songsee`, `box`, `llm-wiki`, `hermes-agent-skill-authoring`, `inspecting-hermes-desktop-dom`, `node-inspect-debugger`, `python-debugpy`. `microsoft-office` (Word, PowerPoint, Excel) is new, and `docx`, `powerpoint` and `xlsx` are no longer listed. `airtable` and `notion` are no longer in this catalog.
