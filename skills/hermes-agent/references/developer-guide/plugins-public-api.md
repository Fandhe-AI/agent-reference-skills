# Public Plugin API

The Hermes modules and names a plugin may import; `hermes plugins validate` warns, without failing, on any other import of a Hermes module.

## Signature / Usage

Adapted (not in the official docs): the page is a generated table with no code; this import is taken from the Delegation Provider Plugins page and uses a module the table allows as a whole module (`agent.delegation_provider`).

```python
from agent.delegation_provider import DelegationProvider, DelegationRouteError
```

## Notes

- The page is generated by `scripts/gen_plugin_api_docs.py` from `hermes_cli/data/plugin_api.json`; the validator reads the same list (catalog rule 9: public surfaces only). This page condenses the official table (which also records where each row is documented); see the official page for the per-row "Listed from" column.
- Standard library, third-party packages, the plugin's own modules and imports under `if TYPE_CHECKING:` are never flagged.
- Adapted from the official docs: the Signature / Usage import is borrowed from the Delegation Provider Plugins page (the public API page has no code block).
- Source: https://hermes-agent.nousresearch.com/docs/developer-guide/plugins/public-api (pinned to v0.23.1)
