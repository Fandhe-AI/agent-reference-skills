# developer-guide

| Name | Description | Path |
|------|-------------|------|

| Adding Providers | How to add a first-class inference provider to Hermes: auth, model catalog, runtime resolution, CLI flows, auxiliary models, adapters, tests and docs. | [adding-providers.md](./adding-providers.md) |
| Adding Tools | How to add a built-in tool to the Hermes repository: schema, handler, registration and toolset. | [adding-tools.md](./adding-tools.md) |
| Browser Provider Plugins | Browser provider plugins register a cloud browser backend that services cloud-mode `browser_*` tool calls. | [browser-provider-plugin.md](./browser-provider-plugin.md) |
| Context Engine Plugins | Context engine plugins replace the built-in `ContextCompressor` with an alternative strategy for managing conversation context (for example a lossless knowledge-DAG engine). | [context-engine-plugin.md](./context-engine-plugin.md) |
| Creating Skills | How to create skills for Hermes Agent: SKILL.md format, frontmatter fields, guidelines, blueprints and publishing. | [creating-skills.md](./creating-skills.md) |
| Desktop Plugin SDK (@hermes/plugin-sdk) | Extend the native Hermes Desktop app (panes, pages, sidebar nav, status bar, palette commands, keybinds, themes, scoped backend namespace) with a single ESM file default-exporting a `HermesPlugin`, importing only `@hermes/plugin-sdk`, with no build step. | [desktop-plugin-sdk.md](./desktop-plugin-sdk.md) |
| Extending the CLI | Build wrapper CLIs that extend the Hermes TUI with custom widgets, keybindings and layout changes through protected extension hooks on `HermesCLI` (defined in `hermes_cli/cli_tui_mixin.py`, mixed into `HermesCLI` in `cli.py`), without overriding `run()`. | [extending-the-cli.md](./extending-the-cli.md) |
| Image Generation Provider Plugins | Image-gen provider plugins register a backend that services every `image_generate` tool call. | [image-gen-provider-plugin.md](./image-gen-provider-plugin.md) |
| Memory Provider Plugins | Memory provider plugins give Hermes persistent, cross-session knowledge beyond built-in MEMORY.md and USER.md by implementing the `MemoryProvider` ABC from `agent/memory_provider.py`. | [memory-provider-plugin.md](./memory-provider-plugin.md) |
| Model Provider Plugins | Model provider plugins declare an inference backend (OpenAI-compatible, Anthropic Messages, Codex-style Responses, Bedrock-native) that Hermes routes `AIAgent` calls through. | [model-provider-plugin.md](./model-provider-plugin.md) |
| Observer Hooks | Read-only telemetry contract for plugins (trace, metrics, audit, replay, export): event families, correlation IDs and payload safety. | [observer-hooks.md](./observer-hooks.md) |
| Plugin LLM Access | `ctx.llm` is the supported way for a plugin to make an out-of-band LLM call: chat or structured, sync or async, with host-owned credentials and a fail-closed trust gate. | [plugin-llm-access.md](./plugin-llm-access.md) |
| Application declarations | A plugin whose MCP server fronts a desktop application declares which application that is and what the server needs of it. | [plugins-application-declarations.md](./plugins-application-declarations.md) |
| Submitting to the Plugin Catalog | The plugin catalog is a human-reviewed directory of Hermes plugins; users install a catalog plugin by name at the exact commit a maintainer read. | [plugins-catalog-submission.md](./plugins-catalog-submission.md) |
| Build a Hermes Plugin | Step-by-step guide to building a Hermes plugin with tools, hooks, slash commands, data files and bundled skills. | [plugins.md](./plugins.md) |
| Programmatic Integration | Three protocols for driving hermes-agent from external programs (IDE plugins, custom UIs, CI, embedded sub-agents): ACP, the TUI gateway JSON-RPC, and the OpenAI-compatible HTTP API server. | [programmatic-integration.md](./programmatic-integration.md) |
| Secret Source Plugins | Secret sources resolve provider credentials from an external secret manager (vault, password manager, OS keystore, custom script) into environment variables at process startup, after `~/.hermes/.env` loads and before Hermes reads credentials. | [secret-source-plugin.md](./secret-source-plugin.md) |
| Public Subagent Lifecycle API | Plugins can launch and supervise fresh Hermes child sessions through `ctx.subagent_lifecycle` without importing `tools.delegate_tool`, gateway internals, TUI state or `AIAgent` fields. | [subagent-lifecycle-api.md](./subagent-lifecycle-api.md) |
| Terminal Environment Provider Plugins | Third-party sandbox vendors integrate terminal backends as plugins installed under `~/.hermes/plugins/`, selected like built-ins via `terminal.backend` in `config.yaml`. | [terminal-environment-plugin.md](./terminal-environment-plugin.md) |
| Video Generation Provider Plugins | Video-gen provider plugins register a backend that services every `video_generate` tool call. | [video-gen-provider-plugin.md](./video-gen-provider-plugin.md) |
| Web Search Provider Plugins | Web-search provider plugins register a backend that services `web_search`, `web_extract` and optional deep-crawl tool calls. | [web-search-provider-plugin.md](./web-search-provider-plugin.md) |
