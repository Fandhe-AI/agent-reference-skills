# Python on Google Cloud (landing)

Landing page for Python development on Google Cloud. It points to the Python development environment setup tutorial, the getting-started tutorials and the reference for the Python Google Cloud Client Libraries.

## Signature / Usage

### Install a client library for one API

```bash
pip install --upgrade google-cloud-storage
```

## Notes

- The landing page itself has no code. Snippet taken from https://docs.cloud.google.com/python/docs/setup.
- Guides listed on the landing page: "Setting up a Python development environment" (`python/docs/setup`), "Getting started" (`python/getting-started`). Reference: "Python Google Cloud Client Libraries" (`python/docs/reference`).
- The related-resources section (Cloud Skills Boost labs, use-case tutorials for IAP, sessions with Firestore and background processing on App Engine, sample repositories) is omitted.
- This is the Google Cloud client library family (`google-cloud-*` packages), distinct from the `google-genai` Gemini SDK (the `google-gemini-api` skill).
- Applies to Python >= 3.10 (the floor of google-api-core 2.44.0 and google-cloud-core 2.8.0; see `supported-python-versions.md`).
