# ClientInfo and the user agent

`google.api_core.client_info.ClientInfo` holds information about the calling client, such as the library and Python version, used to generate a user-agent for API calls. The receiving service uses it for analytics on which versions of Python and Google libraries are in use.

## Signature / Usage

### Signature

```python
class ClientInfo(object):
    def __init__(
        self,

        gapic_version=None,
        client_library_version=None,
        user_agent=None,
        rest_version=None,
        protobuf_runtime_version=None,
    ): ...

```

## Options / Props

| Name | Type | Description |
| --- | --- | --- |
| `python_version` | `str` | Python interpreter version, e.g. `'3.10.0'` (default from module code, see Notes: the running interpreter) |
| `grpc_version` | `Optional[str]` | gRPC library version (default from module code, see Notes: `grpc.__version__` if importable, else `None`) |
| `api_core_version` | `str` | google-api-core library version |
| `gapic_version` | `Optional[str]` | Version of the gapic-generated client library, if generated by gapic |
| `client_library_version` | `Optional[str]` | Version of the client library; generally used if not generated by gapic or if extra functionality is built on a gapic library |
| `user_agent` | `Optional[str]` | Prefix to the user agent header, for application name or partner tool. Recommended format: `application-or-tool-ID/major.minor.version` |
| `rest_version` | `Optional[str]` | String with labeled versions of the dependencies used for REST transport |
| `protobuf_runtime_version` | `Optional[str]` | The protobuf runtime version |

## Notes

- `to_user_agent()` returns the string built in this order (items omitted when `None`): `{user_agent}` prefix, `gl-python/{python_version}`, `grpc/{grpc_version}`, `rest/{rest_version}`, `gax/{api_core_version}`, `gapic/{gapic_version}`, `gccl/{client_library_version}`, `pb/{protobuf_runtime_version}`. A comment in the source says "the order here is important as the internal metrics system expects these items to be in specific locations".
- Use the `user_agent` field for application or partner tool identification; the recommended format is in the table.
- No usage example exists in the docstring; this page shows only the public signature. Snippet taken from https://github.com/googleapis/google-cloud-python/blob/google-api-core-v2.44.0/packages/google-api-core/google/api_core/client_info.py. How a given client accepts a `ClientInfo` is not stated in this source file. The user-agent order (with its source comment) is from the function body of `to_user_agent` in `client_info.py`, and the `python_version` / `grpc_version` defaults (`platform.python_version()`, `grpc.__version__` or `None`) are from the module-level code of `client_info.py`; neither is documented in the docstring.
- Applies to google-api-core 2.44.0.
