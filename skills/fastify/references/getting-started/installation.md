# Installation

Install Fastify via npm or yarn to start building a server.

## Signature / Usage

```sh
npm i fastify
```

```sh
yarn add fastify
```

## Notes

- Target version for this skill: v5.12.1
- If using ECMAScript Modules (ESM), add `"type": "module"` to `package.json`:

  ```json
  {
    "type": "module"
  }
  ```
