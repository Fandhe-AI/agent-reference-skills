# Framework guides

Framework-specific guides that cover the recommended approach to installing Tailwind CSS in a number of popular environments.

## Signature / Usage

Each guide lives at `https://tailwindcss.com/docs/installation/framework-guides/<slug>`.

```text
/docs/installation/framework-guides/nextjs
```

## Notes

- Don't see your framework of choice? Try using the Tailwind CLI, the Vite plugin, or the PostCSS plugin instead.
- Framework APIs live in the nextjs-app / react-router / tanstack-start skills; this page covers only Tailwind setup. The nextjs-app skill's `guides/tailwind-v3-css.md` covers v3, not v4.
- Per-framework step lists are curated in this skill's samples, not duplicated here.
