# System prompts (claude.ai release notes)

Release notes for the core system prompts used by [claude.ai](https://claude.ai) and the Claude iOS/Android apps. These updates apply only to Claude's consumer surfaces and do **not** apply to the Claude API.

## Signature / Usage

```text
Latest entries:
  Claude Haiku 5.5  — October 7, 2026 (knowledge cutoff: the end of June 2026)
  Claude Sonnet 5.5 — October 7, 2026 (previous entry: September 28, 2026; cutoff: end of Jun 2026)
  Claude Opus 5.5   — September 22, 2026 (cutoff: end of Jun 2026)
  Claude Fable 5.1  — September 1, 2026 (cutoff: end of Jun 2026)

Per-model pages: https://platform.claude.com/docs/en/release-notes/system-prompts/claude-<model>
  e.g. /claude-haiku-5-5, /claude-sonnet-5-5, /claude-opus-5-5, /claude-fable-5-1

Covers: product information, refusal handling, child safety instructions,
tone and formatting guidelines, user wellbeing considerations, and the
model's knowledge cutoff.
```

## Notes

- The system prompt is periodically updated to improve Claude's responses; it injects context such as the current date at the start of every conversation and encourages behaviors like formatting code snippets in Markdown.
- The release notes are split into one page per model (the overview page is a card index). Some models have multiple dated entries on their pages.
- Entries by model, in the order of the overview cards (dates are the entry headings on each per-model page):
  - Claude Haiku 5.5 — October 7, 2026
  - Claude Sonnet 5.5 — October 7, 2026 and September 28, 2026
  - Claude Opus 5.5 — September 22, 2026
  - Claude Fable 5.1 — September 1, 2026 (knowledge cutoff: end of Jun 2026)
  - Claude Opus 5 — July 24, 2026 (knowledge cutoff: end of May 2026)
  - Claude Sonnet 5 — June 30, 2026 (knowledge cutoff: end of Jan 2026)
  - Claude Fable 5 — June 9, 2026 (knowledge cutoff: end of Jan 2026)
  - Claude Opus 4.8 — May 28, 2026 (knowledge cutoff: end of Jan 2026)
  - Claude Opus 4.7 — April 16, 2026
  - Claude Sonnet 4.6 — October 7, 2026 and February 17, 2026

  - Claude Opus 4.5 — January 18, 2026 and November 24, 2025

  - Older cards on the overview: Claude Opus 4.1, Claude Opus 4, Claude Sonnet 4, Claude Sonnet 3.7, Claude Sonnet 3.5, Claude Haiku 3.5, Claude Opus 3, Claude Haiku 3.
