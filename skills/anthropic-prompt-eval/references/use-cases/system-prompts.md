# System prompts (claude.ai release notes)

Release notes for the core system prompt used by [claude.ai](https://claude.ai) and the Claude iOS/Android apps. These updates apply only to Claude's consumer surfaces and do **not** apply to the Claude API.

## Signature / Usage

```text
Latest entry: Claude Opus 5 — July 24, 2026

Covers: product information, refusal handling, child safety instructions,
tone and formatting guidelines, user wellbeing considerations, and the
model's knowledge cutoff (end of May 2026 for Claude Opus 5).
```

## Notes

- The system prompt is periodically updated to improve Claude's responses; it injects context such as the current date at the start of every conversation and encourages behaviors like formatting code snippets in Markdown.
- Starting with the Claude 4.6 generation, each model ID is a single fixed snapshot (see [model IDs and versions](https://platform.claude.com/docs/en/about-claude/models/model-ids-and-versions)), so those models have one release-notes entry each; earlier models may have multiple dated entries with updates between versions called out.
- Full verbatim system prompt text could not be retrieved for this reference (the page is long and the fetched content only summarized each entry). For the exact current wording, always read the live page directly: https://platform.claude.com/docs/en/release-notes/system-prompts
- Prior entries as of last verification (see the live page for full text of each): Claude Fable 5 (June 9, 2026), Claude Opus 4.8 (May 28, 2026), Claude Opus 4.7 (April 16, 2026), Claude Sonnet 4.6 (February 17, 2026).
