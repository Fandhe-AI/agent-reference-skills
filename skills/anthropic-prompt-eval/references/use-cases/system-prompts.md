# System prompts (claude.ai release notes)

Release notes for the core system prompts used by [claude.ai](https://claude.ai) and the Claude iOS/Android apps. These updates apply only to Claude's consumer surfaces and do **not** apply to the Claude API.

## Signature / Usage

```text
Latest entries:
  Claude Fable 5.2  — November 9, 2026 (cutoff: end of June 2026)
  Claude Fable 5.1  — October 30, 2026 (also Opus 5, Sonnet 5, Fable 5, Opus 4.8 / 4.7 / 4.6 on this date)
  Claude Sonnet 5.5 — October 27, 2026 (also Opus 5.5)
  Claude Haiku 5.5  — October 26, 2026

Per-model pages: https://platform.claude.com/docs/en/release-notes/system-prompts/claude-<model>
  e.g. /claude-haiku-5-5, /claude-sonnet-5-5, /claude-opus-5-5, /claude-fable-5-1, /claude-fable-5-2

Covers: product information, refusal handling, child safety instructions,
tone and formatting guidelines, user wellbeing considerations, and the
model's knowledge cutoff.
```

## Notes

- The system prompt is periodically updated to improve Claude's responses; it injects context such as the current date at the start of every conversation and encourages behaviors like formatting code snippets in Markdown.
- The release notes are split into one page per model (the overview page is a card index). Some models have multiple dated entries on their pages.
- Entries by model, in the order of the overview cards (dates are the entry headings on each per-model page):
