# R2

Manage your R2 configurations using Wrangler: buckets (`r2 bucket`), objects (`r2 object`), plus the Basin Catalog and Basin SQL commands listed on this page.

## Signature / Usage

```sh
npx wrangler r2 bucket create <NAME>
npx wrangler r2 bucket info <BUCKET>
npx wrangler r2 bucket delete <BUCKET>
npx wrangler r2 bucket list
npx wrangler r2 bucket cors set <BUCKET>
npx wrangler r2 bucket cors delete <BUCKET>
npx wrangler r2 bucket cors list <BUCKET>
npx wrangler r2 bucket dev-url enable <BUCKET>
npx wrangler r2 bucket dev-url disable <BUCKET>
npx wrangler r2 bucket dev-url get <BUCKET>
npx wrangler r2 bucket domain add <BUCKET>
npx wrangler r2 bucket domain remove <BUCKET>
npx wrangler r2 bucket domain update <BUCKET>
npx wrangler r2 bucket domain get <BUCKET>
npx wrangler r2 bucket domain list <BUCKET>
npx wrangler r2 bucket lifecycle add <BUCKET> [NAME] [PREFIX]
npx wrangler r2 bucket lifecycle remove <BUCKET>
npx wrangler r2 bucket lifecycle list <BUCKET>
npx wrangler r2 bucket lifecycle set <BUCKET>
npx wrangler r2 bucket lock add <BUCKET> [NAME] [PREFIX]
npx wrangler r2 bucket lock remove <BUCKET>
npx wrangler r2 bucket lock list <BUCKET>
npx wrangler r2 bucket lock set <BUCKET>
npx wrangler r2 bucket notification create <BUCKET>
npx wrangler r2 bucket notification delete <BUCKET>
npx wrangler r2 bucket notification list <BUCKET>
npx wrangler r2 bucket sippy enable <NAME>
npx wrangler r2 bucket sippy disable <NAME>
npx wrangler r2 bucket sippy get <NAME>
npx wrangler r2 object get <OBJECTPATH>
npx wrangler r2 object put <OBJECTPATH>
npx wrangler r2 object delete <OBJECTPATH>
```

Descriptions:

- `r2 bucket create`: Create a new R2 bucket
- `r2 bucket info`: Get information about an R2 bucket
- `r2 bucket delete`: Delete an R2 bucket
- `r2 bucket list`: List R2 buckets
- `r2 bucket cors set`: Set the CORS configuration for an R2 bucket from a JSON file
- `r2 bucket cors delete`: Clear the CORS configuration for an R2 bucket
- `r2 bucket cors list`: List the CORS rules for an R2 bucket
- `r2 bucket dev-url enable`: Enable public access via the r2.dev URL for an R2 bucket
- `r2 bucket dev-url disable`: Disable public access via the r2.dev URL for an R2 bucket
- `r2 bucket dev-url get`: Get the r2.dev URL and status for an R2 bucket
- `r2 bucket domain add`: Connect a custom domain to an R2 bucket
- `r2 bucket domain remove`: Remove a custom domain from an R2 bucket
- `r2 bucket domain update`: Update settings for a custom domain connected to an R2 bucket
- `r2 bucket domain get`: Get custom domain connected to an R2 bucket
- `r2 bucket domain list`: List custom domains for an R2 bucket
- `r2 bucket lifecycle add`: Add a lifecycle rule to an R2 bucket
- `r2 bucket lifecycle remove`: Remove a lifecycle rule from an R2 bucket
- `r2 bucket lifecycle list`: List lifecycle rules for an R2 bucket
- `r2 bucket lifecycle set`: Set the lifecycle configuration for an R2 bucket from a JSON file
- `r2 bucket lock add`: Add a lock rule to an R2 bucket
- `r2 bucket lock remove`: Remove a bucket lock rule from an R2 bucket
- `r2 bucket lock list`: List lock rules for an R2 bucket
- `r2 bucket lock set`: Set the lock configuration for an R2 bucket from a JSON file
- `r2 bucket notification create`: Create an event notification rule for an R2 bucket
- `r2 bucket notification delete`: Delete an event notification rule from an R2 bucket
- `r2 bucket notification list`: List event notification rules for an R2 bucket
- `r2 bucket sippy enable`: Enable Sippy on an R2 bucket
- `r2 bucket sippy disable`: Disable Sippy on an R2 bucket
- `r2 bucket sippy get`: Check the status of Sippy on an R2 bucket
- `r2 object get`: Fetch an object from an R2 bucket
- `r2 object put`: Create an object in an R2 bucket
- `r2 object delete`: Delete an object in an R2 bucket

### Basin Catalog

Enable Basin Catalog on a bucket:

```sh
npx wrangler basin catalog enable <BUCKET_NAME>
```

Disable Basin Catalog on a bucket:

```sh
npx wrangler basin catalog disable <BUCKET_NAME>
```

Get the Basin Catalog status for a bucket:

```sh
npx wrangler basin catalog get <BUCKET_NAME>
```

#### `basin catalog compaction enable`

Enable catalog-level compaction with a service token:

```sh
npx wrangler basin catalog compaction enable my-bucket --token <TOKEN>
```

Enable table-level compaction:

```sh
npx wrangler basin catalog compaction enable my-bucket my-namespace my-table --target-size 256
```

#### `basin catalog compaction disable`

Disable catalog-level compaction:

```sh
npx wrangler basin catalog compaction disable my-bucket
```

Disable table-level compaction:

```sh
npx wrangler basin catalog compaction disable my-bucket my-namespace my-table
```

Enable snapshot expiration:

```sh
npx wrangler basin catalog snapshot-expiration enable <BUCKET_NAME>
```

Disable snapshot expiration:

```sh
npx wrangler basin catalog snapshot-expiration disable <BUCKET_NAME>
```

### Basin SQL

Report Basin SQL bugs in GitHub (https://github.com/cloudflare/workers-sdk/issues/new/choose). Basin SQL expects the `WRANGLER_BASIN_SQL_AUTH_TOKEN` environment variable to be set.

```sh
npx wrangler basin sql query <WAREHOUSE_NAME> "SELECT * FROM <NAMESPACE>.<TABLE> LIMIT 10"
```

For more information, refer to Basin SQL Wrangler commands (https://developers.cloudflare.com/basin-sql/reference/wrangler-commands/).

## Notes

- The `r2 bucket` and `r2 object` commands allow you to manage application data in the Cloudflare network to be accessed from Workers using the R2 Workers API (documented in the cloudflare-storage skill).
- The Basin Catalog commands show examples only on this page; no flag tables are given.
- The `basin catalog compaction enable|disable` section headings are followed by examples for both catalog-level and table-level; the `snapshot-expiration` examples appear under the `compaction disable` heading on the official page.
- Each command also accepts the global flags; see the global flags page.
