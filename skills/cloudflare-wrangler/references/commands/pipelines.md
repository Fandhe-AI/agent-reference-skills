# Basin Pipelines

Manage your Basin Pipelines resources using Wrangler. The page lists only entry-point examples and defers to the Basin Pipelines docs for the complete command list.

## Signature / Usage

```sh
npx wrangler basin pipelines setup
npx wrangler basin pipelines list
npx wrangler basin pipelines streams list
npx wrangler basin pipelines sinks list
```

## Notes

- For `get` commands in the Basin Pipelines namespace (`basin pipelines get`, `basin pipelines streams get`, and `basin pipelines sinks get`), you can pass either a resource ID or resource name.
- For the complete command list, refer to Basin Pipelines Wrangler commands (https://developers.cloudflare.com/basin-pipelines/reference/wrangler-commands/). That page is outside this reference's scope.
