# D1 (Miniflare)

Bind D1 databases with `d1Databases` and access them from outside a Worker via `getD1Database`.

## Signature / Usage

```js
const mf = new Miniflare({
	d1Databases: {
		DB: "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
	},
});
```

```js
const db = await mf.getD1Database("DB");
const stmt = await db.prepare("<Query>");
const returnValue = await stmt.run();

return Response.json(returnValue.results);
```

## Notes

- D1 product docs: https://developers.cloudflare.com/d1/
- `d1Databases` also accepts a `string[]` of binding names (see the migration page for the `Record<string, string>` form).
