# R2 (Miniflare)

Bind R2 buckets with `r2Buckets` and read or write them from outside a Worker via `getR2Bucket`.

## Signature / Usage

```js
const mf = new Miniflare({
	r2Buckets: ["BUCKET1", "BUCKET2"],
});
```

Manipulating outside Workers:

```js
import { Miniflare } from "miniflare";

const mf = new Miniflare({
	modules: true,
	script: `
  export default {
    async fetch(request, env, ctx) {
      const object = await env.BUCKET.get("count");
      const value = parseInt(await object.text()) + 1;
      await env.BUCKET.put("count", value.toString());
      return new Response(value.toString());
    }
  }
  `,
	r2Buckets: ["BUCKET"],
});

const bucket = await mf.getR2Bucket("BUCKET");
await bucket.put("count", "1");

const res = await mf.dispatchFetch("http://localhost:8787/");
console.log(await res.text()); // 2
console.log(await (await bucket.get("count")).text()); // 2
```

## Notes

- Persist with `r2Persist` (see the Reference block in Get Started).
- R2 Workers API reference: https://developers.cloudflare.com/r2/api/workers/workers-api-reference/
