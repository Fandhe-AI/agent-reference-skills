# widgets

| Name | Description | Path |
| --- | --- | --- |
| Customize the widget header area | By default the widget header shows the `DisplayName` and `Icon` declared in the app manifest's `Definition`/`ThemeResources`. A widget provider can override the header's display name, icon, or hide it entirely by adding a `header` field to the Adaptive Card JSON payload, regardless of the implementation language. | [widget-header-customization.md](./widget-header-customization.md) |
| Feed provider package manifest | XML format for registering a Win32 feed provider in the app package manifest. Feed providers declare their registration inside a `uap3:AppExtension` with `Name="com.microsoft.windows.widgets.feeds"`. | [feed-provider-manifest.md](./feed-provider-manifest.md) |
| FeedManager | Sealed class providing methods for querying enabled feed providers and setting custom query-string parameters from within a feed provider. | [feedmanager.md](./feedmanager.md) |
| IFeedProvider | Interface implemented by Windows feed providers to receive callbacks from the Widgets Board Dashboard about feed and feed-provider enablement state, and to supply custom query-string parameters (e.g. authentication tokens) for the provider's content URI. | [ifeedprovider.md](./ifeedprovider.md) |
| Implement a feed provider | Guide for implementing a Windows feed provider as a packaged Win32 app, in either C# or C++/WinRT, and packaging/testing/debugging it once deployed. A feed provider registers one or more content feeds that appear as pivots above the Widgets Board's Dashboard/Feeds section. | [implement-feed-provider.md](./implement-feed-provider.md) |
| Implement a widget provider | Guide for implementing a Windows widget provider as a packaged Win32 app, in either C# or C++/WinRT, and testing/debugging it once deployed. | [implement-widget-provider.md](./implement-widget-provider.md) |
| IWidgetProvider | Interface implemented by Windows Widget providers to receive callbacks from the widget host for widget lifetime events (create, delete, activate, deactivate, action invocation, context change). | [iwidgetprovider.md](./iwidgetprovider.md) |
| IWidgetProvider2 | Interface implemented by Windows widget providers to receive callbacks from the widget host for widget customization events. Requires Windows App SDK 1.4+. | [iwidgetprovider2.md](./iwidgetprovider2.md) |
| Web widget providers | Widget providers can populate a widget's content with HTML served from a remote URL instead of (or in addition to) the Adaptive Card body schema. The provider still sends an Adaptive Card JSON payload, so implementation otherwise follows the standard `IWidgetProvider` steps — only the payload shape and two additional interfaces differ. | [web-widget-providers.md](./web-widget-providers.md) |
| Widget provider error and analytics reporting | Optional interfaces (`IWidgetProviderErrors`, `IWidgetProviderAnalytics`) a widget provider can implement to receive callbacks from the widget host for widget errors and user-interaction analytics events. Supported by the Widgets Board starting with Windows 11, Build 26900. | [widget-provider-error-analytics-reporting.md](./widget-provider-error-analytics-reporting.md) |
| Widget provider ActivateApplication protocol | Command-line activation format used when a widget provider's manifest specifies the `ActivateApplication` activation type instead of `CreateInstance`. Each activation marshals one `IWidgetProvider` method call into a base64url-encoded JSON command-line argument. | [widget-provider-activateapplication-protocol.md](./widget-provider-activateapplication-protocol.md) |
| Widget provider package manifest | XML format for registering a Win32 widget provider in the app package manifest. Widget providers declare their registration inside a `uap3:AppExtension` with `Name="com.microsoft.windows.widgets"`. | [widget-provider-manifest.md](./widget-provider-manifest.md) |
| WidgetContext | Sealed class providing information about the configuration of a widget within the widget host (ID, definition ID, active state, size). | [widgetcontext.md](./widgetcontext.md) |
| WidgetInfo | Sealed class containing status information for a widget, including the visual template, data template, custom state, last update time, and host context. | [widgetinfo.md](./widgetinfo.md) |
| WidgetManager | Sealed class providing methods for querying, updating, and deleting widgets from within a widget provider. | [widgetmanager.md](./widgetmanager.md) |
| Widget templates (Adaptive Cards) | Windows widget UI and interaction are implemented using Adaptive Cards JSON. Each widget provides a visual template and, optionally, a data template, authored and previewed with the Adaptive Cards Designer (select **Widgets Board** as the host app). | [widgets-create-a-template.md](./widgets-create-a-template.md) |
| WidgetUpdateRequestOptions | Sealed class providing data for calls to `WidgetManager.UpdateWidget`, used to push an updated visual template, data, custom state, and rank for a widget. | [widgetupdaterequestoptions.md](./widgetupdaterequestoptions.md) |
