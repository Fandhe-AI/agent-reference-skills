# Accessibility testing

How to test Flutter app accessibility: automated scanners, the Accessibility Guideline API in `flutter_test`, and visualizing semantic nodes on the web.

## Signature / Usage

Test with Flutter's Accessibility Guideline API on a sample widget named `AccessibleApp`:

```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:your_accessible_app/main.dart';

void main() {
  testWidgets('Follows a11y guidelines', (tester) async {
    final SemanticsHandle handle = tester.ensureSemantics();
    await tester.pumpWidget(const AccessibleApp());

    // Checks that tappable nodes have a minimum size of 48 by 48 pixels
    // for Android.
    await expectLater(tester, meetsGuideline(androidTapTargetGuideline));

    // Checks that tappable nodes have a minimum size of 44 by 44 pixels
    // for iOS.
    await expectLater(tester, meetsGuideline(iOSTapTargetGuideline));

    // Checks that touch targets with a tap or long press action are labeled.
    await expectLater(tester, meetsGuideline(labeledTapTargetGuideline));

    // Checks whether semantic nodes meet the minimum text contrast levels.
    // The recommended text contrast is 3:1 for larger text
    // (18 point and above regular).
    await expectLater(tester, meetsGuideline(textContrastGuideline));
    handle.dispose();
  });
}
```

Web: visualize the semantic nodes created for your web app in profile and release modes:

```console
flutter run -d chrome --profile --dart-define=FLUTTER_WEB_DEBUG_SHOW_SEMANTICS=true
```

## Inspecting accessibility support

| Platform | Steps |
|----------|-------|
| Android | Install the Accessibility Scanner; enable it from **Android Settings > Accessibility > Accessibility Scanner > On**; tap the Accessibility Scanner 'checkbox' icon button to initiate a scan. |
| iOS | Open the `iOS` folder of your Flutter app in Xcode; select a Simulator and click **Run**; select **Xcode > Open Developer Tools > Accessibility Inspector**; select **Inspection > Enable Point to Inspect** and select UI elements to inspect attributes; select **Audit** in the toolbar, then **Run Audit** for a report of potential issues. |
| Web | Open Chrome DevTools (or similar); inspect the HTML tree under the semantics host, containing the ARIA attributes generated by Flutter; in Chrome, the "Elements" tab has an "Accessibility" sub-tab to inspect data exported to the semantics tree. |

## Notes

- To ensure accessibility, check against public standards like WCAG 2 and EN 301 549, and use resources like the VPAT to self-assess.
- The Guideline API checks recommendations for text contrast, target size, and target labels.
- To try the tests, run them on a new app created with `flutter create`; each button on that app's main screen is a tappable target with text rendered in an 18-point font.
- Guideline API tests can be added alongside other widget tests, or in a separate file such as `test/a11y_test.dart`.
- With the web flag activated, semantic nodes appear on top of the widgets; if they are incorrectly placed, the page asks you to file a bug report.
- Flutter `flutter_test` accessibility guidelines (Dart); distinct from Playwright, Vitest, and Android testing tooling in the other skills.
