Index of announcements and release notes for releases to the stable channel. For each stable release the page links the announcement, the release notes and change log, and the breaking changes and migrations.

## Notes

- Stable releases listed on the page, newest first: 3.47.0, 3.44.0, 3.41.0, 3.38.0, 3.35.0, 3.32.0, 3.29.0, 3.27.0, 3.24.0, 3.22.0, 3.19.0, 3.16.0, 3.13.0, 3.10.0, 3.7.0, 3.3.0, 3.0.0, 2.10.0, 2.8.0, 2.5.0, 2.2.0, 2.0.0, 1.22.0, 1.20.0, 1.17.0, 1.12.13, then "Earlier" (archived release notes at `/release/release-notes/release-notes-archive`).
- 2.8.0 and 1.12.13 have no "breaking changes & migrations" entry on the page.
- Bug-fix releases are not listed: use the Flutter repository changelog (`flutter/flutter` `stable` branch, `CHANGELOG.md`). Beta-channel changes: follow the "Beta channel" section of the SDK archive page (`/install/archive`).
- Release notes before 3.44 are only reachable as links from this index and are not reproduced in this skill. Only 3.47.0 is reproduced (see the 3.47.0 release notes page).
