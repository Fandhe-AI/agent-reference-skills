# Firebase

Pointer page for using Firebase (a Backend-as-a-Service platform) with Flutter, including Cloud Firestore and Firebase SQL Connect.

## Signature / Usage

Services Firebase provides, as listed on the page:

```text
cloud databases (Cloud Firestore and Firebase SQL Connect), cloud storage, authentication, crash reporting, AI features, remote configuration, and hosting for your static files
```

## Notes

- Documentation links: Getting started with Firebase and Flutter (`firebase.google.com/docs/flutter/setup`), Choose a database for your Flutter app, and Firebase plugins (`firebase.google.com/docs/flutter/setup#available-plugins`).
- Also lists a blog post on hosting a Flutter app on the web with Firebase, a "Get to know Firebase for Flutter" tutorial (codelab) and video workshop, and community blog posts and videos.
- This page is a resource index; Firebase itself is not covered here. For database selection from Flutter see the choose-a-database page. Backend platforms and ORMs with their own APIs (such as supabase or drizzle) are covered by separate skills.
