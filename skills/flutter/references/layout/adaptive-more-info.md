## Notes

- Example apps showing the adaptive and responsive concepts together: Wonderous and the Flutter adaptive demo (from the gskinnerTeam GitHub organization).
- The page notes the guidance is not exhaustive; the more operating systems, form factors, and input devices you support, the harder it is to spec every permutation, so learning basic usability principles reduces back-and-forth with design.
