# Writing and using fragment shaders

Custom shaders provide rich graphical effects beyond those in the Flutter SDK. A shader is a program authored in GLSL and executed on the user's GPU. Shaders are added to a project by listing them in `pubspec.yaml` and obtained with the `FragmentProgram` API.

## Signature / Usage

Declare `.frag` GLSL files in the `shaders` section of `pubspec.yaml`:

```yaml
flutter:
  shaders:
    - shaders/myshader.frag
```

Load and use at runtime:

```dart
void loadMyShader() async {
  var program = await FragmentProgram.fromAsset('shaders/myshader.frag');
}
```

```dart
void updateShader(Canvas canvas, Rect rect, FragmentProgram program) {
  var shader = program.fragmentShader();
  shader.setFloat(0, 42.0);
  canvas.drawRect(rect, Paint()..shader = shader);
}
```

Canvas API (`Paint.shader`):

```dart
void paint(Canvas canvas, Size size, FragmentShader shader) {
  // Draws a rectangle with the shader used as a color source.
  canvas.drawRect(
    Rect.fromLTWH(0, 0, size.width, size.height),
    Paint()..shader = shader,
  );

  // Draws a stroked rectangle with the shader only applied to the fragments
  // that lie within the stroke.
  canvas.drawRect(
    Rect.fromLTWH(0, 0, size.width, size.height),
    Paint()
      ..style = PaintingStyle.stroke
      ..shader = shader,
  )
}
```

ImageFilter API (Impeller only):

```dart
Widget build(BuildContext context, FragmentShader shader) {
  return ClipRect(
    child: SizedBox(
      width: 300,
      height: 300,
      child: BackdropFilter(
        filter: ImageFilter.shader(shader),
        child: Container(
          color: Colors.transparent,
        ),
      ),
    ),
  );
}
```

GLSL for an `ImageFilter` shader (uniforms set automatically by the engine):

```glsl
#version 460 core
#include <flutter/runtime_effect.glsl>

out vec4 fragColor;

// These uniforms are automatically set by the engine.
uniform vec2 u_size;
uniform sampler2D u_texture;

void main() {
  vec2 uv = FlutterFragCoord().xy / u_size;
#ifdef IMPELLER_TARGET_OPENGLES
  // When sampling from u_texture on OpenGLES the y-coordinates will be flipped.
  uv.y = 1.0 - uv.y;
#endif
  vec4 color = texture(u_texture, uv);
  float gray = dot(color.rgb, vec3(0.299, 0.587, 0.114));
  fragColor = vec4(vec3(gray), color.a);
}
```

Setting uniforms. Given these GLSL declarations:

```glsl
uniform float uScale;
uniform sampler2D uTexture;
uniform vec2 uMagnitude;
uniform vec4 uColor;
```

the corresponding Dart code is:

```dart
class Foobar {
  late final UniformFloatSlot _scale;
  late final List<UniformFloatSlot> _magnitude;
  late final List<UniformFloatSlot> _color;
  late final ImageSamplerSlot _texture;

  void setUp(FragmentShader shader) {
    _scale = shader.getUniformFloat('uScale');
    _magnitude = List<UniformFloatSlot>.generate(2, (int index) {
      return shader.getUniformFloat('uMagnitude', index);
    });
    _color = List<UniformFloatSlot>.generate(4, (int index) {
      return shader.getUniformFloat('uColor', index);
    });
    _texture = shader.getImageSampler('uTexture');
  }

  void update(Color color, Image image) {
    _scale.set(23);
    _magnitude[0].set(114);
    _magnitude[1].set(83);
    _color[0].set(color.r * color.a);
    _color[1].set(color.g * color.a);
    _color[2].set(color.b * color.a);
    _color[3].set(color.a);
    _texture.set(image);
  }
}
```

Current position and sampler usage in GLSL:

```glsl
#include <flutter/runtime_effect.glsl>

uniform vec2 uSize;
uniform sampler2D uTexture;

out vec4 fragColor;

void main() {
  vec2 uv = FlutterFragCoord().xy / uSize;
  fragColor = texture(uTexture, uv);
}
```

Auditing the reflection data generated by the shader compiler (uniform offsets):

```shell
cd "${FLUTTER}"
# Generate the .sl file.
"$(find bin/ -name impellerc)" \
  --runtime-stage-metal \
  --iplr \
  --input=path/to/myshader.frag \
  --sl=foo.sl \
  --spirv=foo.spirv \
  --include=engine/src/flutter/impeller/compiler/shader_lib/ \
  --input-type=frag
# Convert the .sl file to .json
flatc \
  --json \
  ./engine/src/flutter/impeller/runtime_stage/runtime_stage.fbs \
  -- ./foo.sl
# View results
cat foo.json
```

## Notes

- Both the Skia and Impeller backends support writing a custom shader; except where noted, the same instructions apply to both.
- The Flutter command-line tool compiles each shader to its backend format and generates runtime metadata; the compiled shader is included in the app like an asset. In debug mode, changes to a shader trigger recompilation and update during hot reload or hot restart. Shaders from packages are added with `packages/$pkgname` prefixed to the shader program's name.
- A `FragmentProgram` creates one or more `FragmentShader` instances; a `FragmentShader` is a fragment program plus a particular set of uniforms. `Paint.shader` works with most Canvas APIs; with `Canvas.drawRect` it is evaluated for all fragments in the rectangle, with a stroked `Canvas.drawPath` for all fragments within the stroke. Some APIs, such as `Canvas.drawImage`, ignore the shader.
- The `ImageFilter` API for custom shaders (`ImageFilter.shader`, used with `ImageFiltered` or `BackdropFilter`) is only supported by the Impeller backend; using it on other backends throws an error. With `BackdropFilter`, a `ClipRect` limits the affected area, otherwise it applies to the whole screen. The engine sets the `sampler2D` at index 0 and the `float` values at indices 0 and 1 (width, height); your shader must declare them (for example a `sampler2D` and a `vec2`) but you must not set them from Dart. When targeting OpenGLES the texture y-coordinates are flipped.
- Authoring: fragment shaders are GLSL source files with the `.frag` extension (vertex shaders, `.vert`, are not supported). Any GLSL version from 460 down to 100 is supported, though some features are restricted. Limitations: UBOs and SSBOs aren't supported; `sampler2D` is the only supported sampler type; only the two-argument `texture` (sampler and uv) is supported; no additional varying inputs can be declared; all precision hints are ignored when targeting Skia; unsigned integers and booleans aren't supported.
- Uniforms: `float`, `vec2`, `vec3`, `vec4` are set with `FragmentShader.setFloat` / `getUniformFloat` (call once per component for multi-float types); `sampler2D` values with `setImageSampler` / `getImageSampler`. Indices follow declaration order and do not count the `sampler2D` uniform, which starts over at 0. Uninitialized float uniforms default to `0.0`.
- `FlutterFragCoord()` (from `flutter/runtime_effect.glsl`) returns local coordinates and is distinct from `gl_FragCoord` (screen space), which should generally be avoided; under Skia `gl_FragCoord` calls are rewritten to local coordinates, which isn't possible with Impeller.
- Colors: there is no built-in color type; use `vec4` RGBA. The output `fragColor` expects normalized `0.0` to `1.0` values with premultiplied alpha, unlike typical Flutter colors (`0-255`, unpremultiplied).
- Samplers provide a `dart:ui` `Image` (decoded image, or `Scene.toImageSync` / `Picture.toImageSync`). The image uses `TileMode.clamp` by default; customizing the tile mode is not supported and must be emulated in the shader.
- Performance: under Skia, loading a shader may be expensive because it compiles to the platform-specific shader at runtime; precache fragment program objects before an animation. Reuse a `FragmentShader` across frames rather than creating a new one per frame.
- Shell example: variable and command-substitution quoting added relative to the official page (`cd "${FLUTTER}"`, `"$(find ...)"`) to survive paths with spaces.
- Flutter fragment shaders (GLSL via `FragmentProgram`). Distinct from Rive, Theatre.js, and Motion effects (rive, theatrejs, motion skills) and from Metal / CUDA compute kernels (apple-silicon, nvidia-cuda skills); Impeller is the Flutter rendering backend.
