# Supported commands

Redis commands that Memorystore for Redis Cluster supports and the commands it blocks (returning a `NOPERM` error). Memorystore supports all Redis 7.2 commands except the blocked ones.

## Signature / Usage

```bash
redis-cli -h DISCOVERY_ENDPOINT_ADDRESS -p PORT_NUMBER -c
```

## Notes

- The `LATENCY` group isn't blocked, but `latency-monitor-threshold` can't be set, so `LATENCY` commands return no relevant information for it.
- Group columns are a regrouping of the source's flat alphabetical list; subcommands are shown in parentheses (the source writes `CLIENT | CACHING`).
- `FLUSHALL`, `FLUSHDB` and `DEL` are destructive; try them on a disposable instance first.
- Memorystore pages here cover managed Valkey / Redis / Memcached on Google Cloud, distinct from Upstash Redis (`upstash`) and Cloudflare Workers KV (`cloudflare-storage`).
