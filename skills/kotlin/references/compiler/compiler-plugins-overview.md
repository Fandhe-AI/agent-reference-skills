# Compiler plugins

Compiler plugins hook into the compilation process to analyze or change code while it's being compiled, without modifying the compiler itself.

## Signature / Usage

Applying a plugin (All-open, via Gradle):

```kotlin
plugins {
    kotlin("plugin.allopen") version "2.4.21"
}
```

Plugins maintained by the Kotlin team:

| Plugin | Description |
| --- | --- |
| All-open | Automatically makes annotated classes and their members `open` so frameworks can extend them at runtime. |
| AtomicFU | Transforms atomic operations into efficient, platform-specific implementations for lock-free concurrency. |
| DataFrame | Generates typed APIs that let you work with a DataFrame in a safe, Kotlin-friendly way. |
| JPA | Makes JPA-annotated entities `open` and generates zero-argument constructors for them; wraps `all-open` and `no-arg`. |
| js-plain-objects | Exposes Kotlin classes as plain JavaScript objects to improve interop with JS tooling and libraries. |
| jvm-abi-gen | Generates Application Binary Interface (ABI) JARs. |
| kapt | Runs Java annotation processors on Kotlin code and generates additional source files. |
| Lombok | Enables Kotlin code to understand and use code generated by Lombok annotations in Java sources. |
| no-arg | Generates no-argument constructors for annotated classes to support frameworks that require them. |
| Power-assert | Enhances assertion failures by showing detailed values for each part of an expression. |
| SAM with receiver | Allows SAM interfaces to use lambdas with receivers for a more DSL-like syntax. |
| Serialization | Generates code that serializes and deserializes Kotlin objects without reflection. |
| Spring | Makes Spring-annotated classes and members `open`; a preconfigured wrapper around `all-open`. |

Maintained by the Android team at Google:

| Plugin | Description |
| --- | --- |
| Compose compiler Gradle plugin | Integrates the Compose compiler with Gradle to enable declarative UI features and Compose-specific optimizations. |
| Parcelize plugin | Generates `Parcelable` implementations automatically so you can pass Kotlin objects between Android components. |

## Notes

- The Gradle snippet is the plugin line from the all-open page (all-open-plugin.md).
- JPA and Spring rows were added in the current official page; both are preconfigured wrappers (JPA around `no-arg` + `all-open`, Spring around `all-open`).
- Source: https://kotlinlang.org/docs/compiler-plugins-overview.html (kotlin-web-site 2f28ab9, fetched 2026-11-14)
- If no plugin fits, first check whether the Kotlin Symbol Processing (KSP) API or an external linter such as Android lint works.
- A custom compiler plugin is a last resort: the plugin API is unstable and each new compiler release introduces breaking changes.
