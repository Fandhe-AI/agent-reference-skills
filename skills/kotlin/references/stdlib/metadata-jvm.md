# Kotlin Metadata JVM library

The `kotlin-metadata-jvm` library reads, modifies, and generates metadata of Kotlin classes compiled for the JVM. The metadata is stored in the `@Metadata` annotation within `.class` files and is used by tools such as `kotlin-reflect`.

## Signature / Usage

```kotlin
// build.gradle.kts
repositories {
    mavenCentral()
}

dependencies {
    implementation("org.jetbrains.kotlin:kotlin-metadata-jvm:2.4.21")
}
```

Maven: `org.jetbrains.kotlin:kotlin-metadata-jvm:2.4.21` as a `<dependency>`.

### Read and parse

```kotlin
import kotlin.metadata.jvm.*
import kotlin.metadata.*

fun main() {
    val clazz = Class.forName("org.example.SampleClass")
    val metadataAnnotation = clazz.getAnnotation(Metadata::class.java)
    if (metadataAnnotation != null) {
        val metadata = KotlinClassMetadata.readLenient(metadataAnnotation)
        when (metadata) {
            is KotlinClassMetadata.Class -> {
                val kmClass = metadata.kmClass
                println("Class name: ${kmClass.name}")
                kmClass.functions.forEach { function ->
                    println("Function: ${function.name}, Visibility: ${function.visibility}")
                }
            }
            is KotlinClassMetadata.FileFacade -> {
                val kmPackage = metadata.kmPackage
                kmPackage.functions.forEach { function ->
                    println("Function: ${function.name}, Visibility: ${function.visibility}")
                }
            }
            else -> println("Unsupported metadata type: $metadata")
        }
    }
}
```

| Function | Use |
| --- | --- |
| `KotlinClassMetadata.readLenient()` | Read metadata, including that generated by newer Kotlin compiler versions. Does not support modifying or writing. |
| `KotlinClassMetadata.readStrict()` | Use when modifying and writing metadata. Works only with metadata from compiler versions fully supported by your project. |
| `KotlinClassMetadata.write()` | Encode modified metadata into a new `@Metadata` annotation. |
| `KotlinClassMetadata.transform()` | Parse, apply a lambda transformation, and write automatically (instead of `readStrict()` + `write()`). |

`kmClass` gives class-level metadata (name, functions, properties, visibility); `kmPackage` gives top-level functions and properties of file facades.

### Annotations in metadata

APIs for accessing annotations: `KmClass.annotations`, `KmFunction.annotations`, `KmProperty.annotations`, `KmConstructor.annotations`, `KmPropertyAccessorAttributes.annotations`, `KmValueParameter.annotations`, `KmFunction.extensionReceiverAnnotations`, `KmProperty.extensionReceiverAnnotations`, `KmProperty.backingFieldAnnotations`, `KmProperty.delegateFieldAnnotations`, `KmEnumEntry.annotations`.

```kotlin
import kotlin.metadata.jvm.KotlinClassMetadata

annotation class Label(val value: String)

@Label("Message class")
class Message

fun main() {
    val metadata = Message::class.java.getAnnotation(Metadata::class.java)
    val kmClass = (KotlinClassMetadata.readStrict(metadata) as KotlinClassMetadata.Class).kmClass
    println(kmClass.annotations)
    // [@Label(value = StringValue("Message class"))]
}
```

### Modify and create metadata

Modify: parse with `readStrict()`, change `kmClass` (e.g. filter functions), then `write()`; embedding into the `.class` file needs a bytecode framework such as ASM.

```kotlin
val metadata = KotlinClassMetadata.readStrict(metadataAnnotation)
if (metadata is KotlinClassMetadata.Class) {
    val kmClass = metadata.kmClass

    // Removes private functions from the class metadata
    kmClass.functions.removeIf { it.visibility == Visibility.PRIVATE }

    // Serializes the modified metadata back
    val newMetadata = metadata.write()
}
```

Create from scratch: build a `KmClass` / `KmPackage` / `KmLambda`, wrap it in a `KotlinClassMetadata` with `JvmMetadataVersion.LATEST_STABLE_SUPPORTED` and flags (`0` for none), call `write()`, and embed `kind`, `data1`, `data2` with ASM `ClassWriter`.

```kotlin
val klass = KmClass().apply {
    name = "Hello"
    visibility = Visibility.PUBLIC
    constructors += KmConstructor().apply {
        visibility = Visibility.PUBLIC
        signature = JvmMethodSignature("<init>", "()V")
    }
    functions += KmFunction("hello").apply {
        visibility = Visibility.PUBLIC
        returnType = KmType().apply {
            classifier = KmClassifier.Class("kotlin/String")
        }
        signature = JvmMethodSignature("hello", "()Ljava/lang/String;")
    }
}

val annotationData = KotlinClassMetadata.Class(
    klass, JvmMetadataVersion.LATEST_STABLE_SUPPORTED, 0
).write()
```

## Notes

- The library follows the same versioning as the Kotlin compiler and standard library; use the version matching your project's Kotlin version.
- `kotlin-reflect` relies on metadata; inconsistencies between metadata and the actual `.class` file can cause incorrect reflection behavior.
- `readStrict()` supports metadata formats up to one version beyond `JvmMetadataVersion.LATEST_STABLE_SUPPORTED` (e.g. with `kotlin-metadata-jvm:2.1.0` it can process metadata up to Kotlin `2.2.x`); otherwise it throws an error.
- Annotations are stored in Kotlin metadata starting with Kotlin 2.4.0; class files compiled with earlier versions do not carry them in metadata. Keep metadata annotations consistent with those in bytecode.
- `ExperimentalAnnotationsInMetadata` is deprecated with no effect as of kotlin-metadata-jvm 2.4.x (annotations in metadata are enabled by default since 2.4.0); the official sample still imports it, but no opt-in is needed.
- Binary Compatibility Validator (BCV) uses this library to print public API declarations.
- Metadata can also be extracted from bytecode with ASM (`ClassReader` into `ClassNode`, then `KotlinClassMetadata.readLenient()`).
