# Ignore files via .easignore

Learn how to configure EAS to ignore unnecessary files during the build process.

## Signature / Usage

A **.easignore** file defines which files EAS should ignore when uploading your project to the EAS Build servers. By default, the EAS CLI refers to the **.gitignore** file (if it exists). If you create a **.easignore** file in the project root, the EAS CLI prioritizes it over **.gitignore**. Include all files and directories from your **.gitignore** and add the additional files you want to ignore.

```bash
# Copy everything from your .gitignore file here

# Ignore files and directories that EAS Build doesn't need to build your app
/docs

# Ignore native directories (if you are using EAS Build)
/android
/ios

# Ignore test coverage reports
/coverage
```

Save the file and trigger a new build:

```sh
eas build --platform ios --profile development
```

### Adding files to your project upload

Use the `!` prefix to upload files that are not committed to source control (for example, temporary files generated by a script just before the build). The `!` prefixed file should be last, so it takes precedence over any prior rules that would ignore it.

```bash
# Copy everything from your .gitignore file here

/android
/ios

# Include a file not in source control
!temp_file.json
```

## Notes

- Ignoring unnecessary files can help reduce the app's archive size and upload time.
- If the project does not contain **android** and **ios** directories, EAS Build runs Prebuild to generate them before compilation.
