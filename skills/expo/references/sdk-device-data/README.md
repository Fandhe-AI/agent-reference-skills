| SQLite | `expo-sqlite` provides a database that persists across app restarts, queried through a SQLite API. | [sqlite.md](./sqlite.md) |
| StoreReview | `expo-store-review` asks the user to rate the app via ReviewManager or SKStoreReviewController. | [store-review.md](./store-review.md) |
