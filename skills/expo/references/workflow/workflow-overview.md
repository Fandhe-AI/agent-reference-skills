# Develop an app with Expo

Overview of the development process of building an Expo app: key concepts and the core development loop.

## Signature / Usage

```sh
# Three commands that result in more or less the same project
npx create-expo-app@latest --template default@sdk-58 MyApp && cd MyApp && npx expo prebuild

npx create-expo-app --template bare-minimum

npx @react-native-community/cli@latest init MyApp && cd MyApp && npx install-expo-modules
```

## Notes

- "Expo app" means a React Native app that uses Expo tools (any of the SDK, Expo Router, Expo CLI, CNG, ...). Expo is open source (MIT); Expo Services is a suite of hosted services to build, submit, update, automate, and collaborate. Expo Services is not required, and can be used without Expo open source tools.
- Expo Go is a limited playground for students and learners; for production-grade projects use development builds (debug builds including `expo-dev-client`).
- A React Native app has two parts: the app JavaScript, and the Android / Xcode native projects. `create-expo-app` does not create **android** / **ios** by default; they are generated by `npx expo prebuild` and added to **.gitignore** (Continuous Native Generation).
- Run `npx expo prebuild --clean` after adding a native dependency or changing app config. Running prebuild after editing native directories directly overwrites those edits.
- Cloud-based (Expo Build) vs local (Android Studio / Xcode, `npx expo run:[android|ios]`) is a choice per native build.
- Core development loop: write and run JavaScript; update app configuration; write native code or modify native project configuration; install a library that requires native code modifications (the last three require a development build).
- Development variants (development, preview, production) can be installed on the same device.
- Lifecycle steps covered: share with testers (Expo Build internal distribution; local production builds), release to stores (Expo Submit), monitor (Sentry, BugSnag, analytics), update (`expo-updates`, Expo Update).
- Distinct from React itself and from React Native core components (View, Text, FlatList); see the react / react-native skills for those.
