# core

| Name | Description | Path |
|------|-------------|------|
| createIdGenerator | Creates a customizable ID generator function. You can configure the alphabet, prefix, separator, and default size of the generated IDs. | [create-id-generator.md](./create-id-generator.md) |
| DefaultGeneratedFile | A concrete implementation of the `GeneratedFile` interface that provides lazy conversion between base64 and Uint8Array formats. | [default-generated-file.md](./default-generated-file.md) |
| generateId | Generates a unique identifier. This is the same id generator used by the AI SDK. | [generate-id.md](./generate-id.md) |
| generateText | Generates text and calls tools for a given prompt using a language model. Ideal for non-interactive use cases such as automation tasks (drafting email, summarizing web pages) and for agents that use tools. | [generate-text.md](./generate-text.md) |
| Generating and Streaming Text | AI SDK Core provides `generateText` (generate text for a given prompt and model) and `streamText` (stream text from a given prompt and model). Tool calling and structured data generation are built on top of text generation. | [generating-text.md](./generating-text.md) |
| Generating Structured Data | The AI SDK standardises structured object generation across model providers using the `output` property on `generateText` and `streamText`. Zod schemas, Valibot, or JSON schemas specify the shape of the data; the schema is also used to validate the generated data. | [generating-structured-data.md](./generating-structured-data.md) |
| Lifecycle Callbacks | Event callbacks run your own code at important points in an AI SDK call. Attach them directly to `generateText`, `streamText`, `embed`, `embedMany`, `rerank`, and `experimental_decide` to log, record usage, debug multi-step generations, and monitor tool execution. | [lifecycle-callbacks.md](./lifecycle-callbacks.md) |
| ModelMessage | `ModelMessage` represents the fundamental message structure used with AI SDK Core functions. It encompasses the message types usable in the `messages` field of any AI SDK Core function. The Zod schema is available via the `modelMessageSchema` export. | [model-message.md](./model-message.md) |
| Output | The `Output` object provides output specifications for structured data generation with `generateText` and `streamText`. It specifies the expected shape of the generated data and handles validation automatically. | [output.md](./output.md) |
| AI SDK Core | AI SDK Core simplifies working with LLMs by offering a standardized way of integrating them into your app. Its functions cover text generation, structured data generation, and tool usage with a standardized approach to prompts and settings. | [overview.md](./overview.md) |
| Prompt Engineering | Tips for prompts that include tools or structured data schemas, and ways to debug what the provider actually received. | [prompt-engineering.md](./prompt-engineering.md) |
| Reasoning | The AI SDK provides a top-level `reasoning` parameter on `generateText` and `streamText` that controls the model's internal "reasoning" (or "thinking") phase across providers with a single, portable setting. | [reasoning.md](./reasoning.md) |
| Settings | All AI SDK functions support common settings in addition to the model, the prompt, and provider-specific settings. Two groups exist: language model call options (`LanguageModelCallOptions`) and request options (`RequestOptions`). | [settings.md](./settings.md) |
| simulateReadableStream | `simulateReadableStream` creates a `ReadableStream` that emits provided values sequentially with configurable delays. Useful for testing streaming functionality or simulating time-delayed data streams. | [simulate-readable-stream.md](./simulate-readable-stream.md) |
| smoothStream | `smoothStream` creates a `TransformStream` for the `streamText` `experimental_transform` option. It smooths out text and reasoning streaming by buffering and releasing complete chunks with configurable delays, for a more natural reading experience. | [smooth-stream.md](./smooth-stream.md) |
| streamText | Streams text generations from a language model. Use it for interactive use cases such as chat bots and other real-time applications. You can also generate UI components with tools. | [stream-text.md](./stream-text.md) |
