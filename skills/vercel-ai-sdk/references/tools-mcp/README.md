# tools-mcp

| Name | Description | Path |
|------|-------------|------|
| Code Mode | Code mode lets a model write JavaScript or TypeScript that calls your AI SDK tools. The generated code runs in an isolated QuickJS sandbox and returns a JSON-serializable result. Provided by the `@ai-sdk/code-mode` package. | [code-mode.md](./code-mode.md) |
| createMCPClient | Creates a lightweight Model Context Protocol (MCP) client that connects to an MCP server. Provides tools (MCP -> AI SDK tool conversion), resources, prompts, completions, elicitation handling, and experimental events (`client.experimental_events`). | [create-mcp-client.md](./create-mcp-client.md) |
| dynamicTool | Creates tools whose input and output types are unknown at compile time (MCP tools without schemas, user-defined functions loaded at runtime, tools from external sources or databases, dynamic tool generation). | [dynamic-tool.md](./dynamic-tool.md) |
| filterActiveTools | Filters a tool set to only the string tool names listed in `activeTools`. Useful for limiting which tools are sent to a model in a particular step. | [filter-active-tools.md](./filter-active-tools.md) |
| jsonSchema | Creates a JSON schema object compatible with the AI SDK from a JSON schema and an optional validation function. An alternative to Zod for dynamic situations (e.g. OpenAPI definitions) or other validation libraries; usable for structured data generation and tools. | [json-schema.md](./json-schema.md) |
| MCP Apps (guide) | MCP Apps extend MCP tools with interactive UI resources: the model calls ordinary MCP tools, and tools can point to a `ui://` resource containing HTML that your app renders in a sandboxed iframe. The AI SDK provides `@ai-sdk/mcp` helpers (advertise support, split tools by visibility, read `ui://` resources) and `@ai-sdk/react` components (render the iframe, bridge JSON-RPC messages). | [mcp-apps-guide.md](./mcp-apps-guide.md) |
| MCP Apps | MCP Apps helpers in `@ai-sdk/mcp` let an MCP host advertise UI support, keep model-visible and app-visible tools separate, and read `ui://` HTML resources for rendering. | [mcp-apps.md](./mcp-apps.md) |
| MCP Events (guide) | MCP events let a server notify your application when something changes (for example a new document comment). Your MCP client manages the subscription; your webhook endpoint receives the events. | [mcp-events-guide.md](./mcp-events-guide.md) |
| MCP Events | Reference for the experimental methods on `client.experimental_events`, the webhook handler, and the subscription and storage types. Methods belong to `client.experimental_events`; they are not standalone imports. | [mcp-events.md](./mcp-events.md) |
| Experimental_StdioMCPTransport | Transport for MCP clients to communicate with MCP servers over standard input and output streams. Node.js environments only. | [mcp-stdio-transport.md](./mcp-stdio-transport.md) |
| Model Context Protocol (MCP) | The AI SDK connects to MCP servers to access their tools, resources, and prompts via `createMCPClient` from `@ai-sdk/mcp`. | [mcp-tools.md](./mcp-tools.md) |
| Runtime and Tool Context | Context passes server-side state (tenant info, feature flags, session data, request IDs, API credentials) through a generation or agent loop without putting it into the prompt. Shared runtime state (`runtimeContext`) is separate from per-tool state (`toolsContext`). | [runtime-and-tool-context.md](./runtime-and-tool-context.md) |
| Tool Search | `toolSearch()` lets a model find the tools it needs without loading every tool definition into its initial context. Register tools with `deferLoading: true`; search matches their names and descriptions and makes them available on the next model step. | [tool-search-guide.md](./tool-search-guide.md) |
| toolSearch | Creates a tool that searches the surrounding generation's deferred tools (`deferLoading: true`), using keyword matching by default or a custom `search` callback. Works with `generateText`, `streamText`, `ToolLoopAgent`, or `WorkflowAgent` from `@ai-sdk/workflow`. `WorkflowAgent` supports direct tool calling; the others also support code mode configured with `toolDiscovery: 'conversation'`. | [tool-search.md](./tool-search.md) |
| tool | Helper that infers the tool input and context types for `execute` and lifecycle callbacks. It has no runtime behavior. | [tool.md](./tool.md) |
| Tool Calling | Tools are objects the model can call to perform a specific task. The `tools` parameter of `generateText` and `streamText` is an object keyed by tool name. Multi-step calls are enabled with `stopWhen`. | [tools-and-tool-calling.md](./tools-and-tool-calling.md) |
| valibotSchema | Converts a Valibot schema into a JSON schema object compatible with the AI SDK; returns a typed schema. Usable for structured data generation and tools. | [valibot-schema.md](./valibot-schema.md) |
| zodSchema | Converts a Zod schema into a JSON schema object compatible with the AI SDK; takes a Zod schema and optional configuration and returns a typed schema. Usable for structured data generation and tools. | [zod-schema.md](./zod-schema.md) |
