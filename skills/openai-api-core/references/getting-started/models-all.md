## Notes

- The live `/models/all` page is organized by category (Flagship / Image / Realtime & audio / OpenAI Daybreak / Life sciences / Open-weight / Embedding / More models / ChatGPT models / Deprecated models); this table is kept as one flat, case-insensitive alphabetical list of the same entries, with each entry's status prefix (`Deprecated.` / `Shut down.`) kept verbatim from the live descriptions. The Sora 2 entries are no longer in the catalog (shut down 2026-09-24 with the Videos API).
- GPT-Rosalind links to the pricing page's specialized-models section; the live entry lists Model ID `gpt-rosalind-research`, while the changelog (Oct 30, 2026) announces it as `gpt-6-rosalind` (trusted-access program only).
- Source: https://developers.openai.com/api/docs/models/all (Markdown twin, retrieved 2026-11-14); changelog https://developers.openai.com/api/docs/changelog (Oct 26 / Oct 30 / Nov 4 / Nov 5, 2026).
- Each model name links to its own detail page at `/api/docs/models/<id>.md` (not individually reproduced here — this scope covers the catalog overview, not per-model detail pages).
- Deprecated models remain listed in the catalog; see [Deprecations](../legacy-migration/deprecations.md) for retirement timelines and replacements.
