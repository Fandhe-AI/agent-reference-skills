# gcloud container hub config-management version

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta container hub config-management version

```text
NAME
    gcloud beta container hub config-management version - print the version of
        all clusters with Config Management enabled

SYNOPSIS
    gcloud beta container hub config-management version [--filter=EXPRESSION]
        [--limit=LIMIT] [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
        [GCLOUD_WIDE_FLAG ...]
```

```text

    gcloud alpha container hub config-management version - print the version of
```
