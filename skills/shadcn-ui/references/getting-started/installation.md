# Installation

How to install dependencies and structure your app. Choose between shadcn/create (visual preset builder), the CLI, or adding shadcn/ui to an existing project.

## Signature / Usage

```bash
npx shadcn@latest init -t [framework]
```

Supported templates: `next`, `vite`, `start`, `react-router`, and `astro`.

For Laravel, create the app first with `laravel new`, then run `npx shadcn@latest init`.

## Notes

- Recommended for new projects: use shadcn/create (`/create`) to build your preset visually and generate the setup command. Available for Next.js, Vite, Laravel, React Router, Astro, and TanStack Start.
- Each framework guide includes an `Existing Project` section with the manual setup steps for that framework.
- Framework guides listed: Next.js, Vite, TanStack Start, Laravel, React Router, Astro, Manual.
- Framework APIs themselves are in skills nextjs-app / react-router / tanstack-start / tanstack-router.
