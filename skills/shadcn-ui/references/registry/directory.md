# Registry Directory

Browse page for community registries built into the CLI with no extra configuration. Add a component with `npx shadcn add @<registry>/<component>`.

## Signature / Usage

```bash
npx shadcn add @<registry>/<component>
```

## Notes

- Community registries are maintained by third-party developers; always review code on installation for security and quality.
- The registry list itself is rendered dynamically (`<DirectoryList />`) and is not present in the stored Markdown; the machine-readable list is `https://ui.shadcn.com/r/registries.json`.
- To add a registry to the directory, see the index submission page. The page also links Getting Started, Authentication, Namespaces, Examples and the registry.json schema.
