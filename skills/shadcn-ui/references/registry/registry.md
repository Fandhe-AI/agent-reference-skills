# Registry Introduction

The `shadcn` CLI can run your own code registry, distributing custom components, hooks, pages, config, rules and other files to any project.

## Signature / Usage

```bash
npx shadcn@latest build
```

A registry is a `registry.json` entry point plus item JSON files (see Getting Started).

## Notes

- The registry works with any project type and any framework, and is not limited to React.
- Sub-pages: Getting Started, GitHub, Namespaces, Authentication, Examples, and the `registry.json` schema.
- The `shadcn build` command shown above is described in the Getting Started page; the Introduction page itself carries no code example.
