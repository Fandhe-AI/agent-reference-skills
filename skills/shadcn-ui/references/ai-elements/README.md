# ai-elements

| Name | Description | Path |
|------|-------------|------|
| AI Elements | Patterns for agentic interfaces, built from shadcn/ui components. | [ai-elements.md](./ai-elements.md) |
| Chain of Thought | A summary line that expands into the steps an agent took, like "Researched in 3 steps". | [chain-of-thought.md](./chain-of-thought.md) |
| Chat | The thread of a conversation with the agent, with each turn a Message inside Message Scroller. | [chat.md](./chat.md) |
| Checkpoint | A point in the conversation you can return to, shown as a Marker with a Restore button. | [checkpoint.md](./checkpoint.md) |
| Confirmation | Asks the person for a yes or no before a tool runs, with Deny and Approve buttons. | [confirmation.md](./confirmation.md) |
| Context | Shows how much of the model's context window the conversation has used. | [context.md](./context.md) |
| File Tree | The files the agent changed, shown as folders you can open. | [file-tree.md](./file-tree.md) |
| Inline Citation | A source that sits in the sentence it supports, shown as a Hover Card. | [inline-citation.md](./inline-citation.md) |
| Message | One turn in a thread, with the person's text as a Bubble on a Message. | [message.md](./message.md) |
| Model Selector | Two menus: one picks the model the agent runs, the other picks how hard it thinks (effort). | [model-selector.md](./model-selector.md) |
| Plan | The list of steps the agent decides on before it starts, such as the steps of a migration. | [plan.md](./plan.md) |
| Prompt Input | The field the person types into to message the agent. | [prompt-input.md](./prompt-input.md) |
| Queue | The agent's todo list, split into To do and Completed sections. | [queue.md](./queue.md) |
| Reasoning | A line for the agent's thinking, reading "Thinking" while the model thinks and "Thought" when done. | [reasoning.md](./reasoning.md) |
| Sources | A line that lists the links the agent used for a reply, like "Used 3 sources". | [sources.md](./sources.md) |
| Stack Trace | A line for a tool call that failed, with the error as its title, like "Failed: TypeError". | [stack-trace.md](./stack-trace.md) |
| Subagent | A line for work the agent hands to a subagent, like "Ran the research agent". | [subagent.md](./subagent.md) |
| Suggestion | A prompt you send without typing, shown as a Button. | [suggestion.md](./suggestion.md) |
| Task | A piece of work the agent is doing, such as finding the project files or updating a page. | [task.md](./task.md) |
| Terminal | A shell command the agent runs, such as a lint, a test run or a build. | [terminal.md](./terminal.md) |
| Test Results | A test run by the agent, with a summary line that counts what passed and failed. | [test-results.md](./test-results.md) |
| Tool | A tool call the agent makes, such as running a command or reading a file. | [tool.md](./tool.md) |
