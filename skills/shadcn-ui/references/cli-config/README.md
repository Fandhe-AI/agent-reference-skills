# cli-config

| Name | Description | Path |
|------|-------------|------|
| shadcn | The `shadcn` CLI adds components and manages presets, registries and migrations. | [cli.md](./cli.md) |

| Monorepo | The CLI understands monorepo structure and installs components to the correct workspace paths. | [monorepo.md](./monorepo.md) |
| Package Imports | The `shadcn` CLI supports Node.js package imports (`#...` aliases) as an alternative to `compilerOptions.paths`. | [package-imports.md](./package-imports.md) |
| Skills | shadcn's own Agent Skill gives AI assistants such as Claude Code project-aware shadcn/ui context. | [skills.md](./skills.md) |
