## Notes

- The Figma files are community-contributed; direct questions to the file maintainers.
- Per the listings: shadcncraft supports all eight shadcn/ui styles, tweakcn / shadcn/ui Create themes and exports frames to React; shadcncraft and Shadcnblocks mention Figma MCP use.
- Figma platform API / plugins are covered by skill figma.
