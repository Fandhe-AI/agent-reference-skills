# Install

Commands to create a project, initialize shadcn/ui and add components. Source: the installation pages of the official documentation (retrieved 2026-10-16, `shadcn` CLI 4.22.0).

## Initialize an existing project

```sh
npx shadcn@latest init
```

Prerequisite: run it at the root of an existing project. It creates `components.json` and the `cn` utility and sets up CSS variables.

## Create a new Next.js project (CLI)

```sh
npx shadcn@latest init -t next
```

Prerequisite: choose the base, preset, monorepo and other options at the prompts.

## Create a new Next.js monorepo

```sh
npx shadcn@latest init -t next --monorepo
```

## Use a preset generated by shadcn/create (Next.js)

```sh
npx shadcn@latest init --preset [CODE] --template next
```

`[CODE]` is the preset code created with shadcn/create. The generated command may include `--base`, `--monorepo`, `--rtl` and similar flags.

## Initialize per template (-t / --template)

```sh
npx shadcn@latest init -t vite
npx shadcn@latest init -t start
npx shadcn@latest init -t react-router
npx shadcn@latest init -t astro
```

`--template` accepts `next` / `vite` / `start` / `react-router` / `laravel` / `astro` (per the Options in the cli page).

## Specify a preset per template

```sh
npx shadcn@latest init --preset [CODE] --template vite
npx shadcn@latest init --preset [CODE] --template start
npx shadcn@latest init --preset [CODE] --template react-router
npx shadcn@latest init --preset [CODE] --template laravel
npx shadcn@latest init --preset [CODE] --template astro
```

## Specify the base (Radix / React Aria)

```sh
npx shadcn init -b radix
npx shadcn@latest init --base aria
```

`-b, --base` accepts `base` / `radix` / `aria`. Since 2026-07 the default is Base UI; to keep Radix in non-interactive environments such as CI, pass `-b radix` (per the changelog).

## Add components

```sh
npx shadcn@latest add button
npx shadcn@latest add card
```

## Add to a specific workspace in a monorepo

```sh
npx shadcn@latest add card -c apps/web
```

Prerequisite: a monorepo setup already exists. Run it inside `apps/web`, or from the root with `-c` to select the workspace.

## Per-framework preliminary commands

```sh
npx create-next-app@latest
npx create-next-app@latest --src-dir
npm create vite@latest
npm install tailwindcss @tailwindcss/vite
npm install -D @types/node
npm create react-router@latest
npx @tanstack/cli@latest create
npx create-tsrouter-app@latest my-app --template file-router --tailwind --add-ons shadcn
npm create astro@latest astro-app -- --template with-tailwindcss --install --add react --git
laravel new my-app
npm init gatsby
npx create-remix@latest my-app
```

Each line belongs to a different framework's procedure; run only the relevant ones. Vite needs the first three lines plus edits to tsconfig and vite.config (see `references/getting-started/vite.md`).

## Dependencies for manual installation

```sh
npm install shadcn class-variance-authority cn lucide-react tw-animate-css
```

Steps from `installation/manual`. For the subsequent CSS and `components.json` setup, see `references/getting-started/manual.md`.
