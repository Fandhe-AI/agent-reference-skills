| Name | Description | Path |
|------|-------------|------|
| Common Types | Shared building blocks from `@category Common Types`: JSON value types, `_meta` objects (request / notification / result), IDs, cursors, params bases, pagination, `CacheableResult`, `Icon`, `Annotations`, `Role`, and `Implementation`. | [common-types.md](./common-types.md) |
| completion/complete types | Schema types for `completion/complete`: `CompleteRequestParams`, `CompleteResult`, `PromptReference`, `ResourceTemplateReference`. | [completion-types.md](./completion-types.md) |

| server/discover types | `DiscoverRequest` / `DiscoverResult` / `DiscoverResultResponse`, plus `ClientCapabilities`, `ServerCapabilities`, and `Implementation` (`@category server/discover`). | [discover-types.md](./discover-types.md) |
| elicitation/create types | Schema types for `elicitation/create`: form-mode and URL-mode params, the restricted primitive schema definitions (string / number / boolean / enum), and `ElicitResult`. | [elicitation-types.md](./elicitation-types.md) |
| Error types | The JSON-RPC `Error` object, standard JSON-RPC error codes, and the MCP-specific codes `HEADER_MISMATCH` (-32020), `MISSING_REQUIRED_CLIENT_CAPABILITY` (-32021), and `UNSUPPORTED_PROTOCOL_VERSION` (-32022), from `@category Errors`. | [errors.md](./errors.md) |
| JSON-RPC types | JSON-RPC 2.0 message envelopes (`JSONRPCRequest`, `JSONRPCNotification`, `JSONRPCResultResponse`, `JSONRPCErrorResponse`) and the base `Request` / `Notification` / `Result` shapes they extend, from `@category JSON-RPC` in `schema.ts`. | [json-rpc.md](./json-rpc.md) |
| Multi Round-Trip types | Schema types for Multi Round-Trip Requests (MRTR): `InputRequiredResult`, `InputRequests`, `InputResponses`, and `InputResponseRequestParams`. A server answers a client request with `resultType: "input_required"` instead of issuing its own request; the client retries with `inputResponses` and `requestState`. | [mrtr-types.md](./mrtr-types.md) |
| Request-scoped notification types | Schema types for `notifications/cancelled`, `notifications/progress`, and `notifications/message` (logging, Deprecated), plus the aggregate `ClientNotification` / `ServerNotification` unions. | [notifications-types.md](./notifications-types.md) |
| prompts/* types | Schema types for `prompts/list`, `prompts/get`, and `notifications/prompts/list_changed`: `Prompt`, `PromptArgument`, `PromptMessage`, `GetPromptResult`. | [prompts-types.md](./prompts-types.md) |
| resources/* types | Schema types for `resources/list`, `resources/templates/list`, `resources/read`, `notifications/resources/list_changed`, and `notifications/resources/updated`: `Resource`, `ResourceTemplate`, and result types. | [resources-types.md](./resources-types.md) |
| roots/list types | Schema types for `roots/list`: `ListRootsRequest`, `ListRootsResult`, `Root`. The whole category is Deprecated as of 2026-07-28 (SEP-2577). | [roots-types.md](./roots-types.md) |
| sampling/createMessage types | Schema types for `sampling/createMessage` (server-to-client LLM sampling): `CreateMessageRequestParams`, `CreateMessageResult`, `SamplingMessage`, `ModelPreferences`, `ModelHint`, `ToolChoice`, `ToolUseContent`, `ToolResultContent`. The whole category is Deprecated as of 2026-07-28 (SEP-2577). | [sampling-types.md](./sampling-types.md) |
| subscriptions/listen types | Schema types for `subscriptions/listen` and `notifications/subscriptions/acknowledged`: `SubscriptionFilter`, `SubscriptionsListenRequest`, `SubscriptionsListenResult`, `SubscriptionsAcknowledgedNotification`. | [subscriptions-types.md](./subscriptions-types.md) |
| tools/* types | Schema types for `tools/list`, `tools/call`, and `notifications/tools/list_changed`: `Tool`, `ToolAnnotations`, `CallToolRequestParams`, `CallToolResult`, and the list result types. | [tools-types.md](./tools-types.md) |
