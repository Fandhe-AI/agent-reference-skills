# endpoints-compliance

エンドポイントはリソース単位の集約ページ（計 31 EP）。Compliance Access Key と専用スコープが必要（詳細は compliance-security カテゴリを参照）。

| Name | Description | Path |
| --- | --- | --- |

| Apps Artifacts Compliance API | claude.ai chat artifact 版のコンプライアンスアクセス（読み取り専用） | [apps-artifacts.md](./apps-artifacts.md) |
| Apps Chats Compliance API | claude.ai チャット・メッセージ・ファイルへの Compliance API アクセス・削除 | [apps-chats.md](./apps-chats.md) |
| Apps Projects Compliance API | claude.ai Projects のメタデータ・ファイル・コラボレーター・ドキュメント | [apps-projects.md](./apps-projects.md) |
| Code Artifacts Compliance API | Claude Code Artifact（persistent・共有可能コード）Compliance API アクセス | [code.md](./code.md) |
| Groups Compliance API | RBAC グループとメンバーシップの読み取り専用ディレクトリアクセス | [groups.md](./groups.md) |
| Organizations Compliance API | Claude Enterprise テナント内の組織・ロール・権限・設定ディレクトリアクセス | [organizations.md](./organizations.md) |
