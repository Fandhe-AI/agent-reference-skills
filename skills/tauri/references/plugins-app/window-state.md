# Window State

Save window positions and sizes and restore them when the app is reopened. Plugin `tauri-plugin-window-state` 2.5.0 / `@tauri-apps/plugin-window-state` (tag `window-state-v2.5.0`).

## Signature / Usage

After adding the plugin, all windows remember their state when the app is closed and restore it on the next launch.

JavaScript:

```javascript
import { saveWindowState, StateFlags } from '@tauri-apps/plugin-window-state';
// when using `"withGlobalTauri": true`, you may use
// const { saveWindowState, StateFlags } = window.__TAURI__.windowState;

saveWindowState(StateFlags.ALL);
```

Manually restore a window's state from disk:

```javascript
import {
  restoreStateCurrent,
  StateFlags,
} from '@tauri-apps/plugin-window-state';

restoreStateCurrent(StateFlags.ALL);
```

Rust, `save_window_state()` from the `AppHandleExt` trait:

```rust
use tauri_plugin_window_state::{AppHandleExt, StateFlags};

// `tauri::AppHandle` now has the following additional method
app.save_window_state(StateFlags::all()); // will save the state of all open windows to disk
```

Rust, `restore_state()` from the `WindowExt` trait:

```rust
use tauri_plugin_window_state::{WindowExt, StateFlags};

// all `Window` types now have the following additional method
window.restore_state(StateFlags::all()); // will restore the window's state from disk
```

### Setup

Automatic:

```sh
npm run tauri add window-state
cargo tauri add window-state
```

Manual:

1. Add the dependency from `src-tauri`:

```sh
cargo add tauri-plugin-window-state --target 'cfg(any(target_os = "macos", windows, target_os = "linux"))'
```

2. Initialize in `src-tauri/src/lib.rs`:

```rust
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    let mut builder = tauri::Builder::default();
    #[cfg(desktop)]
    {
        builder = builder.plugin(tauri_plugin_window_state::Builder::default().build());
    }

    builder
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

3. `npm install @tauri-apps/plugin-window-state`

### Permissions

`src-tauri/capabilities/default.json`:

```json
{
  "permissions": [
    ...,
    "window-state:default",
  ]
}
```

Default permission set `window-state:default`: all operations are enabled by default. It includes `allow-filename`, `allow-restore-state`, `allow-save-window-state`.

| Identifier | Description |
| --- | --- |
| `window-state:allow-filename` | Enables the filename command without any pre-configured scope. |
| `window-state:allow-restore-state` | Enables the restore_state command without any pre-configured scope. |
| `window-state:allow-save-window-state` | Enables the save_window_state command without any pre-configured scope. |

Each `allow-*` has a matching `deny-*` (e.g. `window-state:deny-filename`).

## Notes

- Restoring the state happens after window creation. To prevent the window from flashing, set `visible` to `false` when creating the window; the plugin shows the window when it restores the state.
- Manual setup snippet differs from the official page (which registers inside `setup()`); config-defined windows are created before `setup` runs, so the plugin is registered with `Builder::plugin` as in the plugin README.
- Tauri plugin (Rust core + system WebView). Not Electron's API; see the electron skill for Electron's `BrowserWindow` (this plugin has no Electron built-in equivalent in the official page).
- Source: `plugins-workspace@window-state-v2.5.0` `plugins/window-state/{Cargo.toml,permissions/autogenerated/reference.md}`.
