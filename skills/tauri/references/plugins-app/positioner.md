# Positioner

Position your windows at well-known locations. A port of electron-positioner for Tauri. Plugin `tauri-plugin-positioner` 2.4.0 / `@tauri-apps/plugin-positioner` (tag `positioner-v2.4.0`).

## Signature / Usage

JavaScript:

```javascript
import { moveWindow, Position } from '@tauri-apps/plugin-positioner';
// when using `"withGlobalTauri": true`, you may use
// const { moveWindow, Position } = window.__TAURI__.positioner;

moveWindow(Position.TopRight);
```

Rust (import the Window trait extension):

```rust
use tauri_plugin_positioner::{WindowExt, Position};

let mut win = app.get_webview_window("main").unwrap();
let _ = win.as_ref().window().move_window(Position::TopRight);
```

### Setup

If you only intend on moving the window from Rust code, you only need the dependency in `src-tauri/Cargo.toml`, and can remove the plugin registration from `lib.rs` if you set up automatically.

Automatic:

```sh
npm run tauri add positioner
cargo tauri add positioner
```

Manual:

1. Add the dependency from `src-tauri`:

```sh
cargo add tauri-plugin-positioner --target 'cfg(any(target_os = "macos", windows, target_os = "linux"))'
```

2. Initialize in `src-tauri/src/lib.rs`:

```rust
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .setup(|app| {
            #[cfg(desktop)]
            app.handle().plugin(tauri_plugin_positioner::init());
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

3. Install the JavaScript Guest bindings:

```sh
npm install @tauri-apps/plugin-positioner
```

### Tray-relative positions

Additional setup is required for tray-relative positions. Add the `tray-icon` feature to `src-tauri/Cargo.toml`:

```toml
[dependencies]
tauri-plugin-positioner = { version = "2.0.0", features = ["tray-icon"] }
```

Then set up `on_tray_event` for the positioner plugin in `src-tauri/src/lib.rs`:

```rust
pub fn run() {
	tauri::Builder::default()
		// This is required to get tray-relative positions to work
		.setup(|app| {
				#[cfg(desktop)]
				{
					app.handle().plugin(tauri_plugin_positioner::init());
						tauri::tray::TrayIconBuilder::new()
							.on_tray_icon_event(|tray_handle, event| {
								tauri_plugin_positioner::on_tray_event(tray_handle.app_handle(), &event);
							})
							.build(app)?;
				}
			Ok(())
		})
		.run(tauri::generate_context!())
		.expect("error while running tauri application");
}
```

### Permissions

`src-tauri/capabilities/default.json`:

```json
{
  "permissions": [
    ...,
    "positioner:default",
  ]
}
```

Default permission set `positioner:default`: allows the moveWindow and handleIconState APIs. It includes `allow-move-window`, `allow-move-window-constrained`, `allow-set-tray-icon-state`.

| Identifier | Description |
| --- | --- |
| `positioner:allow-move-window` | Enables the move_window command without any pre-configured scope. |
| `positioner:allow-move-window-constrained` | Enables the move_window_constrained command without any pre-configured scope. |
| `positioner:allow-set-tray-icon-state` | Enables the set_tray_icon_state command without any pre-configured scope. |

Each `allow-*` has a matching `deny-*` (e.g. `positioner:deny-move-window`).
