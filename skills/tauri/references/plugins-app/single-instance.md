# Single Instance

Ensure that a single instance of your Tauri app is running at a time. Plugin `tauri-plugin-single-instance` 2.5.4 (Rust only; no JavaScript API; tag `single-instance-v2.5.4`).

## Signature / Usage

The plugin `init()` method takes a closure that is invoked when a new app instance was started, but closed by the plugin. Arguments:

1. `app`: the `AppHandle` of the application.
2. `args`: the list of arguments passed by the user to initiate this new instance.
3. `cwd`: the current working directory from which the new application instance was launched.

```rust
.plugin(tauri_plugin_single_instance::init(|app, args, cwd| {
  // Write your code here...
}))
```

Focusing the running instance on a new launch (by default no action is taken):

```rust
use tauri::{AppHandle, Manager};

pub fn run() {
    let mut builder = tauri::Builder::default();
    #[cfg(desktop)]
    {
        builder = builder.plugin(tauri_plugin_single_instance::init(|app, args, cwd| {
            let _ = app.get_webview_window("main")
                       .expect("no main window")
                       .set_focus();
        }));
    }

    builder
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

## Setup

Automatic:

```sh
npm run tauri add single-instance
cargo tauri add single-instance
```

Manual:

1. Add the dependency from `src-tauri`:

```sh
cargo add tauri-plugin-single-instance --target 'cfg(any(target_os = "macos", windows, target_os = "linux"))'
```

2. Initialize in `lib.rs`:

```rust
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .setup(|app| {
            #[cfg(desktop)]
            app.handle().plugin(tauri_plugin_single_instance::init(|app, args, cwd| {}));
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

## Usage in Snap and Flatpak

On Linux the plugin uses DBus: it publishes a service when the first instance starts; later instances try to publish the same service and, if already published, send a request to notify the first instance and exit. This works for deb, rpm and AppImage, but not by default for snap or flatpak because their sandbox blocks most DBus communication unless declared in the packaging manifest.

The plugin publishes a service named `org.{id}.SingleInstance`. `{id}` is the `identifier` from `tauri.conf.json` with dots (`.`) and dashes (`-`) replaced by underline (`_`). Example: identifier `net.mydomain.MyApp` gives `{id}` = `net_mydomain_MyApp` and service name `org.net_mydomain_MyApp.SingleInstance`.

Snap (`snapcraft.yml`):

```yaml
# ...
slots:
  single-instance:
    interface: dbus
    bus: session
    name: org.net_mydomain_MyApp.SingleInstance # Remember to change net_mydomain_MyApp to your app ID

plugs:
  single-instance-plug:
    interface: dbus
    bus: session
    name: org.net_mydomain_MyApp.SingleInstance # Remember to change net_mydomain_MyApp to your app ID

# .....
apps:
  my-app:
    # ...
    plugs:
      # ....
      - single-instance-plug
    slots:
      # ...
      - single-instance

    # ....
```

Flatpak (declare `--talk-name` and `--own-name` finish args in `net.mydomain.MyApp.yml`):

```yaml
# ...
finish-args:
  - --socket=wayland
  - --socket=fallback-x11
  - --device=dri
  - --share=ipc
  # ....
  - --talk-name=org.net_mydomain_MyApp.SingleInstance # Remember to change net_mydomain_MyApp to your app ID
  - --own-name=org.net_mydomain_MyApp.SingleInstance # Remember to change net_mydomain_MyApp to your app ID
# ...
```

## Permissions

Because this plugin currently does not have JavaScript APIs you do not have to configure capabilities to use it. No autogenerated permission reference exists for it.

## Notes

- The official Manual setup registers the plugin inside `setup()`, which runs after all `Builder::plugin` registrations; to satisfy the "register first" requirement, add it with `Builder::plugin` before other plugins as in the focus example and the Deep Linking page.
- The Single Instance plugin must be the first one to be registered to work well. This assures that it runs before other plugins can interfere.
- Tauri plugin (Rust core + system WebView). Not Electron's API; see the electron skill for Electron's `app.requestSingleInstanceLock()`.
- Source: `plugins-workspace@single-instance-v2.5.4` `plugins/single-instance/Cargo.toml`.
