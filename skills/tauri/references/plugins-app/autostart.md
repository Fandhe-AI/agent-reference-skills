# Autostart

Automatically launch your application at system startup. Plugin `tauri-plugin-autostart` 2.7.0 / `@tauri-apps/plugin-autostart` (plugins-workspace tag `autostart-v2.7.0`).

## Signature / Usage

```javascript
import { enable, isEnabled, disable } from '@tauri-apps/plugin-autostart';
// when using `"withGlobalTauri": true`, you may use
// const { enable, isEnabled, disable } = window.__TAURI__.autostart;

// Enable autostart
await enable();
// Check enable state
console.log(`registered for autostart? ${await isEnabled()}`);
// Disable autostart
disable();
```

Rust:

```rust
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .setup(|app| {
            #[cfg(desktop)]
            {
                use tauri_plugin_autostart::MacosLauncher;
                use tauri_plugin_autostart::ManagerExt;

                app.handle().plugin(tauri_plugin_autostart::init(
                    MacosLauncher::LaunchAgent,
                    Some(vec!["--flag1", "--flag2"]),
                ));

                // Get the autostart manager
                let autostart_manager = app.autolaunch();
                // Enable autostart
                let _ = autostart_manager.enable();
                // Check enable state
                println!("registered for autostart? {}", autostart_manager.is_enabled().unwrap());
                // Disable autostart
                let _ = autostart_manager.disable();
            }
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

### Setup

Automatic (run with the project's package manager):

```sh
npm run tauri add autostart
cargo tauri add autostart
```

Manual:

1. Add the plugin to `Cargo.toml` from the `src-tauri` folder:

```sh
cargo add tauri-plugin-autostart --target 'cfg(any(target_os = "macos", windows, target_os = "linux"))'
```

2. Initialize the plugin in `src-tauri/src/lib.rs`:

```rust
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .setup(|app| {
            #[cfg(desktop)]
            app.handle().plugin(tauri_plugin_autostart::init(tauri_plugin_autostart::MacosLauncher::LaunchAgent, Some(vec!["--flag1", "--flag2"]) /* arbitrary number of args to pass to your app */));
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

3. Install the JavaScript Guest bindings:

```sh
npm install @tauri-apps/plugin-autostart
```

### Permissions

By default all potentially dangerous plugin commands and scopes are blocked. Enable them in your `capabilities` configuration.

`src-tauri/capabilities/default.json`:

```json
{
  "permissions": [
    ...,
    "autostart:allow-enable",
    "autostart:allow-disable",
    "autostart:allow-is-enabled"
  ]
}
```

Default permission set `autostart:default`: allows checking, enabling and disabling the automatic start on boot. It includes `allow-enable`, `allow-disable`, `allow-is-enabled`.

| Identifier | Description |
| --- | --- |
| `autostart:allow-disable` | Enables the disable command without any pre-configured scope. |
| `autostart:allow-enable` | Enables the enable command without any pre-configured scope. |
| `autostart:allow-is-enabled` | Enables the is_enabled command without any pre-configured scope. |

Each `allow-*` has a matching `deny-*` (e.g. `autostart:deny-disable`) that denies the command.

## Notes

- Tauri plugin (Rust core + system WebView). Not Electron's API; see the electron skill for Electron's `app.setLoginItemSettings`.
- The Rust `init` takes a `MacosLauncher` (`LaunchAgent` in the official example) and optional args passed to the app at startup.
- Desktop only; register with `#[cfg(desktop)]`.
- Source: `plugins-workspace@autostart-v2.7.0` `plugins/autostart/{Cargo.toml,permissions/autogenerated/reference.md}`.
