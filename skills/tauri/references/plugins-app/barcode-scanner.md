# Barcode Scanner

Allows your mobile application to use the camera to scan QR codes, EAN-13 and other kinds of barcodes. Plugin `tauri-plugin-barcode-scanner` 2.5.3 / `@tauri-apps/plugin-barcode-scanner` (tag `barcode-scanner-v2.5.3`).

## Signature / Usage

JavaScript only:

```javascript
import { scan, Format } from '@tauri-apps/plugin-barcode-scanner';
// when using `"withGlobalTauri": true`, you may use
// const { scan, Format } = window.__TAURI__.barcodeScanner;

// `windowed: true` actually sets the webview to transparent
// instead of opening a separate view for the camera
// make sure your user interface is ready to show what is underneath with a transparent element
scan({ windowed: true, formats: [Format.QRCode] });
```

### Setup

Automatic:

```sh
npm run tauri add barcode-scanner
cargo tauri add barcode-scanner
```

Manual:

1. Add the dependency from `src-tauri`:

```sh
cargo add tauri-plugin-barcode-scanner --target 'cfg(any(target_os = "android", target_os = "ios"))'
```

2. Initialize in `src-tauri/src/lib.rs`:

```rust
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .setup(|app| {
            #[cfg(mobile)]
            app.handle().plugin(tauri_plugin_barcode_scanner::init());
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

3. `npm install @tauri-apps/plugin-barcode-scanner`

### Configuration

On iOS the plugin requires the `NSCameraUsageDescription` Info.plist value, describing why your app needs the camera. In `src-tauri/Info.ios.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
	<dict>
		<key>NSCameraUsageDescription</key>
		<string>Read QR codes</string>
	</dict>
</plist>
```

### Permissions

`src-tauri/capabilities/mobile.json`:

```json
{
  "$schema": "../gen/schemas/mobile-schema.json",
  "identifier": "mobile-capability",
  "windows": ["main"],
  "platforms": ["iOS", "android"],
  "permissions": ["barcode-scanner:allow-scan", "barcode-scanner:allow-cancel"]
}
```

Default permission set `barcode-scanner:default`: allows all barcode related features. It includes `allow-cancel`, `allow-check-permissions`, `allow-open-app-settings`, `allow-request-permissions`, `allow-scan`, `allow-vibrate`.

| Identifier | Description |
| --- | --- |
| `barcode-scanner:allow-cancel` | Enables the cancel command without any pre-configured scope. |
| `barcode-scanner:allow-check-permissions` | Enables the check_permissions command without any pre-configured scope. |
| `barcode-scanner:allow-open-app-settings` | Enables the open_app_settings command without any pre-configured scope. |
| `barcode-scanner:allow-request-permissions` | Enables the request_permissions command without any pre-configured scope. |
| `barcode-scanner:allow-scan` | Enables the scan command without any pre-configured scope. |
| `barcode-scanner:allow-vibrate` | Enables the vibrate command without any pre-configured scope. |

Each `allow-*` has a matching `deny-*` (e.g. `barcode-scanner:deny-scan`).

## Notes

- With `windowed: true` the webview is set to transparent instead of opening a separate camera view; make sure your UI can show what is underneath.
- Mobile only (Android / iOS); register under `#[cfg(mobile)]`.
- Tauri plugin (Rust core + system WebView). Not Electron's API; see the electron skill for Electron (it has no mobile targets).
- Source: `plugins-workspace@barcode-scanner-v2.5.3` `plugins/barcode-scanner/{Cargo.toml,permissions/autogenerated/reference.md}`.
