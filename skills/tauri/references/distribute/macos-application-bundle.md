# macOS Application Bundle

An application bundle is the package format executed on macOS: a directory that includes the app executable, resources, the `Info.plist` file and other files such as frameworks.

## Signature / Usage

```sh
cargo tauri build --bundles app
```

File structure:

```
├── <productName>.app
│   ├── Contents
│   │   ├── Info.plist
│   │   ├── ...additional files from tauri.conf.json > bundle > macOS > files
│   ├── MacOS
│   │   ├── <app-name> (app executable)
│   ├── Resources
│   │   ├── icon.icns (app icon)
│   │   ├── ...resources from tauri.conf.json > bundle > resources
│   ├── _CodeSignature (codesign information generated by Apple)
│   ├── Frameworks
│   ├── PlugIns
│   ├── SharedSupport
```

## Options / Props

| Config key | Description |
| --- | --- |
| `bundle > macOS > entitlements` | Path to the `Entitlements.plist` applied when signing |
| `bundle > macOS > minimumSystemVersion` | Minimum macOS version; default support is macOS 10.13 and above |
| `bundle > macOS > frameworks` | System or custom frameworks and dylib files to include |
| `bundle > macOS > files` | Map of destination path (under `<product-name>.app/Contents`) to source path relative to `tauri.conf.json` |
| `bundle > resources` | Resources copied to `Resources` (used for `InfoPlist.strings`) |

## Native configuration

Tauri configures the most important `Info.plist` properties (binary name, version, bundle identifier, minimum system version and more). To extend it, create `src-tauri/Info.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
	<key>NSCameraUsageDescription</key>
	<string>Request camera access for WebRTC</string>
	<key>NSMicrophoneUsageDescription</key>
	<string>Request microphone access for WebRTC</string>
</dict>
</plist>
```

### Info.plist localization

`Info.plist` supports a single language. For more, create `InfoPlist.strings` per language in `<lang-code>.lproj` directories (the file must be named `InfoPlist.strings`; use two-letter BCP 47 codes in most cases):

```
├── src-tauri
│   ├── tauri.conf.json
│   ├── infoplist
│   │   ├── de.lproj
│   │   │   ├── InfoPlist.strings
│   │   ├── fr.lproj
│   │   │   ├── InfoPlist.strings
```

```ini
NSCameraUsageDescription = "Kamera Zugriff wird benötigt für WebRTC Funktionalität";
NSMicrophoneUsageDescription = "Mikrofon Zugriff wird benötigt für WebRTC Funktionalität";
```

```json
{
  "bundle": {
    "resources": {
      "infoplist/**": "./"
    }
  }
}
```

## Entitlements

Entitlements are Apple key-value pairs that grant particular capabilities (e.g. App Sandbox). They are applied when the app is signed. Create `src-tauri/Entitlements.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>com.apple.security.app-sandbox</key>
    <true/>
</dict>
</plist>
```

```json
{
  "bundle": {
    "macOS": {
      "entitlements": "./Entitlements.plist"
    }
  }
}
```

## Minimum system version

```json
{
  "bundle": {
    "macOS": {
      "minimumSystemVersion": "12.0"
    }
  }
}
```

## Including macOS frameworks

```json
{
  "bundle": {
    "macOS": {
      "frameworks": [
        "CoreAudio",
        "./libs/libmsodbcsql.18.dylib",
        "./frameworks/MyApp.framework"
      ]
    }
  }
}
```

## Adding custom files

```json
{
  "bundle": {
    "macOS": {
      "files": {
        "embedded.provisionprofile": "./profile-name.provisionprofile",
        "SharedSupport/docs.md": "./docs/index.md"
      }
    }
  }
}
```

`profile-name.provisionprofile` is copied to `<product-name>.app/Contents/embedded.provisionprofile` and `docs/index.md` to `<product-name>.app/Contents/SharedSupport/docs.md`.

## Notes

- The tauri-generated `Info.plist` is merged with your file; be careful overwriting defaults such as the application version, which may conflict with other configuration values.
- GUI apps on macOS and Linux do not inherit `$PATH` from shell dotfiles (`.bashrc`, `.bash_profile`, `.zshrc`); see the `fix-path-env-rs` crate.
- Frameworks: reference a system framework by name without the `.framework` extension; system frameworks must exist in `$HOME/Library/Frameworks`, `/Library/Frameworks/` or `/Network/Library/Frameworks/`; local frameworks and dylibs need the full path relative to `src-tauri`.
- Run `tauri build` on a Mac.
