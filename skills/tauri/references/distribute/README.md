# distribute

| Name | Description | Path |
|------|-------------|------|
| App Store | The Apple App Store is the app marketplace maintained by Apple for macOS and iOS apps; this guide covers direct App Store distribution only. | [app-store.md](./app-store.md) |
| AppImage | `AppImage` is a distribution format that bundles all dependencies instead of relying on system packages; output is larger (2-6 MB to 70+ MB) but runs on many Linux distributions without installation. | [appimage.md](./appimage.md) |
| AUR | Publishing to the Arch User Repository (AUR). | [aur.md](./aur.md) |
| CrabNebula Cloud | CrabNebula is an official Tauri partner; CrabNebula Cloud is an application distribution platform that integrates with the Tauri updater. | [crabnebula-cloud.md](./crabnebula-cloud.md) |
| Debian | The stock Debian package generated by the Tauri bundler defines the app icons, a Desktop file, and the dependencies `libwebkit2gtk-4.1-0` and `libgtk-3-0` (plus `libappindicator3-1` for the system tray). | [debian.md](./debian.md) |
| DMG | The DMG (Apple Disk Image) is the common macOS installer that wraps the App Bundle in an installation window with the app and Applications folder icons, used for distribution outside the App Store. | [dmg.md](./dmg.md) |
| Flatpak | Distribute a Tauri app as a Flatpak via Flathub. The source page (titled "Flathub") has two tabs: Open Source and Closed Source. | [flatpak.md](./flatpak.md) |
| Google Play | Google Play is the Android app distribution service maintained by Google; this guide covers the requirements for publishing an Android app on Google Play. | [google-play.md](./google-play.md) |
| macOS Application Bundle | An application bundle is the macOS package format: a directory containing the app executable, resources, the `Info.plist` file, and other files such as frameworks. | [macos-application-bundle.md](./macos-application-bundle.md) |
| Microsoft Store | Microsoft Store is the Windows app store operated by Microsoft; this guide covers direct distribution of Windows apps to the Microsoft Store only. | [microsoft-store.md](./microsoft-store.md) |
| Distribute | Tauri provides the tooling to distribute your application either to the platform app stores or as platform-specific installers. | [overview.md](./overview.md) |
| GitHub (pipelines) | Use `tauri-action` in GitHub Actions to build and upload your app, have Tauri's updater query the newly created GitHub release, and set up a more complicated pipeline for Linux Arm AppImages. | [pipelines-github.md](./pipelines-github.md) |
| RPM | How to distribute and manage RPM packages: configuring scripts, setting dependencies, adding a license, signing and debugging packages. Some sections (scripts and certain other steps) are optional. | [rpm.md](./rpm.md) |
| Android Code Signing | To publish on the Play Store, sign your app with a digital certificate; Android App Bundles and APKs must be signed before being uploaded for distribution. | [sign-android.md](./sign-android.md) |
| iOS Code Signing | Code signing on iOS is required to distribute through the Apple App Store (or alternative marketplaces in the European Union) and to install and run on end-user devices. | [sign-ios.md](./sign-ios.md) |
| Linux Code Signing | Code signing for Linux packages. Artifact signing is not required to deploy on Linux but increases trust, letting end users verify that binaries are genuine and unmodified. | [sign-linux.md](./sign-linux.md) |
| macOS Code Signing | Code signing is required on macOS to list your app in the Apple App Store and to avoid a "broken application" warning for browser downloads; distribution outside the App Store with a Developer ID Application certificate also requires notarization. | [sign-macos.md](./sign-macos.md) |
| Windows Code Signing | Code signing is required on Windows to list your app in the Microsoft Store and to avoid a SmartScreen warning (not required to execute); covers OV certificates, Azure Key Vault and Azure Artifact Signing, and the custom sign command for other mechanisms. | [sign-windows.md](./sign-windows.md) |
| Snapcraft | Distribute your app on Snapcraft.io by building a snap from the Tauri `.deb` bundle. | [snapcraft.md](./snapcraft.md) |
| Windows Installer (MSI / NSIS) | Tauri applications for Windows are distributed either as Microsoft Installers (`.msi`, using the WiX Toolset v3, buildable only on Windows) or as setup executables (`-setup.exe`, using NSIS). | [windows-installer.md](./windows-installer.md) |
