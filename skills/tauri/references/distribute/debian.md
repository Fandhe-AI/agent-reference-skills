# Debian

The stock Debian package generated by the Tauri bundler has everything needed to ship your application to Debian-based Linux distributions: it defines the app icons, generates a Desktop file, and specifies the dependencies `libwebkit2gtk-4.1-0` and `libgtk-3-0`, along with `libappindicator3-1` if your app uses the system tray.

## Signature / Usage

Include custom files in the package with `tauri.conf.json > bundle > linux > deb > files` (package path mapped to a path relative to `tauri.conf.json`):

```json
{
  "bundle": {
    "linux": {
      "deb": {
        "files": {
          "/usr/share/README.md": "../README.md", // copies the README.md file to /usr/share/README.md
          "/usr/share/assets": "../assets/" // copies the entire assets directory to /usr/share/assets
        }
      }
    }
  }
}
```

Additional system dependencies can be specified in `tauri.conf.json > bundle > linux > deb`.

## Cross-Compiling for ARM-based Devices

Manual compilation steps (Debian/Ubuntu host). For ARMv7 use `armv7-unknown-linux-gnueabihf` / `armhf`, for ARMv8 (ARM64) use `aarch64-unknown-linux-gnu` / `arm64`.

1. Install Rust targets:
   - `rustup target add armv7-unknown-linux-gnueabihf`
   - `rustup target add aarch64-unknown-linux-gnu`
2. Install the linker: `sudo apt install gcc-arm-linux-gnueabihf` or `sudo apt install gcc-aarch64-linux-gnu`
3. In `<project-root>/.cargo/config.toml`:

```toml
[target.armv7-unknown-linux-gnueabihf]
linker = "arm-linux-gnueabihf-gcc"

[target.aarch64-unknown-linux-gnu]
linker = "aarch64-linux-gnu-gcc"
```

4. Enable the architecture: `sudo dpkg --add-architecture armhf` or `sudo dpkg --add-architecture arm64`
5. Adjust package sources. On Debian this should not be necessary; on other distributions edit `/etc/apt/sources.list` to include the ARM variant (replace `jammy` with your Ubuntu codename). Example lines for Ubuntu 22.04 appended to the file:

```
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy main restricted
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy-updates main restricted
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy universe
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy-updates universe
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy multiverse
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy-updates multiverse
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy-backports main restricted universe multiverse
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy-security main restricted
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy-security universe
deb [arch=armhf,arm64] http://ports.ubuntu.com/ubuntu-ports jammy-security multiverse
```

   Then add `[arch=amd64]` to all other (pre-existing) `deb` lines for standard 64-bit systems, e.g. `deb [arch=amd64] http://archive.ubuntu.com/ubuntu/ jammy main restricted`.
6. `sudo apt-get update && sudo apt-get upgrade -y`
7. Install webkitgtk: `sudo apt install libwebkit2gtk-4.1-dev:armhf` or `:arm64`
8. OpenSSL (not always required; needed if you see `Failed to find OpenSSL development headers`): `sudo apt install libssl-dev:armhf` / `:arm64`, or vendor it in `Cargo.toml`:

```toml
openssl-sys = {version = "0.9", features = ["vendored"]}
```

9. Set `PKG_CONFIG_SYSROOT_DIR`: `export PKG_CONFIG_SYSROOT_DIR=/usr/arm-linux-gnueabihf/` (ARMv7) or `export PKG_CONFIG_SYSROOT_DIR=/usr/aarch64-linux-gnu/` (ARM64)
10. Build: `cargo tauri build --target armv7-unknown-linux-gnueabihf` or `cargo tauri build --target aarch64-unknown-linux-gnu`

## Notes

- Limitations: build with the oldest base system you intend to support that also provides Tauri v2's required WebKitGTK 4.1 packages (Ubuntu 22.04 and Debian 12 are suitable baselines because they provide `libwebkit2gtk-4.1-dev`). A newer base can raise the minimum glibc and cause runtime errors like `/usr/lib/libc.so.6: version 'GLIBC_2.33' not found`. Use Docker or GitHub Actions to build for Linux (see tauri-apps/tauri#1355, rust-lang/rust#57497).
- The official page also shows the complete Ubuntu 22.04 `sources.list` after the `[arch=amd64]` edit (collapsed "ShowSolution" block); it is not reproduced here.
- Steps may vary depending on your Linux distribution and setup. A QEMU based GitHub Action alternative is slower but also builds AppImages (see the GitHub pipelines page, Arm Runner Compilation).
- GUI apps on Linux do not inherit `$PATH` from shell dotfiles; see the `fix-path-env-rs` crate.
