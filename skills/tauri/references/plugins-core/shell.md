# Shell

Access the system shell. Allows you to spawn child processes.

## Signature / Usage

### Supported Platforms

| Platform | Level | Notes |
| --- | --- | --- |
| Windows | full | |
| Linux | full | |
| macOS | full | |
| Android | partial | Only allows to open URLs via `open` |
| iOS | partial | Only allows to open URLs via `open` |

(`shell-v2.5.0`.)

### Setup

```sh
npm run tauri add shell
# or: cargo tauri add shell
```

Manual. From `src-tauri`:

```sh
cargo add tauri-plugin-shell
```

From the project root, install the JavaScript guest bindings:

```sh
npm install @tauri-apps/plugin-shell
```

```rust
// src-tauri/src/lib.rs
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_shell::init())
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

### Usage

JavaScript:

```javascript
import { Command } from '@tauri-apps/plugin-shell';
// when using `"withGlobalTauri": true`, you may use
// const { Command } = window.__TAURI__.shell;

let result = await Command.create('git-version', ['--version']).execute();
console.log(result);
```

Rust:

```rust
use tauri_plugin_shell::ShellExt;

let shell = app_handle.shell();
let output = tauri::async_runtime::block_on(async move {
		shell
				.command("echo")
				.args(["Hello from Rust!"])
				.output()
				.await
				.unwrap()
});
if output.status.success() {
		println!("Result: {:?}", String::from_utf8(output.stdout));
} else {
		println!("Exit with code: {}", output.status.code().unwrap());
}
```

### Permissions

Commands must be declared with a scope in the capability (`name` is the identifier used from JavaScript, `cmd` the executable, `args` fixed arguments or a validator):

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "main-capability",
  "description": "Capability for the main window",
  "windows": ["main"],
  "permissions": [
    {
      "identifier": "shell:allow-execute",
      "allow": [
        {
          "name": "git-version",
          "cmd": "git",
          "args": ["--version"],
          "sidecar": false
        }
      ]
    }
  ]
}
```

`shell:default` allows the `open` functionality with a reasonable scope pre-configured (opening `http(s)://`, `tel:` and `mailto:` links); it includes `allow-open`.

| Identifier | Notes |
| --- | --- |
| `shell:allow-execute` | execute a command |
| `shell:allow-kill` | kill a spawned child |
| `shell:allow-open` | open (default) |
| `shell:allow-spawn` | spawn a child process |
| `shell:allow-stdin-write` | write to a child's stdin |

## Notes

- Tauri plugin (Rust core + system WebView). Not Electron's `shell` module. For the `shell.open` API, use the Opener plugin instead (see [opener.md](./opener.md)). To access the current process (exit / relaunch) see the Process plugin.
- The official example scopes `sh -c` with the validator `\\S+`, which allows arbitrary commands; it is replaced here with a fixed `cmd`/`args` example.
- The upstream example uses an `exec-sh` command; it was replaced with a fixed-argument `git --version` scope, so the call passes `['--version']` to match the allowed `args`.
- Source: `tauri-apps/plugins-workspace@shell-v2.5.0` `plugins/shell/Cargo.toml`, `plugins/shell/permissions/autogenerated/reference.md`; docs `plugin/shell.mdx` @ `32f68c5`.
