# Websocket

Open a WebSocket connection using a Rust client in JavaScript.

## Supported Platforms

Windows, Linux, macOS, Android, iOS: full support (`websocket-v2.5.0`).

## Setup

```sh
npm run tauri add websocket
# or: cargo tauri add websocket
```

Manual. From `src-tauri`:

```sh
cargo add tauri-plugin-websocket
```

From the project root, install the JavaScript guest bindings:

```sh
npm install @tauri-apps/plugin-websocket
```

```rust
// src-tauri/src/lib.rs
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_websocket::init())
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

## Signature / Usage

The websocket plugin is available in JavaScript.

```javascript
import WebSocket from '@tauri-apps/plugin-websocket';
// when using `"withGlobalTauri": true`, you may use
// const WebSocket = window.__TAURI__.websocket;

const ws = await WebSocket.connect('ws://127.0.0.1:8080');

const removeListener = ws.addListener((msg) => {
  console.log('Received Message:', msg);
});

await ws.send('Hello World!');

// when the listener is no longer needed (e.g. after a reply has been received),
// remove it and disconnect:
// removeListener();
// await ws.disconnect();
```

## Permissions

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "main-capability",
  "description": "Capability for the main window",
  "windows": ["main"],
  "permissions": ["websocket:default"]
}
```

`websocket:default` allows connecting and sending data to a WebSocket server (`allow-connect`, `allow-send`).

| Identifier | Notes |
| --- | --- |
| `websocket:allow-connect` / `websocket:deny-connect` | connect command without any pre-configured scope |
| `websocket:allow-send` / `websocket:deny-send` | send command |

## Notes

- Tauri plugin (Rust core + system WebView). The connection is made by a Rust client on the backend, not the webview's `WebSocket`. WebSocket servers for the Rust, Node.js and Hono stacks are covered by the fandhe-backend, fastify and hono skills.
- The official snippet calls `removeListener()` and `disconnect()` right after `send`, which can detach the listener before a reply arrives; here they are commented and should run only after a reply is received (awaiting `send` does not wait for a response).
- Source: `tauri-apps/plugins-workspace@websocket-v2.5.0` `plugins/websocket/Cargo.toml`, `plugins/websocket/permissions/autogenerated/reference.md`; docs `plugin/websocket.mdx` @ `32f68c5`.
