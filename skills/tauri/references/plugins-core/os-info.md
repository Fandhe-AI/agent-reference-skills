# OS Information

Read information about the operating system using the OS Information plugin.

## Signature / Usage

### Supported Platforms

Windows, Linux, macOS, Android, iOS: full support (`os-v2.4.0`).

### Setup

```sh
npm run tauri add os
# or: cargo tauri add os
```

Manual:

From `src-tauri`:

```sh
cargo add tauri-plugin-os
```

From the project root, install the JavaScript guest bindings:

```sh
npm install @tauri-apps/plugin-os
```

```rust
// src-tauri/src/lib.rs
#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_os::init())
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

### Usage

`platform` returns a string describing the specific operating system in use. The value is set at compile time. Possible values are `linux`, `macos`, `ios`, `freebsd`, `dragonfly`, `netbsd`, `openbsd`, `solaris`, `android`, `windows`.

JavaScript:

```javascript
import { platform } from '@tauri-apps/plugin-os';
// when using `"withGlobalTauri": true`, you may use
// const { platform } = window.__TAURI__.os;

const currentPlatform = platform();
console.log(currentPlatform);
// Prints "windows" to the console
```

Rust:

```rust
let platform = tauri_plugin_os::platform();
println!("Platform: {}", platform);
// Prints "windows" to the terminal
```

### Permissions

```json
{
  "permissions": [
    ...,
    "os:default"
  ]
}
```

`os:default` makes all information available except the host name: `allow-arch`, `allow-exe-extension`, `allow-family`, `allow-locale`, `allow-os-type`, `allow-platform`, `allow-version`.

| Identifier | Notes |
| --- | --- |
| `os:allow-arch` | CPU architecture |
| `os:allow-exe-extension` | executable extension |
| `os:allow-family` | OS family |
| `os:allow-hostname` | host name (not in default) |
| `os:allow-locale` | locale |
| `os:allow-os-type` | OS type |
| `os:allow-platform` | platform |
| `os:allow-version` | OS version |
