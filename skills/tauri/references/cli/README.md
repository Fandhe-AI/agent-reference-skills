# cli

| Name | Description | Path |
|------|-------------|------|
| tauri add / tauri remove | Add a tauri plugin to the project, or remove one from it. | [add-remove.md](./add-remove.md) |
| tauri android | Android commands: `init`, `dev`, `build`, `run`. | [android.md](./android.md) |
| tauri build | Build your app in release mode and generate bundles and installers. | [build.md](./build.md) |
| tauri bundle | Generate bundles and installers for your app (already built by `tauri build`). | [bundle.md](./bundle.md) |
| tauri capability | Manage or create capabilities for your app: `new`. | [capability.md](./capability.md) |
| tauri completions | Generate Tauri CLI shell completions for Bash, Zsh, PowerShell or Fish. | [completions.md](./completions.md) |
| tauri dev | Run your app in development mode with hot-reloading for the Rust code. | [dev.md](./dev.md) |
| tauri icon | Generate various icons for all major platforms. | [icon.md](./icon.md) |
| tauri info | Show a concise list of information about the environment, Rust, Node.js and their versions as well as a few relevant project configurations. | [info.md](./info.md) |
| tauri init | Initialize a Tauri project in an existing directory. | [init.md](./init.md) |
| tauri inspect | Inspect values used by Tauri: `wix-upgrade-code`. | [inspect.md](./inspect.md) |
| tauri ios | iOS commands: `init`, `dev`, `build`, `run`. All iOS commands are only available on macOS hosts. | [ios.md](./ios.md) |
| tauri migrate | Migrate from v1 to v2. | [migrate.md](./migrate.md) |
| Command Line Interface | The Tauri command line interface (CLI) is the way to interact with Tauri throughout the development lifecycle. | [overview.md](./overview.md) |
| tauri permission | Manage or create permissions for your app or plugin: `new`, `add`, `rm`, `ls`. | [permission.md](./permission.md) |
| tauri plugin | Manage or create Tauri plugins: `new`, `init`, `android`, `ios`. | [plugin.md](./plugin.md) |
| tauri signer | Generate signing keys for Tauri updater or sign files: `sign`, `generate`. | [signer.md](./signer.md) |
