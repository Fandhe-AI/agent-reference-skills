# stockFeatures

The complete set of stock optional table features.

## Signature / Usage

```ts
const stockFeatures: StockFeatures;
```

## Notes

- Use individual feature exports for better tree-shaking, or reference `stockFeatures` when a table needs to incorporate all available built-in features.
