# feature-guides

| Name | Description | Path |
| --- | --- | --- |
| Cell Selection | Spreadsheet-style rectangular cell selection (click/drag/Shift/Ctrl) | [cell-selection.md](./cell-selection.md) |
| Cell Spanning | Stateless rowspan/colspan-style merging of adjacent body cells | [cell-spanning.md](./cell-spanning.md) |
| Column Ordering | Manual reordering of columns via `columnOrder` state | [column-ordering.md](./column-ordering.md) |
| Column Pinning | Pins columns to logical start/end regions | [column-pinning.md](./column-pinning.md) |
| Column Sizing | Fixed/min/max column widths | [column-sizing.md](./column-sizing.md) |
| Column Resizing | User drag-to-resize columns, built on Column Sizing | [column-resizing.md](./column-resizing.md) |
| Column Visibility | Dynamically hide/show columns | [column-visibility.md](./column-visibility.md) |
| Column Filtering | Per-column filter, client-side or manual server-side | [column-filtering.md](./column-filtering.md) |
| Global Filtering | Single filter value applied across all columns | [global-filtering.md](./global-filtering.md) |
| Fuzzy Filtering | Approximate-match filtering via a custom filterFn | [fuzzy-filtering.md](./fuzzy-filtering.md) |
| Faceting | Filter-UI metadata: unique values/counts, min/max per column | [column-faceting.md](./column-faceting.md) |
| Aggregation | Summary values (sum, mean, count, etc.) over rows, independent of grouping | [aggregation.md](./aggregation.md) |
| Grouping | Categorizes rows into synthetic parent rows by column value | [grouping.md](./grouping.md) |
| Expanding | Shows/hides sub-rows or custom detail-panel UI | [expanding.md](./expanding.md) |
| Pagination | Client-side or manual server-side row pagination | [pagination.md](./pagination.md) |
| Row Pinning | Keeps selected rows in top/bottom regions | [row-pinning.md](./row-pinning.md) |
| Row Selection | Tracks selected rows with checkbox/radio-style toggling | [row-selection.md](./row-selection.md) |
| Sorting | Client-side and manual server-side row sorting | [sorting.md](./sorting.md) |
| Virtualization | Renders only visible rows/columns for very large tables (via TanStack Virtual) | [virtualization.md](./virtualization.md) |
