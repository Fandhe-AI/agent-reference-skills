# LegacyRow

Row instance type bound to `LegacyFeatures`.

## Signature / Usage

```ts
type LegacyRow<TData extends RowData> = Row<LegacyFeatures, TData>
```

## Notes

- **v9 status: present as a deprecated type alias, renamed to `Row<TFeatures, TData>`.** Use it with `useTable` instead.
