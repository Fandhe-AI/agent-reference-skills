# LegacyHeaderGroup

Header group instance type bound to `LegacyFeatures`.

## Signature / Usage

```ts
type LegacyHeaderGroup<TData extends RowData> = HeaderGroup<LegacyFeatures, TData>
```

## Notes

- **v9 status: present as a deprecated type alias, renamed to `HeaderGroup<TFeatures, TData>`.** Use it with `useTable` instead.
