# LegacyTable

Table instance type bound to `LegacyFeatures`.

## Signature / Usage

```ts
type LegacyTable<TData extends RowData> = Table<LegacyFeatures, TData>
```

## Notes

- **v9 status: present as a deprecated type alias, renamed to `Table<TFeatures, TData>`.** Use it with `useTable` instead.
