# getFacetedUniqueValues

Stub function for v8 API compatibility with `useLegacyTable`. Acts as a marker to enable the faceted unique values.

## Signature / Usage

```tsx
function getFacetedUniqueValues<TData extends RowData>(): FacetedUniqueValuesFactory<TData>
```

## Notes

- **v9 status: present as a deprecated stub, renamed to `createFacetedUniqueValues()`.** Pass it in the `facetedUniqueValues` feature slot with the new `useTable` hook instead.
