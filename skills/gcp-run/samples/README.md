| Cloud Run Job with Task Overrides and Retries | Create a Cloud Run job, tune its task count, retries, parallelism and timeout, then run executions with per-execution overrides and wait for or cancel them. | [job-overrides-and-retries.md](./job-overrides-and-retries.md) |
| Use Secret Manager Secrets as Environment Variables and Mounted Files | Expose Secret Manager secrets to a Cloud Run service as an environment variable or as a file, update them, and remove them, with the service running as a service account that may read the secrets. | [secrets-env-and-volume.md](./secrets-env-and-volume.md) |
| Gradual Rollout and Rollback with Revision Tags | Deploy a new revision with no traffic and a tag, test it on its tag URL with an identity token, shift traffic in steps, and roll back or clean up. | [gradual-rollout-with-tags.md](./gradual-rollout-with-tags.md) |
| Reach a Private VPC Resource with Direct VPC Egress or a Connector | Send Cloud Run traffic to a VPC network, preferably with Direct VPC egress and otherwise with a Serverless VPC Access connector. | [direct-vpc-egress-and-connector.md](./direct-vpc-egress-and-connector.md) |

| Deploy and Manually Scale a Cloud Run Worker Pool | Deploy a worker pool for continuous background work (no inbound HTTP endpoint), connect it to a VPC with Direct VPC, scale it with a fixed instance count, and disable it. | [worker-pool-deploy-and-scale.md](./worker-pool-deploy-and-scale.md) |
