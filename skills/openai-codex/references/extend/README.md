# Extend

| Name | Description | Path |
| --- | --- | --- |
| Scheduled tasks | Schedule recurring tasks to run in the background (formerly "automations"). Review active, paused, and completed tasks and recent runs in **Scheduled**. | [automations.md](./automations.md) |
| Browser | Browser lets ChatGPT open websites, gather current information, and act while you stay in control. In the ChatGPT desktop app it is a built-in browser shared between you and ChatGPT; on web, ChatGPT Work uses a cloud browser. | [browser.md](./browser.md) |
| Build skills | Agent skills package instructions, resources, and optional scripts so ChatGPT or Codex can follow a workflow reliably. Built on the open agent skills standard (agentskills.io). | [build-skills.md](./build-skills.md) |
| Computer Use | With Computer Use, ChatGPT can see and operate graphical user interfaces on macOS or Windows (ChatGPT desktop app, with ChatGPT Work and Codex, in supported regions). | [computer-use.md](./computer-use.md) |
| Plugins | Plugins bundle capabilities (skills, MCP servers, browser extensions, hooks) into reusable workflows in ChatGPT and Codex. Both products share one universal plugin directory. | [plugins.md](./plugins.md) |
| Record & Replay | Demonstrate a workflow on your Mac and turn it into a reusable skill, without writing a prompt from scratch. | [record-and-replay.md](./record-and-replay.md) |
| Web search | ChatGPT includes a first-party web search tool. Treat all web results as untrusted input. | [web-search.md](./web-search.md) |
