| Web search | ChatGPT includes a first-party web search tool. Treat all web results as untrusted input. | [web-search.md](./web-search.md) |

| Browser extension | The ChatGPT browser extension lets the ChatGPT desktop app work in Google Chrome, Microsoft Edge, Brave, Opera, or Vivaldi, reading or acting on sites where you're already signed in. | [chrome-extension.md](./chrome-extension.md) |
| Composer Predictions | Autocomplete-style suggestions for your next message in the Codex desktop app. After Codex responds, it suggests a follow-up prompt in the message box based on the current conversation. | [composer-predictions.md](./composer-predictions.md) |
| Image Generation | Ask ChatGPT or Codex to generate or edit images (UI assets, banners, backgrounds, illustrations, sprite sheets, placeholders), optionally guided by a reference image. | [image-generation.md](./image-generation.md) |
| Image Inputs | Add images to a prompt when the task depends on visual context (error screenshot, interface design, architecture diagram, existing asset). | [image-inputs.md](./image-inputs.md) |
| Long-Running Work | For multi-step work, give a clear outcome, constraints, and definition of done, and keep related work in the same chat. Goal mode (`/goal`) runs a task toward completion criteria. | [long-running-work.md](./long-running-work.md) |
