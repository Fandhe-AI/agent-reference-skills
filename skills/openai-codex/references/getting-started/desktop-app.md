# ChatGPT desktop app

Run projects in parallel, work with files, use your computer, and keep long-running work moving from one desktop workspace.

## Signature / Usage

Get-started flow (the page has no code; steps are reproduced as a text block):

```text
1. Install the ChatGPT desktop app. Download ChatGPT (https://chatgpt.com/download/) for macOS or Windows, or follow the Linux installation guide.
2. Open ChatGPT and sign in with your ChatGPT account.
3. Choose where to work: start a chat, create a project, or open a folder.
4. Send your first message. Choose ChatGPT or Codex.
   - ChatGPT: use the toggle above the composer to select Chat or Work.
   - Codex: start with New chat. For a quick question, point to New chat and select the Quick chat icon on its right.
```

## Notes

- Why use it: keep every chat in view across projects and long-running work; create and inspect real outputs (documents, spreadsheets, images, other files) in the same workspace; work across the browser, desktop apps, and plugins, or schedule a task inside a chat.
- Use the desktop app when you want to coordinate several projects, create and review files, use the browser and your computer, or schedule recurring work (a standalone scheduled task, or a task inside an existing chat).
- macOS and Windows builds are downloaded from `https://chatgpt.com/download/`; Linux is installed by following the Linux guide (preview).
- Sample use cases listed on the page: daily work brief, analyzing a data export into interactive visuals, drafting a PRD from sources, cleaning messy CSV/spreadsheet data into a copy, and synthesizing feedback into actions.
- Source: https://learn.chatgpt.com/docs/app (retrieved 2026-10).
