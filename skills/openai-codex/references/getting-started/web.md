# ChatGPT on the Web

Landing and quickstart page for using ChatGPT (Chat and Work) at chatgpt.com to research, analyze, and create documents, presentations, spreadsheets, and other outputs.

## Signature / Usage

```text
https://chatgpt.com
```

### Quickstart

1. Go to chatgpt.com and sign in with your ChatGPT account.
2. Select **Work** for research, analysis, documents, spreadsheets, presentations, Sites, and other multi-step tasks; select **Chat** for an answer or conversation.
3. Start a chat for a one-off task, or choose a project to keep related chats, files, and instructions together.
4. Send your first message: describe the result you want and add files or context; refine with follow-ups.

## Options / Props

| Need | Where to go |
|------|-------------|
| Choose Chat or Work | Chat to explore a question; Work for a clear outcome that needs planning and context gathering. |
| Model and reasoning | Select from the composer; start with the default effort, raise it for deeper planning, analysis, or larger multi-agent runs. |
| Tools and repeatable workflows | Install plugins (Google Drive, GitHub, Slack); add skills for specific workflows or team guidance. |
| Finished files | Create a document, presentation, spreadsheet, or PDF from source material; request focused revisions and download. |

## Notes

- Use the web when you need a multi-step task completed, deeper reasoning, work that depends on your tools and context, or a reviewable and shareable file.
- Source: https://learn.chatgpt.com/docs/web (retrieved 2026-11-14).
