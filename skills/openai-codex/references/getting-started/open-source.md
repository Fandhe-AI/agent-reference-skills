# Open Source

OpenAI develops key parts of Codex in the open on GitHub; follow progress, report issues, and request improvements there.

## Signature / Usage

```text
When you file an issue, include which component you are using (CLI, SDK, IDE extension, Codex cloud, or Codex Security) and the version where possible.
```

## Options / Props

### Open-source components

| Component | Where to find | Notes |
|-----------|---------------|-------|
| Codex CLI | https://github.com/openai/codex | The primary home for Codex open-source development |
| Codex SDK | https://github.com/openai/codex/tree/main/sdk | SDK sources live in the Codex repo |
| Codex Security CLI | https://github.com/openai/codex-security | CLI for finding and validating security vulnerabilities |
| Codex Security TypeScript SDK | https://github.com/openai/codex-security/tree/main/sdk/typescript | TypeScript SDK for running Codex Security scans |
| Codex App Server | https://github.com/openai/codex/tree/main/codex-rs/app-server | App-server sources live in the Codex repo |
| Skills | https://github.com/openai/skills | Reusable skills that extend ChatGPT and Codex |
| Plugins | https://github.com/openai/plugins | Reusable plugins for ChatGPT and Codex |
| IDE extension | - | Not open source |
| Codex cloud | - | Not open source |
| Universal cloud environment | https://github.com/openai/codex-universal | Base environment used by Codex cloud |

### Where to report issues

- Codex bugs and feature requests: https://github.com/openai/codex/issues
- Codex Security CLI and TypeScript SDK: https://github.com/openai/codex-security/issues
- Discussion forum: https://github.com/openai/codex/discussions

## Notes

- `openai/codex` accepts community contributions through issues (bug reports, reproduction steps, root-cause analysis) but does not accept external code contributions or pull requests; see https://github.com/openai/codex/blob/main/docs/contributing.md.
- Maintainers of widely used open-source projects can apply to the Codex for OSS program (API credits, ChatGPT Pro with Codex, selective access to Codex Security): https://developers.openai.com/community/codex-for-oss
- Source: https://learn.chatgpt.com/docs/open-source (retrieved 2026-11-14).
