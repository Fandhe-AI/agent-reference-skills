# scripts

Vercel CLI 自体は `vercel` スキルを参照。

| Name | Description | Path |
| --- | --- | --- |
| Create Project | Scaffold a new TanStack Start project via the official CLI, or start from an official example. | [create-project.md](./create-project.md) |
| Deploy | Per-host build/deploy commands for TanStack Start. See `../references/deployment/README.md` for the per-host explanation and `vite.config.ts` plugin setup. | [deploy.md](./deploy.md) |
| Dev / Build | Local development and production build/start commands. The exact scripts depend on the build tool (Vite or Rsbuild) and target host. | [dev-build.md](./dev-build.md) |
| Install | Manual dependency setup when building a TanStack Start project from an empty directory (skip if scaffolding via the CLI). | [install.md](./install.md) |
