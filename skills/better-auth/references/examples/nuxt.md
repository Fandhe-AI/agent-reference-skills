# Nuxt Example

Official worked example integrating Better Auth with Nuxt. Demonstrates email/password authentication and Google social sign-in.

## Signature / Usage

```bash
# clone from CodeSandbox or GitHub, then:
# rename .env.example to .env and configure variables
pnpm install
pnpm dev
# open http://localhost:3000
```

## Notes

- Uses `pnpm` as the package manager; ensure it is installed before setup
- Live demo: https://codesandbox.io/p/github/better-auth/examples/tree/main/nuxt-example
- Source: https://github.com/better-auth/better-auth/blob/main/docs/content/docs/examples/nuxt.mdx
