# React Router Example

Official worked example integrating Better Auth with React Router v7. Demonstrates email/password auth, Google social sign-in, passkeys, email verification, password reset, two-factor auth, profile update, and session management.

## Signature / Usage

```bash
# clone from the code sandbox or repository, then:
# duplicate .env.example to .env and populate required variables
pnpm install
pnpm run dev
# open http://localhost:3000
```

## Notes

- Uses React Router v7 as the routing framework with Better Auth handling authentication, sessions, and user management
