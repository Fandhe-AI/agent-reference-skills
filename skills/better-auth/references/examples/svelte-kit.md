# SvelteKit Example

Official worked example integrating Better Auth with SvelteKit. Demonstrates email/password auth, Google social sign-in, passkeys, email verification, password reset, two-factor auth, profile management, and session handling.

## Signature / Usage

```bash
# clone from CodeSandbox or GitHub, then:
# rename .env.example to .env and populate required variables
pnpm install
pnpm dev
# open http://localhost:3000
```
