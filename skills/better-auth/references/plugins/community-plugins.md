# Community Plugins

A list of Better Auth extension plugins built by the community. **Not vetted or guaranteed by the official team.** If you build your own plugin, contributing it to this list is encouraged.

## Notes

- Community plugins are not vetted or guaranteed by the official team
- If you build your own plugin, contributing it to the official documentation list is encouraged

### List

| Name | Description |
|---|---|
| `@dymo-api/better-auth` | Disposable email address validation using a database of about 14 million entries |
| `better-auth-harmony` | Email/phone number normalization. Blocks over 55,000 temporary domains |
| `validation-better-auth` | API request validation compatible with Zod / Yup, etc. |
| `better-auth-localization` | Message localization and translation customization |
| `better-auth-attio-plugin` | User/workspace sync with Attio CRM |
| `better-auth-cloudflare` | Integration with Cloudflare Workers / D1 / KV / R2 |
| `expo-better-auth-passkey` | Mobile passkey authentication for Expo apps |
| `better-auth-credentials-plugin` | LDAP authentication integration |
| `better-auth-opaque` | Breach-resistant authentication via the zero-knowledge OPAQUE protocol |
| `better-auth-firebase-auth` | Firebase authentication (email, Google sign-in) |
| `better-auth-university` | Restricts sign-up to specific university email domains |
| `@alexasomba/better-auth-paystack` | Paystack payment/subscription integration |
| `better-auth-lark` | Lark billing. Automatic customer/plan management |
| `stargate-better-auth` | Access control based on GitHub repository star count |
| `@sequenzy/better-auth` | Automatic Sequenzy mailing list registration on sign-up |
| `better-auth-nostr` | Nostr authentication (NIP-98 protocol) |
| `@ramiras123/better-auth-strapi` | Strapi authorization integration |
| `better-auth-razorpay` | Razorpay payment processing / subscriptions |
| `better-auth-payu` | PayU payment integration |
| `better-invite` | System for creating and managing user invitations |
| `better-auth-usos` | USOS API authentication for university students |
| `better-auth-devtools` | Dev panel for test user management and session inspection |
| `better-auth-audit-logs` | Automatic event logging with PII redaction |
| `better-near-auth` | NEAR blockchain sign-in (with gasless relay support) |
| `ton-better-auth` | Ton Connect blockchain authentication |
| `@dbsc-toolkit/better-auth` | Device-bound session credentials to prevent cookie replay attacks |
| `@marinedotsh/better-auth-referral` | User referral system plugin |
| `better-auth-instagram` | Instagram OAuth provider |
| `better-auth-zoho` | Zoho CRM OAuth provider |
| `better-auth-snapchat` | Snapchat OAuth provider |
| `better-inbox` | In-app notification system with database storage |
