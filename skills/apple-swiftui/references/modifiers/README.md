# modifiers

| Name | Description | Path |
|------|-------------|------|
| background | Layers content or a style behind this view. | [background.md](./background.md) |
| border / tint | Adds a border outline to a view, or overrides the tint color for controls. | [border-tint.md](./border-tint.md) |
| clipShape | Clips the view to a shape, hiding content outside the shape's boundary. | [clip-shape.md](./clip-shape.md) |
| font / fontWeight | Sets the typeface and weight for text in a view hierarchy. | [font.md](./font.md) |
| foregroundStyle | Sets the style used to render foreground elements (text, shapes, template images). | [foreground-style.md](./foreground-style.md) |
| frame | Positions a view within an invisible frame with fixed or flexible size constraints. | [frame.md](./frame.md) |
| glassEffect | Applies the Liquid Glass material effect to a view, with a `Glass` configuration (`.regular`, `.clear`, `.identity`) and a shape defining where the effect renders. | [glass-effect.md](./glass-effect.md) |
| GlassEffectContainer | A view that combines multiple Liquid Glass shapes (from `glassEffect(_:in:)`) into a single shape that can morph individual shapes into one another. | [glass-effect-container.md](./glass-effect-container.md) |
| disabled / hidden / onTapGesture / onAppear / onChange | View modifiers for controlling interactivity, visibility, and lifecycle/event responses. | [interaction.md](./interaction.md) |
| offset / position | Shifts a view's rendered content (`offset`) or fixes its center in parent coordinates (`position`). | [offset-position.md](./offset-position.md) |
| opacity | Sets the transparency of a view. | [opacity.md](./opacity.md) |
| overlay | Layers content in front of this view. | [overlay.md](./overlay.md) |
| padding | Adds space around a view's content on specified edges. | [padding.md](./padding.md) |
| scaleEffect / rotationEffect | Scales or rotates a view's rendered output around an anchor point without affecting layout. | [scale-rotation.md](./scale-rotation.md) |
| shadow | Adds a drop shadow behind a view. | [shadow.md](./shadow.md) |
| lineLimit / multilineTextAlignment | Controls the maximum number of lines and the alignment of wrapped text. | [text-layout.md](./text-layout.md) |
| bold / italic | Applies bold or italic styling to text in a view. | [text-styling.md](./text-styling.md) |
