# Navigation

| Name | Description | Path |
|------|-------------|------|
| alert | Presents an alert dialog when a given condition is true. | [alert.md](./alert.md) |
| confirmationDialog | Presents a confirmation dialog (action sheet on iOS, alert on macOS) when a given condition is true. | [confirmationdialog.md](./confirmationdialog.md) |
| fullScreenCover | Presents a modal view that covers as much of the screen as possible. | [fullscreencover.md](./fullscreencover.md) |
| navigationDestination | View modifiers that associate destination views with data types or bindings for use within a `NavigationStack` or `NavigationSplitView`. | [navigationdestination.md](./navigationdestination.md) |
| NavigationLink | A view that controls a navigation presentation. | [navigationlink.md](./navigationlink.md) |
| NavigationPath | A type-erased list of data representing the content of a navigation stack, enabling heterogeneous element types in a single path. | [navigationpath.md](./navigationpath.md) |
| NavigationSplitView | A view that presents views in two or three columns, where selections in leading columns control presentations in subsequent columns. | [navigationsplitview.md](./navigationsplitview.md) |
| NavigationStack | A view that displays a root view and enables you to present additional views over the root view. | [navigationstack.md](./navigationstack.md) |
| popover | Presents a popover anchored to the modified view. | [popover.md](./popover.md) |
| presentationDetents | Sets the available detents (resting heights) for the enclosing sheet, enabling resizable bottom sheets. | [presentationdetents.md](./presentationdetents.md) |
| sheet | Presents a sheet when a binding to a Boolean value is `true`. | [sheet.md](./sheet.md) |
| Tab | A structure that represents the content for a tab and its associated tab item in a `TabView`. | [tab.md](./tab.md) |
| TabView | A view that switches between multiple child views using interactive user interface elements. | [tabview.md](./tabview.md) |
| ToolbarOverflowMenu / visibilityPriority(_:) | `ToolbarOverflowMenu` places actions always in the toolbar's overflow menu; `visibilityPriority(_:)` controls which items move into the overflow menu first when space runs out. | [toolbar-overflow.md](./toolbar-overflow.md) |
| toolbarVerticalBehavior / toolbarVerticalEdge / axisBehavior / toolbarVerticalCompressionBehavior | Controls for the vertical bar (iPhone Duo): opt out with `toolbarVerticalBehavior`, read the preferred edge from `toolbarVerticalEdge`, restrict items per axis with `axisBehavior`, and choose what compresses first with `toolbarVerticalCompressionBehavior`. | [toolbar-vertical.md](./toolbar-vertical.md) |
| toolbar | Populates the toolbar or navigation bar with the specified items. | [toolbar.md](./toolbar.md) |
| ToolbarItem | A model that represents an item that can be placed in the toolbar or navigation bar. | [toolbaritem.md](./toolbaritem.md) |
