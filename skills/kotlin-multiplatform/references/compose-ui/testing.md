# Testing Compose Multiplatform UI

UI testing uses the same finders, assertions, actions and matchers as the Jetpack Compose testing API. The common test API does not rely on JUnit's `TestRule`: call `runComposeUiTest` and invoke test functions on the `ComposeUiTest` receiver.

## Signature / Usage

Add the UI testing library to the `commonTest` source set in `shared/build.gradle.kts`:

```kotlin
kotlin {
    //...
    sourceSets {
        // Adds the common test dependency
        commonTest.dependencies {
            //...
            implementation("org.jetbrains.compose.ui:ui-test:1.12.2")
        }

        // Adds the desktop test dependency
        jvmTest.dependencies {
            implementation(compose.desktop.currentOs)
        }
    }
}
```

A common test in `shared/src/commonTest/kotlin/<package>/ExampleTest.kt`:

```kotlin
import androidx.compose.ui.test.v2.runComposeUiTest
import kotlin.test.Test

class ExampleTest {

    @OptIn(ExperimentalTestApi::class)
    @Test
    fun myTest() = runComposeUiTest {
        setContent {
            var text by remember { mutableStateOf("Hello") }
            Text(
                text = text,
                modifier = Modifier.testTag("text")
            )
            Button(
                onClick = { text = "Compose" },
                modifier = Modifier.testTag("button")
            ) {
                Text("Click me")
            }
        }

        onNodeWithTag("text").assertTextEquals("Hello")
        onNodeWithTag("button").performClick()
        onNodeWithTag("text").assertTextEquals("Compose")
    }
}
```

Run commands per target:

| Target | Command |
| --- | --- |
| iOS Simulator | `./gradlew :shared:iosSimulatorArm64Test` |
| Android Emulator | `./gradlew :shared:connectedAndroidTest` |
| Desktop | `./gradlew :shared:jvmTest` |
| Wasm (headless browser) | `./gradlew :shared:wasmJsTest` |

Android instrumented tests need extra configuration. In `shared/build.gradle.kts`:

```kotlin
kotlin {
    //...
    androidLibrary {
        withDeviceTestBuilder {
            sourceSetTreeName = "test"
        }
    }
}
```

In `androidApp/build.gradle.kts` set `testInstrumentationRunner = "androidx.test.runner.AndroidJUnitRunner"` inside `android.defaultConfig {}` and add:

```kotlin
dependencies {
    androidTestImplementation("androidx.compose.ui:ui-test-junit4-android:1.12.1")
    debugImplementation("androidx.compose.ui:ui-test-manifest:1.12.1")
}
```

## Notes

- The API is Experimental and may change.
- Instructions follow the project generated by the Kotlin Multiplatform wizard with **Include tests** checked; replace `shared` with your module name otherwise.
- Create the `shared/src/androidDeviceTest` source set for instrumented tests; it needs at least an `AndroidManifest.xml` pointing to `androidx.activity.ComponentActivity` (declared `android:exported="true"` with a MAIN / LAUNCHER intent filter).
- You currently cannot run common Compose Multiplatform tests using `android (local)` test configurations, so gutter icons in Android Studio won't help.
- Versions above come from the docs' version list: Compose Multiplatform 1.12.2, `androidx.compose` 1.12.1.
- Distance line: the Jetpack Compose testing API (finders, assertions, `ComposeTestRule`) belongs to android-testing; this page covers the JUnit-free multiplatform `runComposeUiTest` and per-target Gradle setup.
