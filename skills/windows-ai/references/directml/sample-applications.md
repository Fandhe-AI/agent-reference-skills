# DirectML sample applications

Links to official DirectML sample applications, including a minimal DirectML application, an Olive-based Stable Diffusion optimization sample, and generative-AI samples using the ONNX Runtime Generate() API.

## Options / Props

| Sample | Location | Description |
|--------|----------|-------------|
| DirectML samples (including minimal app) | `Microsoft/DirectML-Samples` on GitHub | Baseline samples demonstrating core DirectML usage, including a minimal DirectML application. |
| Stable Diffusion optimization with DirectML | `microsoft/Olive` (`examples/directml/stable_diffusion`) on GitHub | Demonstrates using Olive to optimize DirectML performance for Stable Diffusion. |
| ONNX Runtime Generate() API samples | `microsoft/onnxruntime-genai` on GitHub | Generative AI model samples using the ONNX Runtime Generate() API. |

## Notes

- These are pointers to external GitHub repositories rather than in-page code; no DirectML code sample is embedded on this page itself.
