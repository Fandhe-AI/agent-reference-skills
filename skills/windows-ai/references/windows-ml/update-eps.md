# Update execution providers in Windows ML

Execution providers (EPs) are updated automatically through Windows Update's optional nonsecurity preview releases ("D week releases"), without any app-side action required.

## Notes

- Updates are compatible updates delivered automatically to your app; apps benefit from performance improvements and new operator support without code changes.
- There is currently no way for an app to programmatically install an updated EP — the OS installs it via Windows Update.
- See [Windows ML execution providers](./supported-execution-providers.md) and expand "Release history" per EP for the update history.
- To check the currently installed EP version, see [Check EP versions](./check-ep-versions.md).
