# Foundry Toolkit for Visual Studio Code

A VS Code extension for building generative AI applications locally, providing access to models from the Microsoft Foundry catalog, Hugging Face, and additional catalogs, plus tools for downloading, fine-tuning, and deploying models on-device or on NPU-enabled hardware.

## Signature / Usage

No API surface — this is a VS Code extension, not a library. Documentation has moved to [Foundry Toolkit for Visual Studio Code](https://code.visualstudio.com/docs/intelligentapps/overview) for the latest cross-platform guidance.

## Options / Props

| Capability | Description |
|------|-------------|
| Model catalog access | Browse and download models from the Microsoft Foundry catalog, Hugging Face, and additional catalogs. |
| Fine-tuning | Fine-tune models on a local dataset from within VS Code. |
| Local/NPU deployment | Deploy and run models on your local machine or on NPU-enabled devices. |

## Notes

- The **Deepseek R1 Distilled** model is NPU-optimized and downloadable on Snapdragon-powered Copilot+ PCs running Windows 11 through this toolkit.
- Formerly documented under `windows/ai/toolkit`; that page now redirects readers to the VS Code docs site as the canonical source.
