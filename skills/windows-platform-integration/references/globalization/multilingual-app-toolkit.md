# Multilingual App Toolkit (MAT)

A Visual Studio extension that helped manage translation of `.resw` string resources via the industry-standard XLIFF format. **Deprecated**: reached end-of-support on October 15, 2025.

## Signature / Usage

N/A — Visual Studio extension, no runtime API.

## Notes

- Existing users can keep using MAT without loss of functionality after end-of-support, but no further updates are planned and new installations are no longer possible.
- Because MAT used the standard XLIFF format, Microsoft recommends switching to another Computer-Aided Translation (CAT) tool that supports XLIFF for ongoing localization workflows.
- Not an API — this page exists to flag that MAT should not be recommended for new localization tooling in current guidance.
