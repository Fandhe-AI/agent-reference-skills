# tags-block

| Name | Description | Path |
|------|-------------|------|
| @author | Block tag that records the author of a method or function. | [author.md](./author.md) |
| @category | Block tag for organizing related API items under a common heading. This page covers `@category`, `@categoryDescription`, `@showCategories`, and `@hideCategories`. | [category.md](./category.md) |
| @defaultValue | Block tag that records the default value of an accessor or property. | [defaultValue.md](./defaultValue.md) |
| @deprecated | Block tag indicating that a declaration is deprecated and may be removed in a future release. | [deprecated.md](./deprecated.md) |
| @document | Block tag that instructs TypeDoc to include an external file as a document within the generated site. | [document.md](./document.md) |
| @example | Block tag used to show a usage example for a function or feature. | [example.md](./example.md) |
| @expand / @expandType / @preventExpand | Tags controlling how type aliases and interfaces are displayed in documentation. This page covers the block tags `@expandType`, `@preventExpand`, and the modifier tag `@expand`. | [expand.md](./expand.md) |
| @group | Tags controlling the grouping and display of documentation items. This page covers `@group`, `@groupDescription`, `@showGroups`, `@hideGroups`, and `@disableGroups`. | [group.md](./group.md) |
| @import | Block tag for declaring type imports in JavaScript projects. | [import.md](./import.md) |
| @inline / @inlineType / @preventInline | Tags controlling inlining of type aliases and interfaces when rendered. This page covers the block tags `@inlineType`, `@preventInline`, and the modifier tag `@inline`. | [inline-type.md](./inline-type.md) |
| @license | Block tag that marks a comment as a license declaration and excludes it from the generated documentation. | [license.md](./license.md) |
| @mergeModuleWith | Block tag that merges the contents of a module into another module or into the project root. | [mergeModuleWith.md](./mergeModuleWith.md) |
| @module | Block tag indicating that a comment refers to the entire file, with an optional module rename. | [module.md](./module.md) |
| @param / @this | Block tag for documenting the parameters of a function or method. This page covers both `@param` and `@this`. | [param.md](./param.md) |
| @privateRemarks | Block tag for adding documentation text that should not be included in the generated API reference documentation. | [privateRemarks.md](./privateRemarks.md) |
| @property / @prop | Block tag for adding documentation comments to the children of a reflection. | [property.md](./property.md) |
| @remarks | Block tag for separating the summary section of a comment from its detailed description. | [remarks.md](./remarks.md) |
| @returns / @return | Block tag for documenting the return value of a function. | [returns.md](./returns.md) |
| @see | Block tag for creating a list of references to related resources. | [see.md](./see.md) |
| @since | Block tag for recording the version in which a method or feature was introduced. | [since.md](./since.md) |
| @sortStrategy | Block tag for overriding the global sort configuration at the declaration level. | [sortStrategy.md](./sortStrategy.md) |
| @summary | Block tag for customizing the description shown for a function or module on the module page. | [summary.md](./summary.md) |
| @template | Block tag for documenting the type parameters of a function, method, class, interface, or type alias. | [template.md](./template.md) |
| @throws | Block tag for documenting exceptions that a function or method may throw. | [throws.md](./throws.md) |
| @typeParam | Block tag for documenting the type parameters of a function, method, class, interface, or type alias. | [typeParam.md](./typeParam.md) |
| TypeScript Tags | TypeScript-specific block tags that TypeDoc recognizes for compatibility. This page covers `@type`, `@yields`, `@jsx`, `@typedef`, `@extends`, `@augments`, `@satisfies`, and `@callback`. | [typescript-tags.md](./typescript-tags.md) |
