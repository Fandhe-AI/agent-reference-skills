#### Logs Bucket Writer (`roles/logging.bucketWriter`)

- Ability to write logs to a log bucket. Lowest-level resources where you can grant this role: - Project
- Permissions (1): `logging.buckets.write`

#### Logs Writer (`roles/logging.logWriter`)

- Provides the permissions to write log entries. Lowest-level resources where you can grant this role: - Project
- Permissions (2): `logging.logEntries.create`, `logging.logEntries.route`

#### Log Field Accessor (`roles/logging.fieldAccessor`)

- Ability to read restricted fields in a log bucket. Lowest-level resources where you can grant this role: - Project
- Permissions (1): `logging.fields.access`

#### Log Link Accessor (`roles/logging.linkViewer`)

- Ability to see links for a bucket.
- Permissions (2): `logging.links.get`, `logging.links.list`

#### SQL Alert Writer (`roles/logging.sqlAlertWriter`)

- Launch stage: Beta
- Ability to write SQL Alerts.
- Permissions (2): `logging.sqlAlerts.create`, `logging.sqlAlerts.update`

#### Logs View Accessor (`roles/logging.viewAccessor`)

- Ability to read logs in a view. Lowest-level resources where you can grant this role: - View
- Permissions (5): `logging.logEntries.download`, `logging.views.access`, `logging.views.listLogs`, `logging.views.listResourceKeys`, `logging.views.listResourceValues`

#### Cloud Logging Service Agent (`roles/logging.serviceAgent`)

- Grants a Cloud Logging Service Account the ability to create and link datasets. > \[!WARNING\] > \*\*Warning:\*\* Do not grant service agent roles to any principals except service agents (https://docs.cloud.google.com/iam/docs/service-agents).
- Permissions (3): `bigquery.datasets.create`, `bigquery.datasets.get`, `bigquery.datasets.link`

### Example: grant a role

Generated example (not in the official docs) granting the first role on this page on a whole project (the role's lowest-level resource is View; granting it there instead limits the scope, but this example does not show that command):

```bash
gcloud projects add-iam-policy-binding PROJECT_ID \
  --member="user:EMAIL_ADDRESS" \
  --role="roles/logging.admin"
```
