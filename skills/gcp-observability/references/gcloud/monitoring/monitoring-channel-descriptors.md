# gcloud monitoring channel-descriptors

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

```text
NAME
    gcloud beta monitoring channel-descriptors describe - describe a
        notification channel descriptor

SYNOPSIS
    gcloud beta monitoring channel-descriptors describe DESCRIPTOR
```
