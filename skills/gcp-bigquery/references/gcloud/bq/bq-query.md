# gcloud bq query

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha bq query

```text
NAME
    gcloud alpha bq query - execute a BigQuery SQL query

SYNOPSIS
    gcloud alpha bq query [SQL_QUERY] [--async] [--endpoint-mode=ENDPOINT_MODE]
        [--job-creation-mode=JOB_CREATION_MODE] [--job-id=JOB_ID]
        [--location=LOCATION] [--[no-]use-cache] [--[no-]use-legacy-sql]
        [GCLOUD_WIDE_FLAG ...]
```
