# App Icons

App icons are the visual indicators that help users find and launch a Windows app; they appear in the Start menu, taskbar, splash screen, title bar, search results, notifications, "Open with" list, task manager, JumpLists, Settings, and Share dialog.

## Options / Props

| Principle | Guidance |
|-----------|----------|
| Keep it simple | Clean, straightforward, timeless designs help users recognize the app quickly |
| Keep it universal | Avoid complex or overly abstract forms; some shapes read differently across cultures |
| Do less, better | Illustrate the app in a single, thoughtfully crafted element |
| Grid | Align construction to a 48x48 grid; use soft/rounded corners for approachability |
| Metaphor | Use at most two metaphors, ideally one; the icon should be understandable without a label |
| Typography | Avoid letters/words in the icon design |

## Notes

- This page covers icons that represent the app itself in Windows/the Microsoft Store. For icons used inside an app's UI, see Icon Elements (`FontIcon`, `SymbolIcon`, etc.).
- Design guidance (metaphor, shape, color, shadow) lives in the separate "Design guidelines for Windows app icons" guide; asset construction and required pixel sizes live in App Icon Construction.
- Package/scope: Windows Store / MSIX app icon assets. Distinct from in-app icon controls and from mobile app icon guidelines (apple-distribution, android-build-gradle).
