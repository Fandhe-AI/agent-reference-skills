# Design principles

The five core principles that shaped Windows 11's visual evolution of Fluent Design, plus the "signature experiences" (Color, Elevation and layering, Iconography, Materials, Shapes and geometry, Typography, Motion) that express that language consistently across the OS and apps.

## Options / Props

| Principle | Description |
|------|-------------|
| Effortless | Faster and more intuitive; easy to do what the user wants, with focus and precision. |
| Calm | Softer and decluttered; fades into the background to help the user stay calm and focused. |
| Personal | Adapts seamlessly to how the user uses the device; bends to individual needs and preferences. |
| Familiar | Balances refreshed look and feel with the familiarity of existing Windows; no learning curve. |
| Complete + Coherent | Visually seamless experience across platforms; consistent Windows experience everywhere. |

## Notes

- "Signature experiences" are the concrete design elements that express these principles: Color, Elevation and layering, Iconography, Materials, Shapes and geometry (Geometry), Typography, Motion.
- Geometry and Elevation/layering are detailed further in their own pages in this category.
