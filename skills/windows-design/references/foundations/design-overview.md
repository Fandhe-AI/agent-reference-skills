# Design overview

Entry point to Windows app design guidance: a hub linking design principles, deep-dive guidelines (layout, navigation, input, typography, motion, and more), and design tools/resources. Guidance follows Microsoft's Fluent Design language.

## Notes

- Three top-level sections: **Design principles** (core principles for how Windows apps should look, feel, and behave), **Guidelines** (deep-dive guidance on layout, navigation, input, typography, motion), and **Design tools and resources** (assets, templates, tools).
- Scope: Windows app UI design guidance (WinUI 3 / Windows App SDK era). Not IT Pro, Windows Server, IoT, driver, or Windows 365 documentation.
