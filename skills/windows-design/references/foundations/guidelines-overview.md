# Guidelines overview

Index of the core building-block topics for Windows app design: the patterns, rules, and behaviors that keep an app intuitive, polished, and aligned with Fluent Design across color, typography, motion, layout, and materials.

## Options / Props

| Topic | Description | Page |
|------|-------------|------|
| Color | Establish hierarchy, communicate meaning, create a cohesive visual identity. | `signature-experiences/color` |
| Commanding | Present actions in clear, consistent patterns. | `basics/commanding-basics` |
| Elevation | Apply depth and layering to guide focus and reinforce structure. | `signature-experiences/layering` |
| Geometry | Use shape, sizing, and spatial relationships for balanced, predictable layouts. | `signature-experiences/geometry` |
| Haptics | Add touch feedback to reinforce input and create responsive interactions. | `signature-experiences/haptics` |
| Iconography | Communicate actions and concepts with familiar, purposeful icons. | `iconography/` |
| Layout | Organize content with grids, spacing, and alignment patterns. | `layout/` |
| Materials | Enhance UI with Fluent materials like Mica and Acrylic. | `signature-experiences/materials` |
| Motion | Provide feedback, guide attention, create smooth interactions. | `signature-experiences/motion` |
| Navigation | Help users move through the app with predictable structure. | `basics/navigation-basics` |
| Typography | Set tone and improve readability with consistent type choices. | `signature-experiences/typography` |
| Usability | Ensure the app is accessible and easy to use. | `usability/` |
| Widgets | Glanceable, interactive surfaces for key information and actions. | `widgets/` |
| Writing | Clear, concise, helpful language. | `style/writing-style` |

## Notes

- This category (`foundations/`) covers Layout, Geometry, and Elevation in depth; other topics (Color, Motion, Typography, Iconography, etc.) are out of this scope and referenced by name only.
