# Core Data

| Name | Description | Path |
|------|-------------|------|
| @FetchRequest (SwiftUI) | SwiftUI property wrapper that executes a Core Data fetch request and provides live-updating results to a view. Re-renders the view whenever the fetched data changes. | [fetchrequest-swiftui.md](./fetchrequest-swiftui.md) |
| NSAsynchronousFetchRequest / NSAsynchronousFetchResult | A fetch request that retrieves results asynchronously and supports progress notification. `NSAsynchronousFetchResult` is the result object that encompasses the response from an executed asynchronous fetch request. | [nsasynchronousfetchrequest.md](./nsasynchronousfetchrequest.md) |
| NSBatchDeleteRequest | Deletes managed objects directly at the SQLite store level without loading them into memory. Efficient for bulk deletions; bypasses context change tracking. | [nsbatchdeleterequest.md](./nsbatchdeleterequest.md) |
| NSBatchInsertRequest | Inserts a batch of records directly into the persistent store without loading objects into memory. Significantly faster than individual `NSManagedObject` insertions for large datasets. | [nsbatchinsertrequest.md](./nsbatchinsertrequest.md) |
| NSEntityDescription | Describes an entity in a Core Data model — analogous to a database table definition. Each entity specifies a name, corresponding class, attributes, and relationships. | [nsentitydescription.md](./nsentitydescription.md) |
| NSFetchedResultsController | Manages the results of an `NSFetchRequest` and notifies a delegate when the result set changes. Primary adapter for driving UITableView / UICollectionView from a Core Data store. | [nsfetchedresultscontroller.md](./nsfetchedresultscontroller.md) |
| NSFetchRequest | Describes the search criteria — entity, predicate, sort order, and result shape — for retrieving data from a Core Data persistent store. | [nsfetchrequest.md](./nsfetchrequest.md) |
| @NSManaged | Swift attribute applied to stored properties of `NSManagedObject` subclasses. Tells the compiler that Core Data will provide the property's storage and accessor implementations at runtime. | [nsmanaged.md](./nsmanaged.md) |
| NSManagedObject | Base class for all Core Data model objects. Provides generic property storage backed by an `NSEntityDescription` and tracks changes within an `NSManagedObjectContext`. | [nsmanagedobject.md](./nsmanagedobject.md) |
| NSManagedObjectContext | An in-memory scratchpad that tracks, validates, and persists changes to a graph of `NSManagedObject` instances. All Core Data reads and writes go through a context. | [nsmanagedobjectcontext.md](./nsmanagedobjectcontext.md) |
| NSManagedObjectModel | Programmatic representation of a `.xcdatamodeld` file. Contains `NSEntityDescription` objects that define the schema used by a `NSPersistentStoreCoordinator`. | [nsmanagedobjectmodel.md](./nsmanagedobjectmodel.md) |
| NSPersistentCloudKitContainer / NSPersistentCloudKitContainerOptions | A container that encapsulates the Core Data stack in your app, and mirrors select persistent stores to a CloudKit private database. `NSPersistentCloudKitContainerOptions` customizes how a store description aligns with a CloudKit database. | [nspersistentcloudkitcontainer.md](./nspersistentcloudkitcontainer.md) |
| NSPersistentContainer | Convenience class that encapsulates the Core Data stack: `NSManagedObjectModel`, `NSPersistentStoreCoordinator`, and a main-queue `NSManagedObjectContext`. | [nspersistentcontainer.md](./nspersistentcontainer.md) |
| NSPersistentStoreCoordinator | Mediates between one or more `NSManagedObjectContext` instances and one or more persistent stores. Presents multiple stores as a single aggregate data source. | [nspersistentstorecoordinator.md](./nspersistentstorecoordinator.md) |
| NSPersistentStoreDescription | Configuration object for creating and loading a persistent store. Pass an array to `NSPersistentContainer.persistentStoreDescriptions` before calling `loadPersistentStores`. | [nspersistentstoredescription.md](./nspersistentstoredescription.md) |
| NSPredicate | Defines a logical condition for filtering objects. Used as `NSFetchRequest.predicate` to constrain Core Data queries, or to filter in-memory collections. | [nspredicate.md](./nspredicate.md) |
| NSSortDescriptor | Immutable specification of how to order a collection by a property. Assigned to `NSFetchRequest.sortDescriptors` to control the order of Core Data query results. | [nssortdescriptor.md](./nssortdescriptor.md) |
| Persistent history (NSPersistentHistoryChangeRequest / Token / Transaction / Change / Result) | Use persistent history tracking to determine what changes have occurred in the store since history tracking was enabled, and to update a view context only as needed. | [persistent-history.md](./persistent-history.md) |
| Staged migrations (NSStagedMigrationManager / NSLightweightMigrationStage / NSCustomMigrationStage) | Migrate complex data models containing changes that are incompatible with a single lightweight migration. Staged lightweight migrations reduce an incompatible migration into a series of compatible stages that a migration manager runs in a specific order. | [staged-migration.md](./staged-migration.md) |
