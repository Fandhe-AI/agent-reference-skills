# Install Lefthook

Source: https://lefthook.dev/install

## Signature / Usage

Lefthook distributes as a standalone, no-deps binary. There are multiple ways to install lefthook but the most common is via package manager for your programming language (see the per-method pages in this category).

You can also download just the [binary](https://github.com/evilmartians/lefthook/releases/latest) for your OS and architecture and put it somewhere in your `$PATH` and update it with

```
lefthook self-update
```
