# Generate a strong pre-shared key

A pre-shared key (PSK, also called shared secret) authenticates the Cloud VPN tunnel to the peer VPN gateway. The recommended practice is a strong 32-character PSK, generated by one of the methods below.

## Signature / Usage

### JavaScript (W3C Web Cryptography API)

Generates a 32-character string from 24 random bytes, base64 encoded.

```javascript
  var a = new Uint8Array(24);
  window.crypto.getRandomValues(a);

  console.log(btoa(String.fromCharCode.apply(null, a)));
```

### OpenSSL (Linux or macOS)

```bash
openssl rand -base64 32
```

### `/dev/urandom` (Linux or macOS)

Send random input to `base64`:

```bash
head -c 32 /dev/urandom | base64
```

Or pass random input through a hash function. On Linux:

```bash
head -c 4096 /dev/urandom | sha256sum | cut -b1-32
```

On macOS:

```bash
head -c 4096 /dev/urandom | openssl sha256 | cut -b1-32
```

## Notes

- The generated key is a secret: do not commit it, share it, or print it to shared logs. Pass it to `--shared-secret` through a protected variable or file (use a placeholder such as `SHARED_SECRET` in scripts), and configure the same value on the peer gateway.
- The in-page "Regenerate" widget of the source is an embedded frame and is not reproduced.
