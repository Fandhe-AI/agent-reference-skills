# Hosted Web Search

Enable hosted web search for a workspace and use it from OpenCode.

```text
/connect
```

```text
Find the latest Bun release and summarize the changes with source links.
```

## Notes

- A workspace owner or admin opens **Integrations**, clicks **Set up** on **Hosted Web Search**, then **Enable**. Members connect with `/connect`.
- The workspace selects **OpenCode Web Search** as the default provider; a member who sets their own `websearch.provider` keeps that choice.
- Each successful search costs $0.01 and returns up to eight results; failed and rate-limited searches are not charged.
- Hosted web search has zero data retention.
