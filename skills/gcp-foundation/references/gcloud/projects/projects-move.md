# gcloud projects move

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta projects move

```text
NAME
    gcloud beta projects move - move a project into an organization

SYNOPSIS
    gcloud beta projects move PROJECT_ID_OR_NUMBER [--folder=FOLDER_ID]
        [--organization=ORGANIZATION_ID] [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha projects move

```text
NAME
    gcloud alpha projects move - move a project into an organization

SYNOPSIS
    gcloud alpha projects move PROJECT_ID_OR_NUMBER [--folder=FOLDER_ID]
        [--organization=ORGANIZATION_ID] [GCLOUD_WIDE_FLAG ...]
```
