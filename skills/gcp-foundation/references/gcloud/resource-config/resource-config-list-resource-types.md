# gcloud resource-config list-resource-types

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta resource-config list-resource-types

```text
NAME
    gcloud beta resource-config list-resource-types - list all resources
        supported by bulk-export

SYNOPSIS
    gcloud beta resource-config list-resource-types
        [--folder=FOLDER | --organization=ORGANIZATION | --project=PROJECT]
        [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha resource-config list-resource-types

```text
NAME
    gcloud alpha resource-config list-resource-types - list all resources
        supported by bulk-export

SYNOPSIS
    gcloud alpha resource-config list-resource-types
        [--folder=FOLDER | --organization=ORGANIZATION | --project=PROJECT]
        [GCLOUD_WIDE_FLAG ...]
```
