# gcloud resource-config apply

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha resource-config apply

```text
NAME
    gcloud alpha resource-config apply - apply a KRM configuration to a Google
        Cloud Platform resource filename or stdin

SYNOPSIS
    gcloud alpha resource-config apply PATH [GCLOUD_WIDE_FLAG ...]
```
