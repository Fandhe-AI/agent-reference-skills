### Principal Access Boundary Policy Viewer (`roles/iam.principalAccessBoundaryViewer`)

- Read-only access to Principal Access Boundary policies and their associated bindings.
- Permissions (3): `iam.principalaccessboundarypolicies.get`, `iam.principalaccessboundarypolicies.list`, `iam.principalaccessboundarypolicies.searchPolicyBindings`

### Role Administrator (`roles/iam.roleAdmin`)

- Provides access to all custom roles in the project. This role can only be granted at the project level.
- Permissions (12): `iam.roles.create`, `iam.roles.createTagBinding`, `iam.roles.delete`, `iam.roles.deleteTagBinding`, `iam.roles.get`, `iam.roles.list`, `iam.roles.listEffectiveTags`, `iam.roles.listTagBindings`, `iam.roles.undelete`, `iam.roles.update`, `resourcemanager.projects.get`, `resourcemanager.projects.getIamPolicy`

### Role Viewer (`roles/iam.roleViewer`)

- Provides read access to all custom roles in the project. Lowest-level resources where you can grant this role: - Project
- Permissions (6): `iam.roles.get`, `iam.roles.list`, `iam.roles.listEffectiveTags`, `iam.roles.listTagBindings`, `resourcemanager.projects.get`, `resourcemanager.projects.getIamPolicy`

### Example: grant a role

Generated example (not in the official docs) granting the first role on this page at its lowest-level resource (Project):

```bash
gcloud projects add-iam-policy-binding PROJECT_ID \
  --member="user:EMAIL_ADDRESS" \
  --role="roles/iam.accessPolicyAdmin"
```

## Notes

- Roles and permissions of the `iam` service from the IAM roles and permissions reference (retrieved 2026-11-14); role names, descriptions and permission lists are verbatim, regrouped per role. The `service.resource.*` group headings of the official page are omitted from the per-role lists and counts, because they are collapsible headings, not permissions.
- The permissions table lists role IDs only (role names and links are on the official page) and gives service agent roles as a count; service agent roles must not be granted to principals other than service agents.
- Source: https://docs.cloud.google.com/iam/docs/roles-permissions/iam (CC BY 4.0; https://developers.google.com/site-policies)
