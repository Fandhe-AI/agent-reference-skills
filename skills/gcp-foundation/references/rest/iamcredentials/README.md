# IAM Service Account Credentials API REST API

| Name | Description | Path |
|---|---|---|
| IAM Service Account Credentials API (iamcredentials) | Creates short-lived credentials for impersonating IAM service accounts. Disabling this API also disables the IAM API (iam.googleapis.com). However, enabling this API doesn't enable the IAM API. | [iamcredentials.md](./iamcredentials.md) |
