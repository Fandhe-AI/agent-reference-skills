# Identity and Access Management (IAM) API REST API (iam) (part 1/2)

## Signature / Usage

Base URL: `https://iam.googleapis.com`. Methods are listed by `id`; the `Versions` line shows which API versions define the method (preferred: v2).

### `iam.iamPolicies.lintPolicy`

- Versions: v1
- `POST https://iam.googleapis.com/v1/iamPolicies:lintPolicy`
- Lints, or validates, an IAM policy. Currently checks the google.iam.v1.Binding.condition field, which contains a condition expression for a role binding. Successful calls to this method always return an HTTP `200 OK` status code, even if the linter detects an issue in the IAM policy.
- Scopes: `https://www.googleapis.com/auth/cloud-platform`
- Request: `LintPolicyRequest`; Response: `LintPolicyResponse`

### `iam.iamPolicies.queryAuditableServices`

- Versions: v1
- `POST https://iam.googleapis.com/v1/iamPolicies:queryAuditableServices`
- Returns a list of services that allow you to opt into audit logs that are not generated by default. To learn more about audit logs, see the Logging documentation (https://cloud.google.com/logging/docs/audit).
- Scopes: `https://www.googleapis.com/auth/cloud-platform`
- Request: `QueryAuditableServicesRequest`; Response: `QueryAuditableServicesResponse`

### `iam.locations.workforcePools.create`

- Versions: v1
- `POST https://iam.googleapis.com/v1/{+location}/workforcePools`
- Creates a new WorkforcePool. You cannot reuse the name of a deleted pool until 30 days after deletion.
- Scopes: `https://www.googleapis.com/auth/cloud-platform`
- Request: `WorkforcePool`; Response: `Operation`

| Parameter | In | Type | Required | Description |
|---|---|---|---|---|
| `location` | path | string | yes | Optional. The location of the pool to create. Format: `locations/{location}`. |
| `workforcePoolId` | query | string | no | Optional. The ID to use for the pool, which becomes the final component of the resource name. The IDs must be a globally unique string of 6 to 63 lowercase letters, digits, or hyphens. It must start with a letter, and cannot have a trailing hyphen. The prefix `gcp-` is reserved for use by Google, and may not be specified. |

### `iam.locations.workforcePools.delete`

- Versions: v1
- `DELETE https://iam.googleapis.com/v1/{+name}`
- Deletes a WorkforcePool. You cannot use a deleted WorkforcePool to exchange external credentials for Google Cloud credentials. However, deletion does not revoke credentials that have already been issued. Credentials issued for a deleted pool do not grant access to resources. If the pool is undeleted, and the credentials are not expired, they grant access again. You can undelete a pool for 30 days. After 30 days, deletion is permanent. You cannot update deleted pools. However, you can view and list them.
- Scopes: `https://www.googleapis.com/auth/cloud-platform`
- Request: —; Response: `Operation`

| Parameter | In | Type | Required | Description |
|---|---|---|---|---|
| `name` | path | string | yes | Required. The name of the pool to delete. Format: `locations/{location}/workforcePools/{workforce_pool_id}` |
