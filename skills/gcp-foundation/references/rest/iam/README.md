# Identity and Access Management (IAM) API REST API

| Name | Description | Path |
|---|---|---|
| Identity and Access Management (IAM) API (iam) part 1 | Manages identity and access control for Google Cloud resources, including the creation of service accounts, which you can use to authenticate to Google and make API calls. Enabling this API also enables the IAM Service Account Credentials API (iamcredentials.googleapis.com). However, disabling this API doesn't disable the IAM Service Account Credentials API. | [iam-1.md](./iam-1.md) |
| Identity and Access Management (IAM) API (iam) part 2 | Manages identity and access control for Google Cloud resources, including the creation of service accounts, which you can use to authenticate to Google and make API calls. Enabling this API also enables the IAM Service Account Credentials API (iamcredentials.googleapis.com). However, disabling this API doesn't disable the IAM Service Account Credentials API. | [iam-2.md](./iam-2.md) |
