# MLCPUComputeDevice

An object that represents a CPU compute device.

## Signature / Usage

```swift
class MLCPUComputeDevice
```

## Notes

- iOS 17.0+, iPadOS 17.0+, Mac Catalyst 17.0+, macOS 14.0+, tvOS 17.0+, visionOS 1.0+, watchOS 10.0+
- Inherits from `NSObject`; conforms to `MLComputeDeviceProtocol`, `NSObjectProtocol`, `Sendable`, `SendableMetatype`, `Equatable`, `Hashable`
- Obtained as the associated value of `MLComputeDevice.cpu(_:)`
- Source: https://developer.apple.com/documentation/coreml/mlcpucomputedevice
