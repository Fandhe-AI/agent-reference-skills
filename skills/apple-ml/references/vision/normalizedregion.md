# NormalizedRegion

A polygon composed of normalized points. It is a type alias for `ContoursObservation.Contour`.

## Signature / Usage

```swift
typealias NormalizedRegion = ContoursObservation.Contour
```

## Notes

- iOS 26.0+ / iPadOS 26.0+ / Mac Catalyst 26.0+ / macOS 26.0+ / tvOS 26.0+ / visionOS 26.0+ / watchOS 27.0+
- `ContoursObservation.Contour` is "an object that represents a detected contour in an image".
- This is the type of `BoundingRegionProviding.boundingRegion`.
