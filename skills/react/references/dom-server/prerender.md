# prerender

`prerender` renders a React tree to a static HTML string using a Web Stream. It depends on Web Streams; for Node.js, use `prerenderToNodeStream` instead.

## Signature / Usage

```js
import { prerender } from 'react-dom/static';

async function handler(request) {
  const {prelude} = await prerender(<App />, {
    bootstrapScripts: ['/main.js']
  });
  return new Response(prelude, {
    headers: { 'content-type': 'text/html' },
  });
}
```

Signature: `const {prelude, postponed} = await prerender(reactNode, options?)`.

Returns a Promise:

- If rendering is successful, the Promise resolves to an object containing:
  - `prelude`: a Web Stream of HTML. You can use this stream to send a response in chunks, or you can read the entire stream into a string.
  - `postponed`: a JSON-serializeable, opaque object that can be passed to `resume` if `prerender` did not finish. Otherwise `null`, indicating that the `prelude` contains all the content and no resume is necessary.
- If rendering fails, the Promise is rejected.

Reading the whole prelude into a string:

```js
import { prerender } from 'react-dom/static';

async function renderToString() {
  const {prelude} = await prerender(<App />, {
    bootstrapScripts: ['/main.js']
  });

  const reader = prelude.getReader();
  const decoder = new TextDecoder();
  let content = '';
  while (true) {
    const {done, value} = await reader.read();
    if (done) {
      content += decoder.decode();
      return content;
    }
    content += decoder.decode(value, {stream: true});
  }
}
```

Aborting prerendering (for partial prerendering with `resume` or `resumeAndPrerender`):

```js
async function renderToString() {
  const controller = new AbortController();
  setTimeout(() => {
    controller.abort()
  }, 10000);

  try {
    // the prelude will contain all the HTML that was prerendered
    // before the controller aborted.
    const {prelude} = await prerender(<App />, {
      signal: controller.signal,
    });
    //...
```

## Options / Props

| Name | Type | Description |
|------|------|-------------|
| reactNode | React node | A React node you want to render to HTML. For example, a JSX node like `<App />`. It is expected to represent the entire document, so the App component should render the `<html>` tag. |
| options.bootstrapScriptContent | string | (optional) If specified, this string will be placed in an inline `<script>` tag. |
| options.bootstrapScripts | string[] | (optional) An array of string URLs for the `<script>` tags to emit on the page. Use this to include the `<script>` that calls `hydrateRoot`. Omit it if you don't want to run React on the client at all. |
| options.bootstrapModules | string[] | (optional) Like `bootstrapScripts`, but emits `<script type="module">` instead. |
| options.identifierPrefix | string | (optional) A string prefix React uses for IDs generated by `useId`. Useful to avoid conflicts when using multiple roots on the same page. Must be the same prefix as passed to `hydrateRoot`. |
| options.importMap | object | (optional) An import map object with `imports` and `scopes` properties. React emits it as an inline `<script type="importmap">` tag before any module scripts, so that `<script type="module">` tags (for example, from `bootstrapModules`) can use bare module specifiers. |
| options.maxHeadersLength | number | (optional) The maximum total length of the header content passed to `onHeaders`, measured in UTF-16 code units. Defaults to 2000. Once the limit is reached, React stops adding resource hints to the headers. |
| options.namespaceURI | string | (optional) The root namespace URI for the stream. Defaults to regular HTML. Pass `'http://www.w3.org/2000/svg'` for SVG or `'http://www.w3.org/1998/Math/MathML'` for MathML. |
| options.onBrowserBailout | function | (optional) Called when React recovers from `browser()` by leaving a Suspense fallback for the browser to replace. Receives an `Error` describing the browser-only render and an `errorInfo` object containing the `componentStack`. If a reason was passed to `browser`, it is available as `error.cause`. By default, React does nothing. |
| options.onError | function | (optional) Fires whenever there is a server error, whether recoverable or not. By default, this only calls `console.error`. If you override it to log crash reports, make sure that you still call `console.error`. You can also use it to adjust the status code before the shell is emitted. |
| options.onHeaders | function | (optional) Fires when React has determined the resource hints for the document, such as preconnects and stylesheet, font, or high-priority image preloads. It receives a `Headers` instance containing the corresponding `Link` header value, so you can send it as an HTTP response header or as a 103 Early Hints response. React calls it even when there are no resource hints to send. The header content is capped by `maxHeadersLength`. |
| options.progressiveChunkSize | number | (optional) The number of bytes in a chunk. |
| options.signal | AbortSignal | (optional) An abort signal that lets you abort prerendering and render the rest on the client. |

## Notes

- Snippet corrected from the original: uses TextDecoder with stream: true and a final flush instead of Buffer.from(value).toString(), so multibyte characters split across chunks decode correctly and no Node.js Buffer is required.
- `nonce` is not an available option when prerendering. Nonces must be unique per request and if you use nonces to secure your application with CSP it would be inappropriate and insecure to include the nonce value in the prerender itself.
- The static `prerender` API is used for static server-side generation (SSG). Unlike `renderToString`, `prerender` waits for all data to load before resolving, which makes it suitable for generating static HTML for a full page, including data fetched using Suspense. To stream content as it loads, use a streaming SSR API like `renderToReadableStream`.
- `prerender` can be aborted and later either continued with `resumeAndPrerender` or resumed with `resume` to support partial pre-rendering. Any Suspense boundaries with incomplete children are included in the prelude in the fallback state.
- Only data read from a source that activates a Suspense boundary, such as a Promise read with `use`, will suspend during rendering. Suspense does not detect data fetched inside an Effect or event handler.
- Troubleshooting: the `prerender` response waits for the entire app to finish rendering, including waiting for all Suspense boundaries to resolve, before resolving. It does not support streaming more content as it loads.
- Distinct from framework SSG: nextjs-app, tanstack-start and react-router wrap these APIs in their own skills; this page documents the raw `react-dom/static` API.
