# React Versions

The React docs at react.dev provide documentation for the latest version of React (latest version: 19.3). Docs are kept updated within major versions; docs are not published for each minor or patch version. When a new major is released, the docs for the previous version are archived as `x.react.dev`.

## Signature / Usage

```text
Latest version: 19.3
  react.dev

Previous versions (archived docs)
  18.react.dev
  17.react.dev
  16.react.dev
  15.react.dev
```

### Older versions

The page also lists blog posts, talks and releases for React 17, 16, 15, 0.14, 0.13, 0.12, 0.11 and 0.10 and below. Posts for 17 and below are hosted on `legacy.reactjs.org`. React was open-sourced on May 29, 2013 (initial commit `75897c`: Initial public release).

## Notes

- Legacy Docs: in 2023 the new docs for React 18 launched as react.dev. The legacy React 18 docs are available at legacy.reactjs.org. Versions 17 and below are hosted on legacy sites. For versions older than React 15, see 15.react.dev.
- Patch versions of older minors (19.0.x, 19.1.x, 19.2.x) are listed through 2026 because security fixes are backported to all affected major versions; see the RSC security advisory pages below.
- The Talks lists in the original page (React 19 Keynote, A Roadmap to React 19, What's new in React 19, etc.) are YouTube links and are not reproduced.
