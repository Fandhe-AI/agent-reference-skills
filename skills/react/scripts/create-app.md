# Create App

新規 React アプリの作成。フレームワーク経由とビルドツールからの構築。

> **警告**: 以下は新規ディレクトリを作成するスキャフォールドコマンド。空のディレクトリで実行し、既存プロジェクト内では実行しない。

## Next.js (App Router)

```sh
npx create-next-app@latest
```

出典: https://react.dev/learn/creating-a-react-app

## React Router (v7)

```sh
npx create-react-router@latest
```

出典: https://react.dev/learn/creating-a-react-app

## Expo (ネイティブアプリ)

```sh
npx create-expo-app@latest
```

出典: https://react.dev/learn/creating-a-react-app

## Vite (React + TypeScript)

```sh
npm create vite@latest my-app -- --template react-ts
```

出典: https://react.dev/learn/build-a-react-app-from-scratch

## Parcel

```sh
npm install --save-dev parcel
```

出典: https://react.dev/learn/build-a-react-app-from-scratch

## Rsbuild

```sh
npx create-rsbuild --template react
```

出典: https://react.dev/learn/build-a-react-app-from-scratch
