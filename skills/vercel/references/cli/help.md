# vercel help

Display help information for Vercel CLI commands.

## Signature / Usage

```bash
vercel help
vercel help [command]
vercel help env add
vercel --help
vercel [command] --help
```

## Notes

- Equivalent to the `--help` / `-h` global option on any command
- A subcommand can follow the command (e.g. `vercel help env add`)
- Shows available subcommands and options for the specified command
- Source: https://vercel.com/docs/cli/help (fetched 2026-11-14)
