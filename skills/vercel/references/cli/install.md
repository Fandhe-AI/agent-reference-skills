# vercel install

Alias for `vercel integration add`. Install a marketplace integration and provision a resource.

## Signature / Usage

```bash
vercel install <integration-name>
vercel i neon
vercel install neon
```

## Notes

- Fully interchangeable with `vercel integration add`; same flags and behavior
- `<integration-name>` is the integration's URL slug from its Marketplace URL (e.g. `neon` for `https://vercel.com/marketplace/neon`); browse with `vercel integration discover`
- Short alias: `vercel i`
- Source: https://vercel.com/docs/cli/install (fetched 2026-11-14)
