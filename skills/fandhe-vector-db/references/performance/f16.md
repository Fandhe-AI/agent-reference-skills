# f16

f32 と IEEE 754 binary16（f16）ビット表現の相互変換・範囲チェック・行エンコードを扱うモジュール。全アイテムが `pub(crate)`（crate 内部専用）。

## Signature / Usage

```rust
/// f16 が表現できる有限値の絶対値上限（65504.0）。
pub(crate) const F16_MAX: f32 = 65504.0;

/// `value` が f16 の有限範囲（`|value| <= F16_MAX`）に収まるかどうか。
/// 非有限（NaN・Inf）は `false` を返す。
pub(crate) fn fits_f16(value: f32) -> bool;

/// f32 を IEEE 754 binary16（f16）のビットパターンへ丸める。オーバーフローは
/// ±Inf へ飽和し、指数アンダーフロー域はサブノーマル f16 として正しく
/// round-to-nearest-even で丸める（`batch_search.rs` から移設）。
pub(crate) fn f32_to_f16_bits(value: f32) -> u16;

/// f16 ビットパターンを f32 へ復元する（`batch_search.rs` から移設。GPU
/// シェーダの `unpack2x16float` と等価な意味論）。
pub(crate) fn f16_bits_to_f32(bits: u16) -> f32;

/// `src` の各要素を f16 ビット表現へエンコードして `out` へ追記する
/// （`hnsw.rs::HnswIndex::freeze_from` の F16 常駐化で使用）。範囲外
/// （`|x| > F16_MAX`）の成分が 1 つでもあれば、どの添字かを含む
/// [`F16EncodeError::OutOfRange`] を返し `out` は変更しない（fail-closed）。
pub(crate) fn encode_rows(src: &[f32], out: &mut Vec<u16>) -> Result<(), F16EncodeError>;

/// [`encode_rows`] の失敗要因。
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum F16EncodeError {
    /// `index` 番目の成分が f16 の有限範囲（`|x| <= 65504.0`）を超えている。
    OutOfRange { index: usize },
    /// 出力バッファの確保に失敗した（`try_reserve_exact` が `Err`）。
    AllocationFailed,
}
```

## Notes

- 全アイテムが `pub(crate)`。crate 外に公開される f16 API は `isa.rs` の `F16Kernel` / `dot_f16` 経由のみ。
- `encode_rows` が範囲外成分を検出した場合は fail-closed（`out` を変更せずエラーを返す）。呼び出し元（`hnsw.rs::HnswIndex::freeze_from`）は D6 の規約に従い F32 常駐へ縮退する（ADR `hnsw-f16-resident` の対象。数値そのものの引用は避け、挙動のみ本ソースから引用する）。
- `hnsw-f16-resident` / `core16-f16-resident-gate`（ADR）は HNSW 索引・core16 経路での f16 常駐化ゲート条件を扱う。本ページでは f16 のビットレベル変換のみを収録し、HNSW 側の常駐化判断ロジックは `search/hnsw.md`（search カテゴリ、担当外）を参照。
- This crate's f16 encoding is plain Rust bit manipulation (no hardware f16 intrinsics beyond `isa.rs::F16Kernel`), unrelated to CUDA/PTX half-precision types (`nvidia-cuda`), Metal/MPS f16 tensors (`apple-silicon`), or HIP `__half` (`amd-rocm`). No API overlap with `fandhe-ai` (same org, separate Rust AI/ML library).
