# scripts

| Name | Description | Path |
|------|-------------|------|
| Cache | Commands to inspect, revalidate, and clean the uv cache. Operate on the cache only through commands, never directly. | [cache.md](./cache.md) |
| Install | Commands to install uv itself: standalone installer, PyPI, Homebrew, MacPorts, WinGet, Scoop, Cargo, Docker. | [install.md](./install.md) |
| pip Interface | pip / pip-tools compatible commands with `uv venv` and `uv pip`: create environments, manage packages, inspect environments, lock and sync requirements. | [pip-interface.md](./pip-interface.md) |
| Project | Project management commands: `uv init` / `uv add` / `uv remove` / `uv lock` / `uv sync` / `uv run` / `uv version` / `uv build` / `uv publish` / `uv export`. | [project.md](./project.md) |
| Python | Commands to install, list, find, pin, upgrade, and uninstall Python versions. | [python.md](./python.md) |
| Self Update and Uninstall | Commands to update uv, show its version, and uninstall it manually. | [self-update-uninstall.md](./self-update-uninstall.md) |
| Shell Completion | Commands to enable shell completion for uv and uvx. | [shell-completion.md](./shell-completion.md) |
| Tools | Commands to run, install, upgrade, and uninstall tools with `uvx` / `uv tool`. | [tools.md](./tools.md) |
