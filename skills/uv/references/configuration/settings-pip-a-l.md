# Settings: pip (a-l)

Settings specific to the `uv pip` command-line interface, in the `[tool.uv.pip]` table (`[pip]` in `uv.toml`). These values are ignored when running commands outside the `uv pip` namespace (e.g., `uv lock`, `uvx`). This page covers `all-extras` through `link-mode`.

## Signature / Usage

```toml
# pyproject.toml
[tool.uv.pip]
all-extras = true
index-url = "https://test.pypi.org/simple"
```

```toml
# uv.toml
[pip]
all-extras = true
index-url = "https://test.pypi.org/simple"
```

## Options / Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `all-extras` | `bool` | `false` | Include all optional dependencies. Only applies to `pyproject.toml`, `setup.py`, and `setup.cfg` sources. |
| `allow-empty-requirements` | `bool` | `false` | Allow `uv pip sync` with empty requirements, which clears the environment of all packages. |
| `annotation-style` | `"line" \| "split"` | `"split"` | Style of the annotation comments in the output file. `line`: single comma-separated line; `split`: each annotation on its own line. |
| `break-system-packages` | `bool` | `false` | Allow uv to modify an `EXTERNALLY-MANAGED` Python installation. WARNING: intended for CI environments with Python installations managed by an external package manager like `apt`; such installations explicitly recommend against modification by other package managers. |
| `compile-bytecode` | `bool` | `false` | Compile Python files to bytecode after installation (processes the entire site-packages directory, ignores errors like pip). |
| `config-settings` | `dict` | `{}` | Settings to pass to the PEP 517 build backend, as `KEY=VALUE` pairs. |
| `config-settings-package` | `dict` | `{}` | Per-package PEP 517 build backend settings. |
| `custom-compile-command` | `str` | `None` | Header comment at the top of the output file generated by `uv pip compile`; reflects custom scripts wrapping `uv pip compile`. |
| `dependency-metadata` | `list[dict]` | `[]` | Pre-defined static metadata for dependencies. Respected fields: `name`, optional `version`, `requires-dist`, `requires-python`, `provides-extra`. |
| `emit-build-options` | `bool` | `false` | Include `--no-binary` and `--only-binary` entries in the `uv pip compile` output. |
| `emit-find-links` | `bool` | `false` | Include `--find-links` entries in the `uv pip compile` output. |
| `emit-index-annotation` | `bool` | `false` | Include comment annotations indicating the index used to resolve each package (e.g., `# from https://pypi.org/simple`). |
| `emit-index-url` | `bool` | `false` | Include `--index-url` and `--extra-index-url` entries in the `uv pip compile` output. |
| `emit-marker-expression` | `bool` | `false` | Emit a marker string indicating the conditions under which the pinned dependencies are valid. They may be valid even when the expression is false; when true, they are known to be correct. |
| `exclude-newer` | `str \| false` | `None` | Limit candidates to those uploaded prior to a point in time (RFC 3339 timestamp, friendly duration, or ISO 8601 duration; months and years not allowed). `false` disables. |
| `exclude-newer-package` | `dict` | `None` | Per-package `PACKAGE = "DATE"` cutoffs; `false` exempts a package from the global cutoff. |
| `extra` | `list[str]` | `[]` | Include optional dependencies from the specified extra; may be provided more than once. Only for `pyproject.toml`, `setup.py`, `setup.cfg` sources. |
| `extra-build-dependencies` | `dict` | `[]` | Additional build dependencies for packages. |
| `extra-build-variables` | `dict[str, dict[str, str]]` | `{}` | Extra environment variables to set when building certain packages. |
| `extra-index-url` | `list[str]` | `[]` | Extra package index URLs in addition to `--index-url`; take priority over `index_url`. Earlier values take priority. |
| `find-links` | `list[str]` | `[]` | Locations to search for candidate distributions in addition to registry indexes. |
| `fork-strategy` | `"fewest" \| "requires-python"` | `"requires-python"` | Strategy for selecting multiple versions of a package across Python versions and platforms. |
| `generate-hashes` | `bool` | `false` | Include distribution hashes in the output file. |
| `group` | `list[str]` | `None` | Include the following dependency groups. |
| `index-strategy` | `"first-index" \| "unsafe-first-match" \| "unsafe-best-match"` | `"first-index"` | Strategy when resolving against multiple index URLs (`first-index` prevents "dependency confusion" attacks). |
| `index-url` | `str` | `"https://pypi.org/simple"` | URL of the Python package index. Lower priority than `extra_index_url`. |
| `keyring-provider` | `str` | `disabled` | Attempt to use `keyring` for index authentication; only `subprocess` is supported. |
| `link-mode` | `"clone" \| "copy" \| "hardlink" \| "symlink"` | `"clone"` (macOS, Linux) or `"hardlink"` (Windows) | Method when installing packages from the global cache. symlink mode is discouraged (clearing the cache breaks installed packages). |

Examples from the reference:

```toml
[tool.uv.pip]
annotation-style = "line"
break-system-packages = true
custom-compile-command = "./custom-uv-compile.sh"
emit-index-annotation = true
exclude-newer-package = { tqdm = "2022-04-04T00:00:00Z", markupsafe = false }
extra = ["dev", "docs"]
generate-hashes = true
group = ["dev", "docs"]
index-strategy = "unsafe-best-match"
link-mode = "copy"
```

## Notes

- There is no `uv.pip` equivalent to a top-level setting unless listed here; many keys have top-level corollaries that apply to `uv pip` unless overridden in this table.
- `emit-*` settings and `annotation-style` only affect the output file of `uv pip compile`.
