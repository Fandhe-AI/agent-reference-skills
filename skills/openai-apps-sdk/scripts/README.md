# scripts

| Name | Description | Path |
| --- | --- | --- |
| install | Install the Node MCP SDK, MCP Apps helpers, and `zod` to build a plugin's MCP server, plus the optional OpenAI MCP Extensions and MCP Events packages. | [install.md](./install.md) |
| local-dev-and-inspector | Run the MCP server locally, inspect it with MCP Inspector, and expose it to ChatGPT for testing as a custom MCP server plugin. | [local-dev-and-inspector.md](./local-dev-and-inspector.md) |
| package-and-marketplace | Package a plugin manually, scaffold it with `@plugin-creator`, and manage local marketplace sources with the `codex plugin marketplace` CLI. Public submission is a form-based flow with no CLI commands. | [package-and-marketplace.md](./package-and-marketplace.md) |
