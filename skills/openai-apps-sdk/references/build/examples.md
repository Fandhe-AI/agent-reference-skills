# Examples

The Pizzaz demo bundles several UI components so you can see the full MCP server + optional UI tool surface area end to end.

## Signature / Usage

```bash
git clone https://github.com/openai/openai-apps-sdk-examples
```

Pizzaz and other reference implementations (MCP server plus component implementations) live in the `openai-apps-sdk-examples` GitHub repository. Use them as blueprints when assembling a plugin's MCP server and optional UI.

## Notes

- Includes a Python SDK example alongside the Node/TypeScript ones referenced elsewhere in `build/`.
- Pair with [App quickstart](./app-quickstart.md) for a guided walkthrough before adapting the repository's components.
