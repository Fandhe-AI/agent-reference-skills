# Finding classes

Finding classes in Security Command Center let you filter and prioritize security issues by the type of risk a finding identifies (threat, vulnerability, misconfiguration, and so on). The class is stored in the `findingClass` field; a finding with no class is classified as `Finding class unspecified`. Applies to the Standard-legacy, Standard, Premium, and Enterprise (Deprecated) service tiers unless a class says otherwise.

## Signature / Usage

### List active findings of one category

The page does not define a filter expression for `findingClass`; this lists the active findings of one category (`XSS`) under an organization and source.

```bash
gcloud scc findings list 123456 --source=5678 \
    --filter="state=\"ACTIVE\" AND category=\"XSS\""
```

## Options / Props

### Finding classes

| Class | Identifies | Tier / stage |
|---|---|---|
| `Chokepoint` | A resource or resource group where high-risk attack paths converge, based on attack path simulations. Remediating one chokepoint finding might remediate multiple toxic combinations. | All tiers listed above |
| `External exposure` | External-facing IP addresses, hostnames, domain names, URLs and exposed services confirmed reachable from the public internet. | Preview; Premium and Enterprise (Deprecated) |
| `Misconfiguration` | Weaknesses caused by incorrect or suboptimal configuration of resources, assets or policies; usually fixed by updating the configuration named in the finding. Distinct from `Vulnerability`. | All tiers listed above |
| `Observation` | An event, configuration detail or other issue that might not be a problem in itself but could be if the environment were compromised. Commonly generated by Sensitive Data Protection, Sensitive Actions Service and AI Protection. | All tiers listed above |
| `Posture violation` | Resource configurations that don't align with your security posture or a Compliance Manager cloud control. | All tiers listed above |
| `SCC error` | A problem in the configuration of Security Command Center or one of its services that prevents it from detecting security issues. | All tiers listed above |
| `Secret` | Plaintext credentials, keys, access tokens or certificates in container images that run on Gemini Enterprise Agent Platform. | Preview; Premium and Enterprise (Deprecated) |
| `Threat` | A potential active attack or other unwanted or malicious activity; investigate immediately. | All tiers listed above |
| `Toxic combination` | A group of security issues that together create a path to one or more high-value resources. | All tiers listed above |
| `Vulnerability` | A flaw or weakness in software programs (for example a CVE) that an attacker could use to gain access or compromise the environment. | All tiers listed above |
| `Finding class unspecified` | No value (or no `findingClass` property) was set; review the finding to decide what kind of issue it is. | All tiers listed above |

## Notes

- The Security Command Center Enterprise service tier will shut down on May 21, 2027. Organizations on Enterprise move to Premium automatically on or after May 21, 2027.
- `External exposure` and `Secret` classes are Preview ("Pre-GA Offerings Terms"; "as is", might have limited support).
- Normally the service that generates a finding sets `findingClass`. Integrated and third-party providers are recommended, not required, to set it.
- Threat findings should be investigated immediately. Toxic combination and chokepoint findings are described in the toxic combinations overview (see the Security Command Center docs).
- Snippet taken from https://docs.cloud.google.com/sdk/gcloud/reference/scc/findings/list (gcloud 593.0.0 help). With no `--location`, the help says the request goes to the SCC V1 API; pass `--location` to use the V2 API.
