# View an audit

When an audit completes, Audit Manager stores an audit summary report, a control overview report, and evidence in the destination Cloud Storage buckets. View compliance scores for controls, cloud controls, and resources on the **Audit report** page of the Google Cloud console, or download reports from the bucket.

## Signature / Usage

### Compliance summary formula

```text
(Number of evaluated items that compliance / Total number of items) * 100
```

An item can be a control, a cloud control, or a resource. The total includes items in compliance, in violation, and not evaluated (skipped).

### Report location in Cloud Storage

Reports are stored in folders in the destination bucket with this convention: `audit-reports/audit_RESOURCE_NAME_FRAMEWORK_NAME_TIMESTAMP/UNIQUE_ID`. Each audit folder has separate reports per control, cloud control, and evidence. Control and cloud control reports are ODS and describe the compliance evaluation for a single control, with observations and expected values. Evidence reports are JSON and include all resources evaluated for each control, with a raw dump of asset data and the command run to produce the output.

## Options / Props

### Roles

| Role | Notes |
|---|---|
| Audit Manager Admin (`roles/auditmanager.admin`) | One of these on the resource |
| Audit Manager Auditor (`roles/auditmanager.auditor`) | One of these on the resource |
| Compliance Manager Viewer (`roles/cloudsecuritycompliance.viewer`) | Required if auditing a framework created with Compliance Manager |
| Storage Admin (`roles/storage.admin`), Storage Legacy Bucket Owner (`roles/storage.legacyBucketOwner`), or Storage Legacy Object Reader (`roles/storage.legacyObjectReader`) | One of these on the bucket that holds the reports |

### Dashboard counts (per tab: controls, cloud controls, resources)

| Item | Meaning |
|---|---|
| Compliance summary | Percentage from the formula above |
| Total | Total controls or cloud controls in the framework, or total resources evaluated |
| Compliant | Items that met the evaluation requirements |
| Violations | Items that didn't meet the evaluation requirements |
| Inconclusive | Items Audit Manager couldn't determine as compliant (for example, retrieved configuration or log data didn't clearly match the rules) |
| Skipped | Items Audit Manager couldn't evaluate because of an error or system issue (for example, insufficient permissions to inspect a resource) |
| Not supported | Items that require evaluating resources outside Google Cloud |
| Evidence collected | Amount of information extracted through the technical assessment |
| Violating evaluations | Number of rules or resources assessed as failing |

### Report path placeholders

| Placeholder | Description |
|---|---|
| `RESOURCE_NAME` | ID of the folder or project, such as `folders_12345` or `projects_12345` |
| `FRAMEWORK_NAME` | Framework name, such as `builtin-nist800-53-revision5` |
| `TIMESTAMP` | When the report was generated |
| `UNIQUE_ID` | Unique ID for the report |

## Notes

- Console flow: **Audit Manager** > **Compliance audits** > **View audits** (in-progress or completed audits from Audit Manager or Compliance Manager) > click the audit name for status, audited resources, framework, location, time run, bucket, and **Overrides** (parameters specified for the report). **Download report** gives an OpenDocument Spreadsheet (ODS); you can also download directly from the bucket.
- The **Control** tab groups by controls, the **Cloud control** tab by cloud controls, and the **Resources** tab by service API name (for example `cloudresourcemanager.googleapis.com`). Control, cloud control, and resource detail pages show IDs, shared responsibility status, review and evaluation status, evidence amounts, regulatory controls, and links to related reports.
- Preview: **Insights generated by Gemini** shows a Gemini-generated summary of results. Gemini output can be plausible but factually incorrect; validate it before use.
