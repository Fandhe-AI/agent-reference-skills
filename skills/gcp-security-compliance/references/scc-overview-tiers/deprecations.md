# Deprecations and shut down features

Standard-legacy, Standard, Premium, and Enterprise (Deprecated) service tiers. The Security Command Center Enterprise service tier will shut down on May 21, 2027; an organization that uses it automatically moves to the Premium service tier on or after May 21, 2027. The Google Cloud Platform Terms of Service ("Discontinuation of Services") define the deprecation policy, which applies only to the services, features, or products listed there; after deprecation a feature stays available for at least the period defined in the Terms of Service before shutdown.

## Signature / Usage

### Update an asset's security marks (still available after the asset management removal)

```bash
gcloud scc assets update-marks 5678 --organization=123456 \
    --security-marks="key1=val1.1" --update-mask="marks.key1"
```

## Options / Props

### Deprecated features

| Feature | Deprecated date | Shutdown date | Details |
|---|---|---|---|
| Artifact guard with CI/CD integration | September 30, 2026 | On or after October 30, 2026 | Artifact guard and CI/CD integration will no longer be available. |
| Data Security Posture Management | September 14, 2026 | On or after February 1, 2027 | DSPM will no longer be available; see the controls and alternative detection capabilities in the data security framework page. |
| Security Command Center Enterprise service tier | May 21, 2026 | On or after May 21, 2027 | The tier will no longer be available; by default the organization moves to the Premium service tier on that date. |
| Manual state changes for Security Health Analytics and VM Manager findings | February 20, 2024 | On or after October 21, 2024 | You can no longer manually update the state of vulnerability or misconfiguration findings generated by Security Health Analytics or VM Manager; manual creation of findings with the exact name of a source that Security Command Center manages automatically is also prevented. |
| Security Health Analytics use of security marks for asset allowlists | June 26, 2023 | On or after April 15, 2025 | Available only in instances activated before June 26, 2023; otherwise use the mute feature. After April 15, 2025 security marks can still be applied but no longer affect how Security Health Analytics processes assets. |
| Rapid Vulnerability Detection service | May 14, 2024 | July 14, 2024 | Preview release discontinued and shut down on July 14, 2024; findings set to `Inactive` and retained per the Security Command Center data retention policy. |
| Asset management features: Asset API endpoints; the `assets` subgroup of `gcloud scc` except `gcloud scc assets update-marks`; the **Assets** page in the console | June 20, 2023 | On or after June 20, 2024 | Available only for instances activated before June 20, 2023 that used asset functionality in the 90 days before that date; migrate to Cloud Asset Inventory by June 20, 2024. |

### Detector shut downs

| Service | Finding display name | API name | Shutdown date | Description |
|---|---|---|---|---|
| Cloud Run Threat Detection | Privilege Escalation: Fileless Execution in /dev/shm | `CLOUD_RUN_FILELESS_EXECUTION_DETECTION_SHM` | Mar 11, 2026 | A process has been executed from a path within /dev/shm. |
| Virtual Machine Threat Detection | Defense Evasion: Unexpected kernel code modification | `Not applicable` | June 2, 2025 | Detects unexpected modifications in the kernel code memory. |

## Notes

- Detector shut downs: Detection rules and modules are managed services and aren't subject to Google Cloud's deprecation policy; they can be shut down when redundant or no longer relevant.
- Dates are as stated in the source ("On or after" the shutdown date). Plan migrations for the Enterprise tier (May 21, 2027), DSPM (February 1, 2027), and Artifact guard with CI/CD integration (October 30, 2026).
- Asset management removal: use Cloud Asset Inventory (https://docs.cloud.google.com/asset-inventory/docs/asset-inventory-overview; supported asset types at https://docs.cloud.google.com/asset-inventory/docs/supported-asset-types) instead of the Security Command Center asset API and `gcloud scc assets` commands.
