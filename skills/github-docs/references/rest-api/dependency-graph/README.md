# dependency-graph

| Name | Description | Path |
|------|-------------|------|
| Dependency Review API | 2 つのコミット間の依存関係の差分（既知の脆弱性情報付き）を取得するエンドポイント。 | [dependency-review.md](./dependency-review.md) |
| Dependency Submission API | ビルド時に解決された依存関係をスナップショットとして送信し、dependency graph に追加するエンドポイント。 | [dependency-submission.md](./dependency-submission.md) |
| SBOM API | リポジトリの dependency graph を SPDX JSON 形式の software bill of materials (SBOM) としてエクスポートするエンドポイント。 | [sboms.md](./sboms.md) |
