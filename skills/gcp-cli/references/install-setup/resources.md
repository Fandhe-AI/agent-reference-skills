# Resources

Landing page listing supporting resources for the Google Cloud SDK / gcloud CLI.

## Signature / Usage

- Getting support: resources that help you get support while using Google Cloud SDK (https://docs.cloud.google.com/sdk/docs/getting-support).
- Release notes: Google Cloud SDK release notes (https://docs.cloud.google.com/sdk/docs/release-notes). Not part of this reference scope.
- Usage statistics: opt in to provide usage statistics to Google to help improve Google Cloud SDK (https://docs.cloud.google.com/sdk/docs/usage-statistics).

```bash
gcloud config set disable_usage_reporting false
```
