# Getting support

Resources for getting support while using the Google Cloud CLI.

## Signature / Usage

- Paid support: if you have a paid Google Cloud support plan, always open support cases through the support console (see "create a support case": https://docs.cloud.google.com/support/docs/customer-care-procedures#create_a_support_case).
- Support packages: Google Cloud offers packages for different needs, such as 24/7 coverage, phone support, and access to a technical support manager (Cloud Customer Care: https://docs.cloud.google.com/support).
- Bugs and feature requests: use the public issue tracker, https://issuetracker.google.com/issues/new?component=187143, to discuss and track features and fixes and share workarounds. Set the 'Type' field (such as Bug or Feature Request).

From the command line, `gcloud feedback` opens that issue tracker:

```bash
gcloud feedback
```
