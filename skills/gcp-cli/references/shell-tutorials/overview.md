# Cloud Shell tutorials overview

Index of the Cloud Shell tutorial authoring documentation: one Markdown extensions page and five walkthrough-directive pages (Cloud Shell Editor, Layout, Open in Cloud Shell, Projects, Spotlights).

## Signature / Usage

The overview page lists these pages (no code of its own). Directive format, as shown on the "Writing tutorials" page:

Snippet taken from https://docs.cloud.google.com/shell/docs/cloud-shell-tutorials/tutorials

```text
<walkthrough-DIRECTIVE_NAME PARAMETER="PARAMETER_VALUE">
</walkthrough-DIRECTIVE_NAME>
```

| Section | Page | Summary |
| --- | --- | --- |
| Markdown extensions | markdown-extensions | Cloud Shell tutorials support Markdown extensions to expand the capability of the language. |
| Walkthrough directives | directives-cloud-shell-editor | Interact with Cloud Shell Editor in a walkthrough. |
| Walkthrough directives | directives-layout | Control the layout of elements in your walkthrough and link to other tutorials. |
| Walkthrough directives | directives-cloud-shell-open | Present a button to open in Cloud Shell or open in Cloud Shell automatically. |
| Walkthrough directives | directives-project-setup | Present options to select a project, display current project details, or enable Cloud APIs. |
| Walkthrough directives | directives-spotlights | Apply a spotlight to supported UI elements to support navigation. |
