# Open in Cloud Shell directive

Walkthrough directive related to opening Cloud Shell.

## Signature / Usage

Creates a button that opens Cloud Shell with the current project selected.

```text
<walkthrough-open-cloud-shell-button></walkthrough-open-cloud-shell-button>
```
