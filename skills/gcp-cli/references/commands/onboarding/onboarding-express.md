# gcloud onboarding express

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha onboarding express get-project

```text
NAME
    gcloud alpha onboarding express get-project - get or provision a Starter
        Tier project for onboarding

SYNOPSIS
    gcloud alpha onboarding express get-project
        [--auto-accept-tos-ids=[TOS_ID,...]] [--region=REGION]
        [GCLOUD_WIDE_FLAG ...]
```

- Text taken verbatim from `gcloud meta generate-help-docs` of Google Cloud CLI 593.0.0 (retrieved 2026-11-14). Release tracks on this page: alpha.

- GCLOUD_WIDE_FLAG stands for the global flags (`--help`, `--project`, `--format`, `--quiet`, `--verbosity`, ...); see the gcloud-wide flags in the `gcp-cli` skill.
