# gcloud emulators pubsub

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta emulators pubsub env-init

```text
NAME
    gcloud beta emulators pubsub env-init - print the commands required to
        export pubsub emulator's env variables

SYNOPSIS
    gcloud beta emulators pubsub env-init [--data-dir=DATA_DIR]
        [GCLOUD_WIDE_FLAG ...]
```

### gcloud beta emulators pubsub start

```text
NAME
    gcloud beta emulators pubsub start - start a local pubsub emulator

SYNOPSIS
    gcloud beta emulators pubsub start [--data-dir=DATA_DIR]
        [--host-port=HOST_PORT] [GCLOUD_WIDE_FLAG ...]
```
