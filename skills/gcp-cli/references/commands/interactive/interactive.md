# gcloud interactive

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta interactive

```text
NAME
    gcloud beta interactive - start the gcloud interactive shell

SYNOPSIS
    gcloud beta interactive [--context=CONTEXT] [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha interactive

```text
NAME
    gcloud alpha interactive - start the gcloud interactive shell

SYNOPSIS
    gcloud alpha interactive [--context=CONTEXT] [GCLOUD_WIDE_FLAG ...]
```

## Notes

- Text taken verbatim from `gcloud meta generate-help-docs` of Google Cloud CLI 593.0.0 (retrieved 2026-11-14). Release tracks on this page: alpha, beta.
- Examples are verbatim from `gcloud help`. Some wrap a long value with a trailing backslash and indentation (join the lines when running them), and some omit positional arguments that the SYNOPSIS requires; follow the SYNOPSIS.
- GCLOUD_WIDE_FLAG stands for the global flags (`--help`, `--project`, `--format`, `--quiet`, `--verbosity`, ...); see the gcloud-wide flags in the `gcp-cli` skill.
