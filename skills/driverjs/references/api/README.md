# api

| Name | Description | Path |
|------|-------------|------|
| Configuration | Driver.js accepts a configuration object when creating a driver instance. Options can be set at the driver level (global) and overridden at the step level. | [configuration.md](./configuration.md) |
| Methods | All methods are called on the driver instance returned by `driver()`. | [methods.md](./methods.md) |
| Theming | Driver.js can be styled using plain CSS. All popover and overlay elements use stable CSS class names that can be targeted directly or scoped via the `popoverClass` option. | [theming.md](./theming.md) |
