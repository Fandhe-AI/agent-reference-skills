# images

|------|-------------|------|

| ColorFilter | Transforms pixel colors via tint or a 4x5 color matrix. | [colorfilter.md](./colorfilter.md) |
| ImageVector | Vector graphic representation built from path/group nodes. | [imagevector.md](./imagevector.md) |
| rememberVectorPainter | Creates and remembers a VectorPainter from an ImageVector or manual composition. | [remembervectorpainter.md](./remembervectorpainter.md) |
