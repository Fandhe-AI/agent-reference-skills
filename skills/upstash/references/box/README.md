# Box

| Name | Description | Path |
|------|-------------|------|
| Agent | Every box can have a built-in agent (Claude Code, Codex, or OpenCode) with access to the filesystem, git, and shell commands, simulating an agent running on your own computer | [agent.md](./agent.md) |
| Browser | Create a box with `browser: true` to get a managed, headless Chromium controlled through the SDK: open tabs, read pages, screenshot, extract structured data, run AI agents on the live DOM, record sessions, and connect Playwright/Puppeteer directly over CDP | [browser-overview.md](./browser-overview.md) |
| Browser: AI Actions | A DOM-aware browser agent runs inside the box and resolves natural-language instructions against the live page: find elements, execute a single action, or complete a multi-step task autonomously | [browser-ai-actions.md](./browser-ai-actions.md) |
| Browser: Connect over CDP | The box browser is a real Chromium; `box.browser.cdpUrl()` returns an authenticated Chrome DevTools Protocol WebSocket URL that Playwright, Puppeteer, or Stagehand can connect to directly | [browser-connect.md](./browser-connect.md) |
| Browser: Live View | Every tab can produce a shareable, view-only live view URL that streams the tab in real time — open it in a browser or embed it in an `<iframe>` to show users what their agent is doing | [browser-live-view.md](./browser-live-view.md) |
| Browser: Reading Pages | Three ways to get data out of a tab: read the DOM as text, capture a screenshot, or have an AI agent extract structured data against a schema | [browser-reading-pages.md](./browser-reading-pages.md) |
| Browser: Recordings | Recordings capture the browser to a replayable HLS video, covering all tabs, following whichever is in the foreground, and including everything an AI task does | [browser-recordings.md](./browser-recordings.md) |
| Browser: Tabs & Navigation | Tabs are the unit of work in the box browser. `box.browser` opens and lists them; every page operation (navigation, screenshots, AI actions) runs on a specific `Tab` handle | [browser-tabs.md](./browser-tabs.md) |
| Filesystem | Every box has its own isolated filesystem. Upload, write, read, list, and download files inside the box via `box.files` | [filesystem.md](./filesystem.md) |
| Git | Clone a repository, inspect changes, commit work, push a branch, or open a pull request from inside a box via `box.git` | [git.md](./git.md) |
| Guide: AI File Editor with TanStack AI | An `EphemeralBox` provides code execution and file operations—enough for a full AI file editor: the model writes code to transform an uploaded file, spins up a box, runs the code, downloads the result, and tears the box down | [guides-tanstack-ai-file-editor.md](./guides-tanstack-ai-file-editor.md) |
| Guide: Build a Code Review Agent | Build a code review agent (like CodeRabbit or Greptile) with Upstash Box: clone a repo, inspect the PR diff, and return structured findings with severity and suggested fixes | [guides-code-review-agent.md](./guides-code-review-agent.md) |
| Guide: Code Interpreter with Vercel AI SDK | Add a code interpreter tool to a Vercel AI SDK chat app: when the model needs computation, it writes code and runs it in a fresh `EphemeralBox` that is isolated, disposable, and auto-expires when the session ends | [guides-ai-sdk-code-interpreter.md](./guides-ai-sdk-code-interpreter.md) |
| Guide: Hermes Setup | Set up [Hermes](https://github.com/NousResearch/hermes-agent) inside an Upstash Box | [guides-hermes-setup.md](./guides-hermes-setup.md) |
| Guide: LangChain Deep Agents | The [`langchain-upstash-box`](https://pypi.org/project/langchain-upstash-box/) package wraps an Upstash Box as a LangChain Deep Agents sandbox backend, so a Deep Agent's shell and file tools run inside the box instead of on your machine | [guides-langchain-deep-agents.md](./guides-langchain-deep-agents.md) |
| Guide: Next.js Setup | Scaffold a Next.js app inside an Upstash Box and open it in the browser through a public URL, without using an agent | [guides-nextjs-setup.md](./guides-nextjs-setup.md) |
| Guide: OpenClaw Setup | Set up [OpenClaw](https://docs.openclaw.ai) inside an Upstash Box | [guides-openclaw-setup.md](./guides-openclaw-setup.md) |
| Guide: Pi Setup | Use [Pi](https://pi.dev) with the [`@upstash/box-pi`](https://www.npmjs.com/package/@upstash/box-pi) extension, which runs every tool call inside an Upstash Box while Pi itself and model API keys stay on the local machine | [guides-pi-setup.md](./guides-pi-setup.md) |
| Guide: Remote Development | Forward ports over SSH to run any web server (Next.js, Vite, Django, Rails, Express, ...) inside a box and access it locally as if it were running on your own machine | [guides-remote-development.md](./guides-remote-development.md) |
| Guide: Running Tests with Crabbox | [Crabbox](https://crabbox.sh) is a CLI that runs commands inside a remote box from your local machine — run a test suite in a clean cloud environment without touching your local setup | [guides-crabbox-setup.md](./guides-crabbox-setup.md) |
| Guide: Scrape Dynamic Websites with Playwright | Use Upstash Box to run Playwright against a JavaScript-heavy site, scrape structured data, and pull results back — because a box is a real Linux container, Chromium and its system dependencies install exactly like on a laptop | [guides-web-scraping-playwright.md](./guides-web-scraping-playwright.md) |
| Network Policy | Network policies control outbound network access from a box: block all outbound traffic, allow only specific public domains, or restrict egress to specific CIDR ranges | [network-policy.md](./network-policy.md) |
| Quickstart | Upstash Box gives AI agents a computer: a secure, isolated cloud container with an AI Agent built-in, with full filesystem, shell, git, and runtime access | [quickstart.md](./quickstart.md) |
| Schedules | Create recurring tasks (shell commands or agent prompts) that run on a cron schedule inside a box, via `box.schedule` | [schedules.md](./schedules.md) |
| Security & Secrets | Every box runs in its own isolated container (dedicated filesystem, process tree, network stack); boxes cannot communicate with or observe each other | [security.md](./security.md) |
| Snapshots | Snapshots capture and duplicate box state — filesystem and agent configuration — as a point-in-time checkpoint you can restore later, independent of the source box | [snapshots.md](./snapshots.md) |
