# SBOM overview

A software bill of materials (SBOM) is a machine-readable inventory of an application that identifies the packages your software relies on (third-party vendor software, internal artifacts and open source libraries). For container images stored in Artifact Registry, Artifact Analysis can generate an SBOM or store one you upload, with consistent storage and retrieval.

## Signature / Usage

Generate an SBOM for an image in Artifact Registry:

```text
gcloud artifacts sbom export --uri=LOCATION-docker.pkg.dev/PROJECT_ID/REPOSITORY/IMAGE_NAME
```

## Options / Props

| Topic | Details |
|-------|---------|
| Format produced | Software Package Data Exchange (SPDX) 2.3; additional formats are supported when you upload an SBOM from outside Google Cloud |
| Storage | Cloud Storage in your Google Cloud project; SBOMs remain until you delete the objects or the bucket |
| Supported packages | All packages that Artifact Analysis scanning can identify; packages must be containerized and stored in a Docker repository in Artifact Registry |

### SBOM reference occurrence (Grafeas)

| Content | Description |
|---------|-------------|
| Cloud Storage location | Location of the SBOM |
| SBOM hash | Hash of the SBOM |
| Signature | Signature over `SbomReferenceIntotoPayload`, verifying the SBOM was generated by Artifact Analysis; DSSE protocol, payload type `application/vnd.in-toto+json`, payload is the jsonified `SbomReferenceIntotoPayload` |

### Package occurrence (one per installed package)

| Content |
|---------|
| Package version |
| Package type |
| License information for installed packages |

## Notes

- An SBOM can help attest to software composition in support of regulations such as Executive Order (EO) 14028.
- Limitation: installed package tracking is only supported for container images pushed to Artifact Registry and assessed by the Container Scanning API; the gcloud CLI lookup based on installed packages only works with such images.
- Cloud Storage costs apply: https://cloud.google.com/storage/pricing.
