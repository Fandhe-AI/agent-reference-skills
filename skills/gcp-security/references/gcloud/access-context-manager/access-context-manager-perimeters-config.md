# gcloud access-context-manager perimeters config

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha access-context-manager perimeters config export

```text
NAME
    gcloud alpha access-context-manager perimeters config export - export the
        configuration for a Access Context Manager service perimeter

SYNOPSIS
    gcloud alpha access-context-manager perimeters config export
        ([PERIMETER : --policy=POLICY] --all) [--path=PATH; default="-"]
        [--resource-format=RESOURCE_FORMAT] [GCLOUD_WIDE_FLAG ...]
```
