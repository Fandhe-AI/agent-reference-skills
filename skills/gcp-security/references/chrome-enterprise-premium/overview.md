# Chrome Enterprise Premium overview

Chrome Enterprise Premium extends Chrome's built-in security for enterprises with configurable data loss prevention (DLP), real-time phishing / malware / sandboxing protection, and context-aware access controls based on user identity, device security posture and location. Chrome Enterprise Core is included with Google Cloud at no additional cost; Premium adds the security features compared below. A 60-day trial of Premium is available.

## Signature / Usage

### Example of a device signal used in an access level

Device signals reach policy decisions through access levels. This CEL condition from the device-based access level guide allows access only from encrypted devices, using Endpoint Verification device attributes:

```text
device.encryption_status == DeviceEncryptionStatus.ENCRYPTED
```

## Options / Props

### Common signals for policy decisions

| Signal | Detail |
|---|---|
| User or group information | Identity of the requester |
| Location | IP or geographic region |
| Device | Enterprise-managed devices, personally-owned devices, mobile devices |
| Third-party device signals | Check Point, CrowdStrike, Lookout, Tanium, VMware |
| Risk scores | Listed as a signal |

### Chrome Enterprise Premium compared with Chrome Enterprise Core

| Group | Feature rows |
|---|---|
| Applications and resources access | Web applications on Google Cloud; SSH, RDP and TCP ports for VMs on Google Cloud; Google Cloud APIs; Google Cloud console; web applications on Google Cloud internal load balancing; web applications on customer premises; web applications on AWS and Azure; SAML-based applications (login time); Google Workspace Admin Console |
| Access levels | Using users; IP addresses and geolocations; time and date restrictions; login credential strength; enterprise certificates; device certificates (an organization-level license is required to create or modify access levels that use these attributes); device security postures; Chrome security postures; third party partner signals; advanced expression language |
| Other | Same-origin policy configuration in HTTP OPTIONS; custom authentication domain and 403 pages |
| Chrome protections | Data loss prevention with predefined or custom detectors; malware protection with advanced sandboxing; phishing and malicious URL protection; threat and data protection alerting and reporting |

## Notes

- Common use cases: let non-employees reach a single web application without a VPN; allow access from personal or mobile devices that meet a minimum security posture; prevent copying sensitive data into email or personal storage; allow only enterprise-managed devices to reach key systems; DLP for corporate data; gate access by location; protect hybrid applications.
