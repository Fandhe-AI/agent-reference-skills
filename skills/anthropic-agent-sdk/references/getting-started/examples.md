# Examples

Routes to complete, runnable Agent SDK projects and guided Claude Cookbook recipes that match what you want to build.

## Signature / Usage

```bash
git clone https://github.com/anthropics/claude-agent-sdk-demos
cd claude-agent-sdk-demos/hello-world
```

## Notes

- Run a minimal agent first: the Agent SDK quickstart (first working agent in TypeScript or Python; finds and fixes bugs in a sample file), or the `hello-world` minimal TypeScript project in `claude-agent-sdk-demos` to start from repo code.
- Demo applications live in the `anthropics/claude-agent-sdk-demos` repo (https://github.com/anthropics/claude-agent-sdk-demos). They are demos for local development, ranging from an email client to a multi-agent research system. Clone the one whose shape matches what you are building.
- Claude Cookbook Agent SDK series: Python notebooks that progress from a simple research agent to multi-agent systems, each building on the previous. Start with the one-liner research agent (https://platform.claude.com/cookbook/claude-agent-sdk-00-the-one-liner-research-agent). Full cookbook: https://platform.claude.com/cookbook.
