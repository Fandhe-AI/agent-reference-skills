# Age Ratings (IARC)

The **Age ratings** page of the app submission process: content-based age/rating info generated via the International Age Ratings Coalition (IARC) questionnaire.

## Signature / Usage

On first submission (or first update after the older rating process), complete a multiple-choice IARC questionnaire. If a rating ID already exists from another storefront, it can be reused instead of re-answering. Click **Save and generate** to receive assigned ratings; **Edit** to redo the questionnaire if content changes.

## Options / Props

| Item | Notes |
|---|---|
| IARC rating ID | Optional reuse of an existing cross-storefront rating |
| Publisher display name / email | Shared with IARC as part of the questionnaire process |
| Rating persistence | Same rating applies to subsequent updates unless content changes or IARC updates its questions |
| Appeal | Available via a link in the rating certificate email from IARC |
| Legacy ratings (pre-questionnaire) | 3+, 7+, 12+, 16+, 18+ — content-severity tiers, still referenced for older submissions |

## Notes

- Ratings describe suitability of app **content**, not the intended target audience age.
- A rating may make the app ineligible for certain markets; this is shown as a market restriction, and can be appealed via IARC.
- Accuracy in the questionnaire is required — misrepresenting content is a certification/policy risk.
