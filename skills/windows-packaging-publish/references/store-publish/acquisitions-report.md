# Acquisitions Report

Partner Center report showing how customers discover and acquire an app: page views, install attempts, installs, conversion, and geographic spread.

## Signature / Usage

Accessed in Partner Center under Insights → Acquisitions. Filterable by time range (1/3/6/12 months or custom), market, device type, OS version, campaign ID, page type, install type, and package version; near-real-time data available via the recent data view.

## Options / Props

| Metric | Description |
|---|---|
| Acquisition funnel | Page views → Install attempts → Acquisitions → Installs → First launches |
| Page views | Devices that viewed the Store listing (PDP/Mini-PDP/Store installer) |
| Installs | Successful installs, including new installs and reinstalls; excludes uninstalls, updates, preinstalls |
| Install success rate | Successful installs / (successful + failed installs) |
| User-initiated aborts | Installs canceled/paused by the user |
| Install failures | Genuine installation failures (excludes user cancels and network errors) |
| Conversion | Installs / page views |
| Campaign conversion | Conversion attributable to custom promotion campaigns |
| Acquisition | New license grants (paid MSIX apps/games only) |
| Gross sales | Total USD earned from app sales (paid products, before refunds/chargebacks) |
| Geographical spread | Installs by country/region |

## Notes

- Source breakdown distinguishes Microsoft Store on Windows, Microsoft Store web, external web URL, custom campaign, Bing web search, Xbox app, Windows Start, and App restore.
- Conversions from a custom campaign are attributed for 24 hours after the first page view carrying that campaign ID.
