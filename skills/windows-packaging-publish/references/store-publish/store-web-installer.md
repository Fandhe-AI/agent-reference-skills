# Microsoft Store Web Installer and Store Badges / Links

The Store Web Installer is a small stub .exe generated by the Store service that installs Store apps from websites (apps.microsoft.com or a Store badge on your site) without opening the Store app.

## Signature / Usage

Badge size customization (the badge is a web component, `ms-store-badge`, that doesn't inherit page CSS):

```css
/* Adjust the badge size to match other buttons on your page. */
ms-store-badge::part(img) {
  max-width: 200px;
}
```

Enable on your own website:

```text
apps.microsoft.com/badge -> enter your app data -> set Launch mode = Direct -> copy the generated code into your site.
```

## Options / Props

| Item | Value |
|---|---|
| Store listing URL | `https://apps.microsoft.com/store/detail/<your app's Store ID>` (Product Identity page in Partner Center) |
| Open Store app directly | `ms-windows-store://pdp/?ProductId=<your app's Store ID>` |
| Badge input | 12-character Store ID |
| Override on apps.microsoft.com | `mode=full` URL parameter launches the Store PDP instead of the Web Installer |
| Block for enterprises | Domain-block `get.microsoft.com` |

## Notes

- Supported content: free packaged MSIX content and Win32 apps published on the Store. Not available for MSIXVC apps, paid content, or content rated above Everyone/ESRB (or equivalent) while signed in to Windows with a School account.
- Flow: the stub verifies prerequisites (architecture, user age, market availability), installs via the same API as the Store app, tracks campaign IDs, and launches the app then closes. If prerequisites aren't met, it launches the Store app.
- On apps.microsoft.com the Web Installer is the default; no change is needed for eligible apps.
- Enterprise: `ApplicationManagement/RequirePrivateStoreOnly` MDM policy, the "Only display the private store within the Microsoft Store app" group policy, and the `RemoveWindowsStore` registry DWORD = 1 disable the Store application but don't block installs/updates of Store apps. Use AppLocker to control app installs (including via the Web Installer), alone or combined with those policies. Blocking `get.microsoft.com` doesn't affect the Store app or already installed apps.
- The URI scheme is useful when users are already on Windows or when linking from within a WinUI app.
- Source: https://learn.microsoft.com/en-us/windows/apps/distribute-through-store/how-to-use-store-web-installer-for-distribution, last updated 2026-09-14 (ms.date).
