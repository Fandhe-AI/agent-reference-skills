# Responsible AI FAQ for AI-Generated Keywords

Responsible-AI disclosure for the AI-Generated keywords feature, which recommends Store-listing search keywords to developers using Azure OpenAI.

## Signature / Usage

Surfaced in Partner Center on the Store listing page during submission: based on the app name and app description the developer has entered, the feature suggests search keywords that the developer can accept or ignore.

## Notes

- Powered by Azure OpenAI; recommendations are generated solely from the developer's own app name and app description.
- Intended use is to help developers increase Store discoverability by surfacing relevant keywords.
- Underwent red-teaming and other testing prior to release, aligned with the Microsoft AI Principles.
- If the app name/description are not meaningful words or sentences, the system may generate stale (low-quality) suggestions.
- Suggested keywords are never added automatically to the listing — the developer has full control over selection.
