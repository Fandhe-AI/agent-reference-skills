# Additional Information

Supplemental Store-listing fields that aid discoverability and licensing: keywords, copyright, license terms, and developer attribution.

## Signature / Usage

All fields optional. Keywords are the primary discoverability lever — up to 7 keywords, 40 characters each, no more than 21 total words across all keywords combined. AI-generated keyword suggestions can be produced from the app description.

## Options / Props

| Field | Limit | Notes |
|---|---|---|
| Keywords | 7 max, 40 chars each, 21 words total across all keywords | Not shown to customers; used only for search matching |
| Copyright and trademark info | 200 characters | Optional attribution text |
| Additional license terms | 10,000 characters, or a single URL | Defaults to Standard Application License Terms if left blank |
| Developed by | 255 characters | Distinct from "Published by" (always shows the account's publisher display name) |

## Notes

- Keywords formerly called "Search terms".
- Irrelevant keywords risk certification/policy issues — only include terms genuinely related to the app.
