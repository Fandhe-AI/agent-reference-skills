# Reserve App Name

The first step toward publishing an MSIX app on the Microsoft Store: reserving a unique app name.

## Signature / Usage

1. Navigate to the Partner Center apps and games page (`https://aka.ms/submitwindowsapp`).
2. Click **New product** → **MSIX or PWA app** (or **Game** for MSIX/PWA games).
3. Enter the desired name and click **Check availability**.
4. If available, click **Reserve product name**.

## Notes

- All Microsoft Store apps must have a unique name.
- A name can be reserved up to three months before the app is ready to publish; unused reservations are removed after three months.
- Multiple names can be reserved simultaneously; the final name is chosen at publish time.
- A name may be unavailable even if no app by that name is visible in the Store — another developer may have reserved it without submitting yet.
- MSI/EXE apps have a separate, equivalent name-reservation flow (`publish-your-app/msi/reserve-your-apps-name`) with the same basic process.
