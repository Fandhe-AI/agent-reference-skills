# Analytics and Reports (Overview)

Partner Center analytics for published apps: acquisition, usage, health, and customer-feedback reporting throughout the app lifecycle.

## Signature / Usage

Access via Partner Center dashboard, or programmatically via the Microsoft Store analytics API for MSIX apps.

## Options / Props

| Report | Description |
|---|---|
| Summary report | Consolidated overview of acquisition, usage, health, and feedback metrics |
| Acquisitions report | Views/installs by acquisition channel, market, platform |
| Add-on acquisitions report | Add-on sales with demographic/platform breakdown |
| Usage report | How customers use the app, including custom-defined events |
| Health report | Crashes, hangs, and other stability metrics |
| Ratings & Reviews report | Customer ratings/reviews with developer response capability |
| Insights report | AI-detected significant changes in acquisition/health data over the last 30 days |

## Notes

- Programmatic access to MSIX analytics data uses the Microsoft Store analytics API (`access-analytics-data-using-windows-store-services`), a separate API from the Submission API.
