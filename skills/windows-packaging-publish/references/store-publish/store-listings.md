# Store Listings

The text and image content shown to customers on an app's Store page, entered per Store-listing language.

## Signature / Usage

Minimum required for completion: a **Description** and at least one **screenshot**, for at least one language. Listings can be edited per-language in Partner Center, or bulk-managed via CSV import/export.

## Options / Props

| Field | Limit | Required |
|---|---|---|
| Description | 10,000 characters (plain text) | Yes |
| What's new in this version | 1,500 characters | No (leave blank on first submission) |
| Product features | Up to 20 items, 200 characters each | No |
| Short title | 50 characters | No |
| Sort title | 255 characters | No |
| Voice title | 255 characters | No |
| Short description | 1,000 characters (best kept under 270; only first 270 shown in some views) | No — falls back to first 500 characters of Description |
| Additional system requirements | Up to 11 items each for Minimum/Recommended hardware, 200 characters each | No |
| Keywords | Up to 7 keywords, 40 characters each, max 21 total words across all keywords | No |
| Copyright and trademark info | 200 characters | No |
| Additional license terms | 10,000 characters (or a single URL) | No — defaults to Standard Application License Terms |
| Developed by | 255 characters | No |

## Notes

- AI-generated keyword suggestions are available based on the entered description.
- Store listing must be completed separately for each language, unless imported via CSV.
- Store logos are required (not optional) if the app is available on Xbox.
