# Microsoft Store App Quality

Overview of app quality basics for Store apps: metadata (icon, title, description, screenshots / trailers), lasting value and UI, and customer feedback.

## Signature / Usage

```text
Store listing metadata checklist: icon -> title -> description (features section + summary) -> screenshots / trailers (under one minute)
```

## Options / Props

| Area | Guidance |
|---|---|
| Icon | Clear, simple, unique, instantly recognizable; avoid fuzzy/distorted icons or ID-style photos; use text sparingly; don't copy existing icons |
| Title | Original and distinctive (avoid spelling variations of other apps); informative, not generic ("My First App", "Client App") |
| Description | Simple language and good grammar; concise; list features in the features section and summarize the best ones; tell the truth (mark planned features as planned); state dependencies on other apps at the beginning |
| Screenshots / trailers | Show actual features and a clean interface; avoid many near-identical screenshots; show the Windows experience; keep trailers under a minute and relevant |
| Value | Lasting value (enough content, regular updates, meaningful gameplay/outcomes); one useful feature no one else offers |
| UI | Clean, simple, intuitive and consistent with the platform; the single biggest quality hallmark for users |
| Check in | Ask for ratings and reviews and leave the rating to customers; respond to bugs and feature requests; keep updating |
