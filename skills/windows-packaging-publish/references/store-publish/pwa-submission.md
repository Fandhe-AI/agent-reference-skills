# PWA Submission Flow (Partner Center)

Creating a Partner Center submission for a Progressive Web App (PWA) product. The checklist structure and most field-level requirements are shared with the MSIX submission flow; this page covers what is PWA-specific.

## Signature / Usage

1. Reserve the app name: Partner Center → **New product** → **MSIX or PWA app**, check availability, then reserve.
2. From the app's application overview page, in the **Product release** section, click **Start submission** to create a draft submission.
3. Complete each checklist section (Pricing and availability, Properties, Age ratings, Packages, Store listings, Submission options), then click **Submit for certification**.

## Options / Props

| Aspect | PWA specifics |
|---|---|
| Product type selection | **MSIX or PWA app** at New product creation (same reservation flow as MSIX) |
| Packages page | Takes an app package generated from the web app (e.g. via PWABuilder), rather than a native MSIX build output |
| Pricing and availability, Properties, Age ratings, Store listings | Same fields and requirements as the MSIX submission checklist — see Create App Submission |

## Notes

- Sections can be completed in any order.
- Alternatively, submissions can be automated via the Microsoft Store submission API rather than the Partner Center UI.
