# App Properties

The **Properties** page of the app submission process: category, privacy policy, support info, product declarations, and system requirements.

## Signature / Usage

Required: primary **Category** (and subcategory if applicable). Optional: secondary category, **Privacy policy URL** (required if the app accesses/collects/transmits personal information), support website/contact info, **Game settings** (if category is Games), **Display mode** (immersive/Windows Mixed Reality, 4K/HDR/variable refresh rate for games), **Product declarations**, **System requirements**.

## Options / Props

| Field | Required | Notes |
|---|---|---|
| Category | Yes | Determines Store categorization |
| Subcategory / secondary category | No | Secondary category uses the same list as primary |
| Privacy policy URL | Conditional | Required if app collects/transmits personal data; may still be required based on declared package capabilities even if not |
| Support info (website, contact) | Conditional | Support contact required if published to Xbox |
| Game settings | Conditional | Shown only when category is Games; multiplayer session player counts capped at 1000 |
| Display mode | No | Windows Mixed Reality immersive view, boundary setup, 4K/HDR/variable refresh rate for games |
| Product declarations | No | Checkboxes affecting how the app is displayed/offered |
| System requirements | No | Indicate required/recommended hardware |

## Notes

- Failure to provide a required privacy policy can result in certification failure.
