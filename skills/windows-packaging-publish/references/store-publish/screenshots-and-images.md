# Screenshots and Images

Visual assets — screenshots, logos, trailers, and promotional art — uploaded in the Store listings step to represent the app in the Store.

## Signature / Usage

At least one screenshot (`.png`, ≤ 50 MB) is required per submission; other image/trailer assets are optional but affect display quality and Xbox eligibility.

## Options / Props

| Asset | Requirement |
|---|---|
| Screenshots (Desktop) | 1366x768 or larger, up to 4K (3840x2160); max 10 |
| Screenshots (Xbox) | 1920x1080 to 3840x2160; max 8 |
| Screenshots (Holographic) | 1268x720 or larger, up to 4K; max 8 |
| Screenshot caption | 200 characters or less |
| 2:3 Poster art | 720x1080 or 1440x2160 px; required if published to Xbox |
| 1:1 box art | 1080x1080 or 2160x2160 px |
| 1:1 App tile icon | 300x300 px; overrides package-embedded icon if provided |
| 16:9 Super hero art | 1920x1080 or 3840x2160 px; required for game trailers to appear at top of listing |
| Xbox branded key art | 584x800 px, must include title |
| Xbox titled hero art | 1920x1080 px, must include title |
| Xbox featured promotional square | 1080x1080 px, must NOT include title |
| Holographic image | 2400x1200 px |
| Trailers | `.mp4`/`.mov`, ≤ 2 GB, 1920x1080, ≤ 15 per listing, title ≤ 255 chars |
| Trailer thumbnail | `.png`, 1920x1080 |
| Closed captions | WebVTT `.vtt`, < 50 MB |
| Audio descriptions | `.mp3`, < 500 MB |

## Notes

- Only one screenshot (any device family) is required, but 4+ per supported device family is recommended.
- Trailers must not include embedded age-rating overlays when shown only on the Microsoft Store product page (this exception does not apply to trailers distributed elsewhere).
- Do not include the product title or other text in the 16:9 Super hero art image.
