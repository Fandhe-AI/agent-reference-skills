# Confidential VM overview

Confidential VM instances are Compute Engine VMs that use hardware-based memory encryption to help ensure that data and applications can't be read or modified while in use. Isolation (keys generated by and kept in dedicated hardware, inaccessible to the hypervisor) and attestation together form a Trusted Execution Environment (TEE). You enable the service when you create a new VM instance.

## Signature / Usage

```bash
gcloud compute instances create INSTANCE_NAME \
    --confidential-compute-type=CONFIDENTIAL_COMPUTING_TECHNOLOGY \
    --machine-type=MACHINE_TYPE_NAME \
    --min-cpu-platform="CPU_PLATFORM" \
    --maintenance-policy=MAINTENANCE_POLICY \
    --zone=ZONE_NAME \
    --image-project=IMAGE_PROJECT \
    --image-family=IMAGE_FAMILY_NAME \
    --project=PROJECT_ID
```

## Options / Props

The technology is determined by the machine type and CPU platform you choose.

| Technology | Description |
|------------|-------------|
| AMD SEV | Memory encryption through the AMD Secure Processor; boot-time attestation through Google's vTPM. Performance difference from a standard VM ranges from none to minimal. Unlike the other technologies, AMD SEV on N2D and C3D machine types supports live migration. |
| AMD SEV-SNP | Expands SEV with hardware-based security to help prevent malicious hypervisor-based attacks like data replay and memory remapping. Attestation reports can be requested at any time directly from the AMD Secure Processor. |
| Intel TDX | Creates an isolated trust domain (TD) within a VM and uses hardware extensions to manage and encrypt memory; augments defense against limited physical-access attacks on DRAM (capturing, modifying, relocating, splicing, aliasing memory contents). |
| NVIDIA Confidential Computing | Extends the TEE to attached NVIDIA GPUs so data in GPU-accelerated AI / ML workloads is encrypted in use. Integrated with AMD SEV or Intel TDX for CPU+GPU workloads. |

### Services that use Confidential VM

- Confidential GKE Nodes (enforce Confidential VM for all GKE nodes).
- Confidential Space (parties share sensitive data with a mutually agreed workload).
- Managed Service for Apache Spark Confidential Compute.
- Dataflow Confidential VM (worker instances).
