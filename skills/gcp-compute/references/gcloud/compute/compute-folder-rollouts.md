# gcloud compute folder-rollouts

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha compute folder-rollouts cancel

```text
NAME
    gcloud alpha compute folder-rollouts cancel - cancel a folder rollout

SYNOPSIS
    gcloud alpha compute folder-rollouts cancel (NAME : --folder=FOLDER)
        [--rollback] [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha compute folder-rollouts delete

```text
NAME
    gcloud alpha compute folder-rollouts delete - delete a folder rollout

SYNOPSIS
    gcloud alpha compute folder-rollouts delete (NAME : --folder=FOLDER)
        [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha compute folder-rollouts describe

```text
NAME
    gcloud alpha compute folder-rollouts describe - describe a folder rollout

SYNOPSIS
    gcloud alpha compute folder-rollouts describe (NAME : --folder=FOLDER)
        [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha compute folder-rollouts list

```text
NAME
    gcloud alpha compute folder-rollouts list - list Google Compute Engine
        Folder Rollouts

SYNOPSIS
    gcloud alpha compute folder-rollouts list --folder=FOLDER
        [--filter=EXPRESSION] [--limit=LIMIT] [--page-size=PAGE_SIZE]
        [--sort-by=[FIELD,...]] [--uri] [GCLOUD_WIDE_FLAG ...]
```
