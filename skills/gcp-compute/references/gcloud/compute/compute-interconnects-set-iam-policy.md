# gcloud compute interconnects set-iam-policy

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha compute interconnects set-iam-policy

```text
NAME
    gcloud alpha compute interconnects set-iam-policy - set the IAM policy for
        a Compute Engine interconnect

SYNOPSIS
    gcloud alpha compute interconnects set-iam-policy INTERCONNECT POLICY_FILE
        [--endpoint-mode=ENDPOINT_MODE] [GCLOUD_WIDE_FLAG ...]
```
