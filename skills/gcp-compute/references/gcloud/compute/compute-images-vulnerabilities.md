# gcloud compute images vulnerabilities

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha compute images vulnerabilities describe-note

```text
NAME
    gcloud alpha compute images vulnerabilities describe-note - describe a
        Compute Engine image

SYNOPSIS
    gcloud alpha compute images vulnerabilities describe-note NOTE_NAME
        [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha compute images vulnerabilities list

```text
NAME
    gcloud alpha compute images vulnerabilities list - list Google occurrences
        of PACKAGE_VULNERABILITY

SYNOPSIS
    gcloud alpha compute images vulnerabilities list [NAME ...] [--image=IMAGE]
        [--regexp=REGEXP, -r REGEXP] [--filter=EXPRESSION] [--limit=LIMIT]
        [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
        [GCLOUD_WIDE_FLAG ...]
```
