# Installation

Install the TanStack Virtual adapter for your framework as a dependency using your preferred npm package manager.

## Signature / Usage

```bash
npm install @tanstack/react-virtual
```

## Options / Props

| Package | Description |
|---------|-------------|
| `@tanstack/react-virtual` | React adapter |
| `@tanstack/solid-virtual` | Solid adapter |
| `@tanstack/svelte-virtual` | Svelte adapter |
| `@tanstack/vue-virtual` | Vue adapter |
| `@tanstack/lit-virtual` | Lit adapter |
| `@tanstack/angular-virtual` | Angular adapter |
| `@tanstack/marko-virtual` | Marko adapter |
| `@tanstack/virtual-core` | Framework-agnostic core (no framework) |
