# Developer Connect IAM roles and permissions

## Signature / Usage

Predefined roles of `developerconnect` (role ID, description, included permissions) and, for each permission, the roles that contain it.

### Roles

#### Developer Connect Admin (`roles/developerconnect.admin`)

- Full access to Developer Connect resources.
- Permissions (40): `developerconnect.connections.constructGitHubAppManifest`, `developerconnect.connections.create`, `developerconnect.connections.createTagBinding`, `developerconnect.connections.delete`, `developerconnect.connections.deleteTagBinding`, `developerconnect.connections.fetchGitHubInstallations`, `developerconnect.connections.fetchLinkableGitRepositories`, `developerconnect.connections.generateGitHubStateToken`, `developerconnect.connections.get`, `developerconnect.connections.list`, `developerconnect.connections.listEffectiveTags`, `developerconnect.connections.listTagBindings`, `developerconnect.connections.processGitHubAppCreationCallback`, `developerconnect.connections.processGitHubOAuthCallback`, `developerconnect.connections.update`, `developerconnect.gitRepositoryLinks.addPullRequestComment`, `developerconnect.gitRepositoryLinks.addPullRequestReviewComment`, `developerconnect.gitRepositoryLinks.create`, `developerconnect.gitRepositoryLinks.delete`, `developerconnect.gitRepositoryLinks.diffCommit`, `developerconnect.gitRepositoryLinks.fetchCommit`, `developerconnect.gitRepositoryLinks.fetchCommitList`, `developerconnect.gitRepositoryLinks.fetchFileBlame`, `developerconnect.gitRepositoryLinks.fetchGitRefs`, `developerconnect.gitRepositoryLinks.fetchPullRequest`, `developerconnect.gitRepositoryLinks.fetchPullRequestList`, `developerconnect.gitRepositoryLinks.get`, `developerconnect.gitRepositoryLinks.gitProxyRead`, `developerconnect.gitRepositoryLinks.gitProxyWrite`, `developerconnect.gitRepositoryLinks.list`, `developerconnect.gitRepositoryLinks.modifyPullRequest`, `developerconnect.gitRepositoryLinks.openPullRequest`, `developerconnect.locations.get`, `developerconnect.locations.list`, `developerconnect.operations.cancel`, `developerconnect.operations.delete`, `developerconnect.operations.get`, `developerconnect.operations.list`, `resourcemanager.projects.get`, `resourcemanager.projects.list`

#### Developer Connect Viewer (`roles/developerconnect.viewer`)

- Read-only access to Developer Connect resources.
- Permissions (12): `developerconnect.connections.get`, `developerconnect.connections.list`, `developerconnect.connections.listEffectiveTags`, `developerconnect.connections.listTagBindings`, `developerconnect.gitRepositoryLinks.get`, `developerconnect.gitRepositoryLinks.list`, `developerconnect.locations.get`, `developerconnect.locations.list`, `developerconnect.operations.get`, `developerconnect.operations.list`, `resourcemanager.projects.get`, `resourcemanager.projects.list`

#### Developer Connect HTTP Proxy Writer (`roles/developerconnect.connectionHttpProxyWriter`)

- Launch stage: Beta
- Grants read and write access to connections through the HTTP Proxy.
- Permissions (2): `developerconnect.connections.httpProxyRead`, `developerconnect.connections.httpProxyWrite`

#### Developer Connect Git Proxy Reader (`roles/developerconnect.gitProxyReader`)

- Grants read-only access to repositories through the Git Proxy.
- Permissions (1): `developerconnect.gitRepositoryLinks.gitProxyRead`

#### Developer Connect Git Proxy User (`roles/developerconnect.gitProxyUser`)

- Grants read and write access to repositories through the Git Proxy.
- Permissions (2): `developerconnect.gitRepositoryLinks.gitProxyRead`, `developerconnect.gitRepositoryLinks.gitProxyWrite`

#### Developer Connect Insights Admin (`roles/developerconnect.insightsAdmin`)

- Admin access to Developer Connect Insights resources.
- Permissions (13): `developerconnect.deploymentEvents.get`, `developerconnect.deploymentEvents.list`, `developerconnect.insightsConfigs.create`, `developerconnect.insightsConfigs.delete`, `developerconnect.insightsConfigs.get`, `developerconnect.insightsConfigs.list`, `developerconnect.insightsConfigs.update`, `developerconnect.locations.get`, `developerconnect.locations.list`, `developerconnect.operations.get`, `developerconnect.operations.list`, `resourcemanager.projects.get`, `resourcemanager.projects.list`

#### Developer Connect Insights Config Agent (`roles/developerconnect.insightsAgent`)

- Allow Developer Connect to access SDLC information.
- Permissions (10): `cloudasset.assets.exportResource`, `cloudasset.assets.listResource`, `cloudasset.assets.searchAllResources`, `cloudasset.feeds.create`, `cloudasset.feeds.delete`, `cloudasset.feeds.get`, `cloudasset.feeds.update`, `containeranalysis.occurrences.get`, `containeranalysis.occurrences.list`, `logging.logEntries.create`

#### Developer Connect Insights Viewer (`roles/developerconnect.insightsViewer`)

- Read-only access to Developer Connect Insights resources.
- Permissions (10): `developerconnect.deploymentEvents.get`, `developerconnect.deploymentEvents.list`, `developerconnect.insightsConfigs.get`, `developerconnect.insightsConfigs.list`, `developerconnect.locations.get`, `developerconnect.locations.list`, `developerconnect.operations.get`, `developerconnect.operations.list`, `resourcemanager.projects.get`, `resourcemanager.projects.list`

#### Developer Connect OAuth Admin (`roles/developerconnect.oauthAdmin`)

- Launch stage: Beta
- Grants read and write access to AccountConnector resources.
- Permissions (24): `developerconnect.accountConnectors.create`, `developerconnect.accountConnectors.delete`, `developerconnect.accountConnectors.fetchUserRepositories`, `developerconnect.accountConnectors.get`, `developerconnect.accountConnectors.gitProxyRead`, `developerconnect.accountConnectors.gitProxyWrite`, `developerconnect.accountConnectors.httpProxyRead`, `developerconnect.accountConnectors.httpProxyWrite`, `developerconnect.accountConnectors.list`, `developerconnect.accountConnectors.update`, `developerconnect.locations.get`, `developerconnect.locations.list`, `developerconnect.operations.get`, `developerconnect.operations.list`, `developerconnect.providers.list`, `developerconnect.users.delete`, `developerconnect.users.deleteSelf`, `developerconnect.users.fetchAccessToken`, `developerconnect.users.finishOAuth`, `developerconnect.users.getSelf`, `developerconnect.users.list`, `developerconnect.users.startOAuth`, `resourcemanager.projects.get`, `resourcemanager.projects.list`

#### Developer Connect OAuth User (`roles/developerconnect.oauthUser`)

- Launch stage: Beta
- Grants read and write access to User resources, and read access to AccountConnectors.
- Permissions (18): `developerconnect.accountConnectors.fetchUserRepositories`, `developerconnect.accountConnectors.get`, `developerconnect.accountConnectors.gitProxyRead`, `developerconnect.accountConnectors.gitProxyWrite`, `developerconnect.accountConnectors.httpProxyRead`, `developerconnect.accountConnectors.httpProxyWrite`, `developerconnect.accountConnectors.list`, `developerconnect.locations.get`, `developerconnect.locations.list`, `developerconnect.operations.get`, `developerconnect.operations.list`, `developerconnect.users.deleteSelf`, `developerconnect.users.fetchAccessToken`, `developerconnect.users.finishOAuth`, `developerconnect.users.getSelf`, `developerconnect.users.startOAuth`, `resourcemanager.projects.get`, `resourcemanager.projects.list`

#### Developer Connect Read Token Accessor (`roles/developerconnect.readTokenAccessor`)

- Launch stage: Beta
- Grants access to Read-Only tokens (both PAT and short-lived). Also grants access to view the git repository link.
- Permissions (3): `developerconnect.connections.get`, `developerconnect.gitRepositoryLinks.fetchReadToken`, `developerconnect.gitRepositoryLinks.get`

#### Developer Connect Token Accessor (`roles/developerconnect.tokenAccessor`)

- Launch stage: Beta
- Grants access to Read/Write and Read-Only tokens (both PAT and short-lived). Also grants access to view the git repository link.
- Permissions (4): `developerconnect.connections.get`, `developerconnect.gitRepositoryLinks.fetchReadToken`, `developerconnect.gitRepositoryLinks.fetchReadWriteToken`, `developerconnect.gitRepositoryLinks.get`

#### Developer Connect User (`roles/developerconnect.user`)

- Grants access to view the connection and to the features that interact with the actual repository such as reading content from the repository
- Permissions (25): `developerconnect.connections.fetchGitHubInstallations`, `developerconnect.connections.fetchLinkableGitRepositories`, `developerconnect.connections.get`, `developerconnect.connections.list`, `developerconnect.connections.listEffectiveTags`, `developerconnect.connections.listTagBindings`, `developerconnect.gitRepositoryLinks.addPullRequestComment`, `developerconnect.gitRepositoryLinks.addPullRequestReviewComment`, `developerconnect.gitRepositoryLinks.diffCommit`, `developerconnect.gitRepositoryLinks.fetchCommit`, `developerconnect.gitRepositoryLinks.fetchCommitList`, `developerconnect.gitRepositoryLinks.fetchFileBlame`, `developerconnect.gitRepositoryLinks.fetchGitRefs`, `developerconnect.gitRepositoryLinks.fetchPullRequest`, `developerconnect.gitRepositoryLinks.fetchPullRequestList`, `developerconnect.gitRepositoryLinks.get`, `developerconnect.gitRepositoryLinks.list`, `developerconnect.gitRepositoryLinks.modifyPullRequest`, `developerconnect.gitRepositoryLinks.openPullRequest`, `developerconnect.locations.get`, `developerconnect.locations.list`, `developerconnect.operations.get`, `developerconnect.operations.list`, `resourcemanager.projects.get`, `resourcemanager.projects.list`

#### Developer Connect Service Agent (`roles/developerconnect.serviceAgent`)

- Gives the Developer Connect API Service Account access to necessary GCP resources. > \[!WARNING\] > \*\*Warning:\*\* Do not grant service agent roles to any principals except service agents (https://docs.cloud.google.com/iam/docs/service-agents).
- Permissions (10): `apphub.applications.get`, `apphub.services.get`, `apphub.services.list`, `apphub.workloads.get`, `apphub.workloads.list`, `developerconnect.connections.get`, `developerconnect.connections.httpProxyRead`, `developerconnect.connections.httpProxyWrite`, `developerconnect.gitRepositoryLinks.get`, `developerconnect.operations.get`

### Example: grant a role

Generated example (not in the official docs) granting the first role on this page on a whole project (the role entry on this page does not list the lowest-level resources where it can be granted; granting it on a narrower resource, where the role supports that, limits the scope):

```bash
gcloud projects add-iam-policy-binding PROJECT_ID \
  --member="user:EMAIL_ADDRESS" \
  --role="roles/developerconnect.admin"
```
