# gcloud source-manager pull-requests open

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta source-manager pull-requests open

```text
NAME
    gcloud beta source-manager pull-requests open - open a Secure Source
        Manager pull request

SYNOPSIS
    gcloud beta source-manager pull-requests open
        (PULL_REQUEST : --region=REGION --repository=REPOSITORY) [--async]
        [--endpoint-mode=ENDPOINT_MODE] [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha source-manager pull-requests open

```text
NAME
    gcloud alpha source-manager pull-requests open - open a Secure Source
        Manager pull request

SYNOPSIS
    gcloud alpha source-manager pull-requests open
```
