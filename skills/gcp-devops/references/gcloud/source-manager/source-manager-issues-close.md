# gcloud source-manager issues close

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta source-manager issues close

```text
NAME
    gcloud beta source-manager issues close - close a Secure Source Manager
        issue

SYNOPSIS
    gcloud beta source-manager issues close
        (ISSUE : --region=REGION --repository=REPOSITORY) [--async]
        [--endpoint-mode=ENDPOINT_MODE] [--etag=ETAG] [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha source-manager issues close

```text
NAME
    gcloud alpha source-manager issues close - close a Secure Source Manager
        issue
```
