# gcloud app-lifecycle-manager flags pull

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta app-lifecycle-manager flags pull

```text
NAME
    gcloud beta app-lifecycle-manager flags pull - create a JSON manifest file
        using the SaaS Flags API as the source of truth

SYNOPSIS
    gcloud beta app-lifecycle-manager flags pull --output-file=OUTPUT_FILE
        (--unit-kind=UNIT_KIND : --location=LOCATION) [--flag-set=FLAG_SET]
        [--overwrite-output-file] [GCLOUD_WIDE_FLAG ...]
```

## Notes

- Text taken verbatim from `gcloud meta generate-help-docs` of Google Cloud CLI 593.0.0 (retrieved 2026-11-14). Release tracks on this page: beta.
- Examples are verbatim from `gcloud help`. Some wrap a long value with a trailing backslash and indentation (join the lines when running them), and some omit positional arguments that the SYNOPSIS requires; follow the SYNOPSIS.
- GCLOUD_WIDE_FLAG stands for the global flags (`--help`, `--project`, `--format`, `--quiet`, `--verbosity`, ...); see the gcloud-wide flags in the `gcp-cli` skill.
