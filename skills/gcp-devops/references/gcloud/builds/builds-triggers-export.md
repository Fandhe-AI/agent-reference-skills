# gcloud builds triggers export

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud beta builds triggers export

```text
NAME
    gcloud beta builds triggers export - export a build trigger

SYNOPSIS
    gcloud beta builds triggers export (TRIGGER : --region=REGION)
        --destination=PATH [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha builds triggers export

```text
NAME
    gcloud alpha builds triggers export - export a build trigger

SYNOPSIS
    gcloud alpha builds triggers export (TRIGGER : --region=REGION)
        --destination=PATH [GCLOUD_WIDE_FLAG ...]
```
