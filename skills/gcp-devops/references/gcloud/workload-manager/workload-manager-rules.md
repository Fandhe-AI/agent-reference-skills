# gcloud workload-manager rules

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha workload-manager rules list

```text
NAME
    gcloud alpha workload-manager rules list - lists rules in a location

SYNOPSIS
    gcloud alpha workload-manager rules list --location=LOCATION
        [--custom-rules-bucket=CUSTOM_RULES_BUCKET]
        [--endpoint-mode=ENDPOINT_MODE] [--evaluation-type=EVALUATION_TYPE]
        [--filter=EXPRESSION] [--limit=LIMIT] [--page-size=PAGE_SIZE]
        [--sort-by=[FIELD,...]] [GCLOUD_WIDE_FLAG ...]
```
