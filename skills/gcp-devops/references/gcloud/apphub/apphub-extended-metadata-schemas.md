# gcloud apphub extended-metadata-schemas

## Signature / Usage

GA commands show the full `gcloud help` text; alpha and beta commands show NAME and SYNOPSIS (use `gcloud alpha|beta <command> --help` for the rest).

### gcloud alpha apphub extended-metadata-schemas describe

```text
NAME
    gcloud alpha apphub extended-metadata-schemas describe - describe an App
        Hub extended metadata schema

SYNOPSIS
    gcloud alpha apphub extended-metadata-schemas describe
        (EXTENDED_METADATA_SCHEMA : --location=LOCATION) [GCLOUD_WIDE_FLAG ...]
```

### gcloud alpha apphub extended-metadata-schemas list

```text
NAME
    gcloud alpha apphub extended-metadata-schemas list - list App Hub extended
        metadata schemas

SYNOPSIS
    gcloud alpha apphub extended-metadata-schemas list --location=LOCATION
        [--limit=LIMIT] [--page-size=PAGE_SIZE] [--uri] [GCLOUD_WIDE_FLAG ...]
```
