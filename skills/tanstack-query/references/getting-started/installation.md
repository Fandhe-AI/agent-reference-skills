# Installation

Install `@tanstack/react-query` via npm/pnpm/yarn/bun/deno, or use an ESM CDN.

## Signature / Usage

```bash
npm i @tanstack/react-query
```

```bash
pnpm add @tanstack/react-query
```

```bash
yarn add @tanstack/react-query
```

```bash
bun add @tanstack/react-query
```

## Notes

- Compatible with React v18+, works with ReactDOM and React Native
- Browser support: Chrome >= 91, Firefox >= 90, Edge >= 91, Safari >= 15, iOS >= 15, Opera >= 77 (older browsers need polyfills / transpiling from `node_modules`)
- Recommended companion: `@tanstack/eslint-plugin-query` (`npm i -D @tanstack/eslint-plugin-query`) to catch bugs and inconsistencies
- CDN usage: import from an ESM-compatible CDN such as ESM.sh via `<script type="module">`
