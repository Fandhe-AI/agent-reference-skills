# Introduction to App Architecture

Introduces why apps need a robust architecture: adapting to common tasks (starting activities, passing data between apps, multi-form-factor resources) while remaining testable, maintainable, and robust.

## Notes

- Serves as the entry point into the Guide to app architecture; links out to UI layer, domain layer, data layer, ViewModel, navigation, and dependency injection guides.
- Emphasizes three qualities good architecture provides: robustness (handles edge cases and failures gracefully), testability (components testable in isolation), maintainability (organized, easy to modify).
- Highlights common tasks apps must handle correctly regardless of architecture: starting activities and managing the back stack, passing data between apps via intents/App Links, and adapting resources across phones, tablets, foldables, and other form factors.
