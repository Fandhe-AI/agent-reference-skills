# hooks

| Name | Description | Path |
|------|-------------|------|
| RootState (state properties) | The state model returned by `useThree()` and passed to `useFrame` callbacks. | [root-state.md](./root-state.md) |
| useFrame | This hook allows you to execute code on every rendered frame, such as running effects or updating controls. | [use-frame.md](./use-frame.md) |
| useGraph | Convenience hook which creates a memoized, named object/material collection from any `Object3D`. | [use-graph.md](./use-graph.md) |
| useInstanceHandle | Exposes react-internal local state from `instance.__r3f`. | [use-instance-handle.md](./use-instance-handle.md) |
| useLoader | This hook loads assets and suspends for easier fallback- and error-handling. | [use-loader.md](./use-loader.md) |
| useThree | This hook gives you access to the state model which contains the default renderer, the scene, your camera, and so on. | [use-three.md](./use-three.md) |
