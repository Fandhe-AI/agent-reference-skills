# cluster-network

Commands for verifying the ConnectX-7 cluster network, checking/removing netplan configuration, and unifying user information across multiple nodes. Run all commands on each node of the cluster (e.g. DGX Spark).

## Check netplan configuration file

```bash
sudo ls /etc/netplan/99-nvidia-sync-cluster.yaml
sudo cat /etc/netplan/99-nvidia-sync-cluster.yaml
```

Run on each cluster node. Confirms the existence and shows the contents of the netplan configuration file generated by NVIDIA Sync for ConnectX-7.

## Inspect network runtime state

```bash
ip -br link
ip -br addr
```

Run on each cluster node. Checks the active network interfaces and the assigned IP addresses.

## Check connectivity between nodes

```bash
ping -c 3 <peer-cluster-ip>
```

Run on each cluster node. Replace `<peer-cluster-ip>` with the actual cluster IP address of the node to check connectivity against.

## Disable/remove netplan configuration

> **Warning**: Moving `/etc/netplan/99-nvidia-sync-cluster.yaml` disables the ConnectX-7 cluster network configuration. To restore it, move the file back to its original path.

```bash
sudo mkdir -p /root/netplan-disabled
sudo mv /etc/netplan/99-nvidia-sync-cluster.yaml /root/netplan-disabled/
sudo netplan generate
sudo netplan try
ip -br addr
```

Run on the node where you want to remove the configuration. After moving the file aside, regenerate the configuration with `netplan generate`, apply it with `netplan try` (a confirmation prompt will appear), then verify the result with `ip -br addr`.

## Unify user information across multiple nodes (Ubuntu 24.04)

Check whether a UID/GID is already in use.

```bash
getent passwd <uid>
getent group <gid>
```

Run on each node. Replace `<uid>` / `<gid>` with the IDs to check.

Create a group with the specified GID.

```bash
sudo groupadd --gid <gid> <group-name>
```

Run on each node.

Create a user with the specified UID and primary GID.

```bash
sudo adduser --uid <uid> --gid <gid> <username>
```

Run on each node.

If administrator privileges are required, add the user to the sudo group.

```bash
sudo usermod -aG sudo <username>
```

Run on each node.
