# Quick Start

Fastest way to get started with TanStack Router: scaffold a new project via the CLI.

## Signature / Usage

```sh
# React
npx @tanstack/cli create --router-only

# Solid
npx @tanstack/cli create --router-only --framework solid
```

The CLI prompts for: file-based or code-based route configuration, TypeScript support, Tailwind CSS integration, toolchain setup, Git initialization.

## Notes

- File-based routing is the recommended approach for most projects; it automatically creates routes from your file structure
- Full option/template details: https://github.com/TanStack/cli
